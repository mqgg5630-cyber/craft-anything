# 角色锁定 · 逐张验收清单

一张一张勾，任何一项打叉就只重做那一张。

## A. 角色（最重要）

- [ ] 角色数量一致，左右顺序一致
- [ ] 轮廓与线稿风格一致（线宽、描边色、水彩边缘）
- [ ] 大小与画面占比一致，位置基本不偏移
- [ ] 表情一致：眼睛画法（闭眼弧线 / 圆眼高光）、嘴形、腮红位置与浓淡
- [ ] 特征配件一致：犄角（颜色/角度）、蝠翼、心形尾巴、羽毛翅膀
- [ ] **没有**新增任何穿戴物：帽子、围巾、耳罩、手套、毛衣
- [ ] 没有"变精细/变 3D"，仍是原来的扁平水彩质感

## B. 文字

- [ ] 内容一字不差（含中间的爱心/间隔符）
- [ ] 颜色一致，大小一致；若本轮升级了字形，10 张之间的字体风格一致（不是每张一个样）
- [ ] 位置一致，下方下划线保留
- [ ] 字没有被背景元素压住或模糊

## C. 版式

- [ ] 竖屏比例接近原图（9:16 上下），不是横版或方形（2:3 的用 FIX_RATIO=1 居中裁，不必重新生成）
- [ ] 没有意外加上的画框、暗角、霜花边框
- [ ] 顶部渐变走向与原图一致（谁深谁浅）
- [ ] 月亮/太阳位置与大小一致
- [ ] 中间仍是"大片留白"，能放手机图标
- [ ] 底部地景高度不高于原图，没有向上侵占留白

## D. 季节

- [ ] 旧季节道具全部消失（蝙蝠/南瓜/糖果/枯枝……逐个点过）
- [ ] 新季节元素成体系，不是孤立贴上去的
- [ ] 配色仍在原图的色系里（不要突然出现高饱和红绿）
- [ ] 10 张彼此有差异（地景/天空各不同），但一眼能看出是同一套

## E. 交付

- [ ] 命名排序正确（01…10）
- [ ] 子文件夹命名带季节，且放在原图所在的同级目录
- [ ] 每轮一个独立子文件夹，没有覆盖上一轮
- [ ] 有总图 `00-总图-第N轮.jpg`，且是**完整网格**（行数没缺）
- [ ] 没有打 zip，直接是文件夹
- [ ] 原图副本留在同目录，便于对照
