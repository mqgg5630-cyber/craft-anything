# 季节版壁纸套装（同款换季）

一句话目标：**人物一像素都不改，只换季节。**

增删季节道具很容易，难的是让人物"一模一样"。所以不要"重新画一张同风格的图"，而要
**以原图为编辑底稿（image edit / image-to-image）**，让模型只重绘季节区域。

## 开始前必须拿到的三样东西

1. **原图**（最好是原始分辨率，不要截图压缩版）。拿到后立刻复制一份到工作区，命名为
   `source/<season>-original.jpg`，后续每次编辑都用它当底稿，绝不用上一轮的产物当底稿（会逐轮劣化）。
2. **角色特征清单**：几个角色、各自造型（翅膀/犄角/尾巴/配饰）、表情、在画面中的位置与大小、
   手写文字内容与字体颜色。写下来，逐条抄进 prompt。
3. **输出规格**：张数（默认 10）、比例（手机壁纸 9:16）、存放位置（默认在原图同级新建子文件夹）。

任何一项缺失就先问，别猜。用户说"角色要一模一样"时，这条清单就是验收标准。

## 铁律（违反就要重做）

- **不给角色加任何东西**：帽子、围巾、耳罩、手套、圣诞帽一律禁止，哪怕"更有冬天的感觉"。
  模型非常爱自作主张加圣诞帽，prompt 里必须显式写 `Do NOT add hats, scarves or clothing`。
- **文字只准"变好看"，不准"变位置"**：内容、颜色、位置、大小、下划线保留，字体质量可以升级
  （用户常要求"字体更好看一点"）。做法是在 prompt 里单独写一段"只改字形"：手写刷字体/连笔 script +
  光泽小爱心 + 细墨迹 + 字尾轻微加粗，并强调 `same spot, same size, same color`、`real crisp legible
  text, no gibberish`。整批 10 张必须用**同一段**字形描述，否则字体风格会散。
- **不改版式**：渐变走向、月亮位置、"中间大片留白"的空旷感都要保持，否则 10 张拼在一起不像一套。
- **不要用"重新画"的措辞**：开头用 `Edit this vertical phone wallpaper`，并逐条列出 `KEEP COMPLETELY
  UNCHANGED: ...` 与 `Only change the season: ...` 两段。
- **一次只改季节相关的三层**：天空（雪花/极光/流星）、月亮周围、画面底部地景。中间留白区域尽量不动。

## 流程

### 1. 校准一张，再做剩下九张

先只做第 1 张，用 `offer_options`（两个模型各出一版）让用户选，确认人物是否过关。
通过后再用同一条 prompt 骨架批量做剩下的，**不要**在未确认前一次生成 10 张——返工成本极高。
（若用户明确说"不用给我选"，就跳过比较、直接出图，但仍先做 1 张自检。）

### 2. 十张的构图分工（避免十张长得一样）

| # | 主题 | 底部地景 |
|---|---|---|
| 01 | 初雪月夜（最接近原图的保守版） | 雪人 + 热可可 + 礼物 |
| 02 | 圣诞夜 | 小圣诞树 + 礼物盒 + 姜饼 |
| 03 | 极光冰湖 | 结冰湖面 + 长椅 + 小灯笼 |
| 04 | 初雪森林 | 雪压白桦/松树框住两侧 + 小雪人 |
| 05 | 雪国小村 | 雪顶小屋 + 暖光窗 + 烟囱炊烟（**不加画框**） |
| 06 | 温泉雪景 | 冒热气的水面 + 雪石 + 小木桶 |
| 07 | 流星夜 | 雪原 + 雪人 + 灯笼 |
| 08 | 企鹅戏雪 | 半成品雪人 + 手套 + 企鹅 |
| 09 | 暖灯雪径 | 蜿蜒雪路 + 纸灯笼 + 光点 |
| 10 | 驯鹿雪原 | 小雪人 + 小驯鹿 + 粉云 |

> 别做"霜花边框/窗框"这类整张加框的构图：一加框就和其余 9 张不是一套了。

换季时把表里的地景换成当季等价物（春：花丛/樱花/风筝；夏：西瓜/萤火虫/海边；秋：南瓜/枫叶/稻草人），
天空层同理（春：花瓣；夏：晚霞/星轨；秋：落叶）。**01 号永远是"最保守版"**，用来确认基线。

### 3. 尺寸把关：以原图的真实像素比例为准，不套"标准 9:16"

**先 `identify` 原图，把原始尺寸当成唯一标准**（例：原图 1080×2340 = 9:19.5，比 9:16 更细长；
若套成 9:16 就等于给用户裁掉一截，用户会立刻看出来"比例不对"）。把这个数字写进 prompt 第一段：
`Output canvas exactly 1080 x 2340 (9:19.5), same tall narrow frame as the reference; no crop, no letterbox, no padding.`

- 模型常出的尺寸：704×1520 / 768×1376 / 848×1264。前两种只是分辨率不同、比例接近，**直接放行**。
- 生成后统一归一到原图尺寸，比例硬对齐：
  `convert in.jpg -resize 1080x2340^ -gravity center -extent 1080x2340 -quality 95 out.jpg`
  （`^` 是最小覆盖式等比缩放 + 居中裁切，短边先撞线，因此只裁掉极窄的两侧，人物和人脸不动；
  **绝不**用 `!` 强制拉伸，那会把角色压扁。）
- 一张图如果有多种尺寸，用户会认为"没对齐"：**整批必须同一个像素尺寸**，不只看比例。
- 只有"人物被裁到边缘"或"横版/方形"才需要重新生成，其余一律靠归一化解决，省生成额度。

**原图自带黑边就先检查**：参考图底部若有一条黑色像素行，编辑模型会把它当构图一部分抄进结果。
prompt 里明写 `the reference has a thin black strip along its bottom edge — do not copy it`，
生成后可用下面一行自查（输出接近 0 就是黑边）：
`convert f.jpg -crop 1x1+300+$((h-1)) -format '%[fx:int(255*r)]' info:`

### 4. 交付

- **每一轮新建一个子文件夹**，命名带季节和轮次：`冬天版壁纸 Winter Round 2`，不覆盖上一轮。
- 文件名带轮次前缀，跨文件夹也不混：`winter-r2-01-snow-night.jpg` … 语义化后缀，序号决定排序。
- 每个子文件夹里都放一张总图 `00-总图-第N轮.jpg`（原图在最前，后面 10 张按序），便于一眼挑；
  原图副本 `00-halloween-original-reference.jpg` 也留一份，日后对照用。
- 不打包 zip，用户要的是文件夹本身。上传前用 `identify` 或浏览器预览确认总图是完整网格，
  **不要**在拼图后追加图片——重拼一次再上传，避免云端版本缺行。
- 交付话术里点明：角色/文字保持不变、每张的差异点、如果某张角色走样可以指定重做哪一张。

## prompt 模板

见 `references/prompt-template.md`（英文，直接填空）。英文 prompt 对图像模型的"锁定能力"明显更好，
即使和用户用中文沟通，prompt 也建议用英文。

## 验收清单

生成后逐张过 `references/character-lock-checklist.md`。任何一项不通过就只重做那一张，不要整批重来。

## 常见翻车

- **加了圣诞帽/围巾**：最常见。重做，并把禁用清单写在 prompt 最前面。
- **原南瓜还在**：模型只加雪不删道具。必须写 `Remove all bats` / `replace the pumpkins ... with ...` 这种
  显式的"删+换"指令，逐个点名原图里的季节道具。
- **中间留白被填满**：追加 `keep the same amount of empty space in the middle`，否则壁纸没法放图标。
- **文字被重绘变形**：重做；prompt 里把文字单独列为 `KEEP ... lettering and underline exactly as is (position,
  color, size)`。
- **越改越糊**：底稿永远是原图，不是上一轮输出。
- **每轮张数上限**：图像生成有单轮上限（10 次）。**一轮 = 10 次调用，一旦拿一次去校准/重做，这一轮就凑不齐 10 张**
  （实际踩过：先重做了 01，第 10 张被限额挡住）。所以顺序是：先想清楚→一次性发完 10 张→用后处理修尺寸/比例，
  把重新生成留到下一轮。若已经撞上限，就先把 9 张交付并明确说明第 10 张下一轮补，不要假装齐了。
- **总图缺行**：拼图之后又追加了图片、或用旧的拼接命令重跑，导致云端总图少最后一行。重拼一次再上传，
  上传前用 `identify -format '%wx%h'` 看一眼高度是否够。
