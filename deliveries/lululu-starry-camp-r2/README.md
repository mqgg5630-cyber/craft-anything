# 星空露营第二辑 · 10张

沿用原帖五张已通过 GitHub Actions 下载并校验的参考图，每张均直接使用 `../lululu-sunset-new/source/04.webp` 和另一张原片作为参考，以保持两位角色、脸部比例、橙子帽、西瓜短裤和草莓裙及蕾丝帽一致。10 张是独立 AI 生成的同角色新场景；局部面容、服饰花纹和比例仍有生成差异，不能保证逐像素或模型级完全一致。

`images/` 是 10 张无 UI 壁纸，`ui/` 是对应的 10 张静态模拟锁屏（非实机截图），两张 `00-...总预览.jpg` 仅用于预览。所有图片为生成原生尺寸；尺寸、哈希与逐张原片映射在 `output-manifest.json`。原片是公开 CDN 图，不保证是作者无损母版。

本地图片解码及唯一性通过，参考原图 SHA-256 校验通过；Google Drive 重新列目录并核对 22 个文件的 MD5，见 `cloud-verification.json`。
