## 3. 尺寸与文字：明确区分原生和交付

原片像素固定为 **884×1851**，不是泛指9:16，也不是前一篇锦鲤的尺寸。

- 生图模型实际输出：01—09均704×1504，10为704×1474。
- 为满足用户“按照原图大小”，使用一次**等比Lanczos缩放＋极少量居中裁切**适配到884×1851，不做横纵非等比拉伸，不对叶片、果碗和字形压扁拉长。
- 这涉及插值放大，不能称884×1851为模型原生分辨率，也不宣称增加原生细节。每张原生尺寸、等比缩放系数、缩放后连续尺寸和目标尺寸逐项记录在 `output-manifest.json`。
- 在完成尺寸适配后排字，因此10张字形比例与字号保持一致，不再缩放文字。
- 使用开源 **Ma Shan Zheng（马善政）书法字体**，76px，左侧竖排4字、统一字距，墨色文字与一点朱红方形点缀；朱红点不是伪造作者印章，没有添加任何假作者署名。
- 字体来自 `google/fonts` 仓库 `ofl/mashanzheng`，字体blob `11bbfb9867d70612158229d037e7a5f622bd0e38`，随附OFL许可在 `assets/fonts/cjk/OFL-MaShanZheng.txt`。
- 所有文字由本地真实中文字形绘制，不依赖模型拼写；原片本身文字不改，AI背景未带入原片原有书法或印章。
