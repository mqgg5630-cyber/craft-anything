# 2. 白天能一起做的六件事

[← 回总目录](../README.md)

这一章六个玩法，全部只需要一张床、一张桌和一部手机。每个都给了三个变体，挑你们不讨厌的那个。

### 2.1 桌游与扑克：一副牌能玩两小时

- 情况：什么都没带，房间只有电视。
- 判断：一副扑克至少能玩十种两人游戏：钓鱼、21 点、接龙对抗、抽鬼牌、记忆翻牌。没有牌就用手机记事本画井字棋。
- 原话：「我们玩抽鬼牌，输的人回答一个问题，或者明天去买早饭。」
- 回应：
  - 「太幼稚」→ 「幼稚的游戏才笑得出来。」
  - 「我总输」→ 「那换个运气成分大的。」
- 接着做：一局定规则，三局定输赢，赌注选「小事」不选「钱」。
- 做对了：两个人笑得像小孩。
- 红线：不要用游戏赌钱、赌亲密行为。
- 依据：C。规则简单的共同游戏最适合陌生空间。
- 来源：S01、S13
- 相关：2.3、4.5

### 2.2 电影马拉松：一部片子加一场讨论

- 情况：打开电视随便刷，刷到半夜什么都没看进去。
- 判断：选片两个人各提一部，轮着看；每次只看一部，看完聊十分钟。比连刷五部有记忆点。
- 原话：「一人选一部，先看你的。看完谁都不许吐槽，先说自己最喜欢的一场戏。」
- 回应：
  - 「我不想看你那部」→ 「那换类型，喜剧或悬疑你挑。」
  - 「看着看着睡着了」→ 「睡着也算过完了，明天继续。」
- 接着做：提前把零食、水、毯子备好，中途不起身。
- 做对了：看完有话说，而不是看完就忘。
- 红线：不要边看边刷手机评论剧情。
- 依据：B。共同观赏后的讨论能提高关系中的共享意义。
- 来源：S01、S13
- 相关：4.1、1.6

### 2.3 互相采访：二十个问题

- 情况：聊到没话说，气氛开始尴尬。
- 判断：问题要从「具体经历」开始，不要从「你觉得我怎么样」开始。后者会变成考试。
- 原话：「我问十个你问十个。第一个：你小时候最想干但现在干不了的事是什么。」
- 回应：
  - 「太正式了」→ 「那就一人问一个，轮流来。」
  - 「我不想聊小时候」→ 「那换：最近一次觉得自己厉害是什么时候。」
- 接着做：每人准备十个问题，写在备忘录里，不许问「你爱不爱我」。
- 做对了：听到了没听过的事。
- 红线：不要借问题审问对方的前任或过去。
- 依据：C。渐进式自我暴露能提升亲密感。
- 来源：S02、S13
- 相关：4.5、2.4

### 2.4 一起写一封给一年后的信

- 情况：想留下点东西，又不想只是拍照片。
- 判断：两个人各写一封，封好，约定一年后同一天拆。写三件事：现在的日子、担心的事、希望一年后怎样。
- 原话：「我们各写一封，写完互相不看，封起来，明年今天一起拆。」
- 回应：
  - 「写不出来」→ 「写三行也行，不求文采。」
  - 「万一分手了」→ 「那也留着，是那天的你。」
- 接着做：用酒店信纸或便签，写好封进信封，各自保管。
- 做对了：这一晚有了时间跨度。
- 红线：不要偷看对方那封。
- 依据：C。仪式性书写能固定共同记忆。
- 来源：S13、S01
- 相关：2.3、4.6

### 2.5 房间里的运动会：拉伸与摔跤

- 情况：坐了一天，两个人都僵。
- 判断：狭小空间适合三件事：双人拉伸、枕头大战、跟着视频做十分钟操。注意别撞到家具。
- 原话：「我们跟着视频做十分钟拉伸，谁先笑谁输。」
- 回应：
  - 「我不想动」→ 「那你躺着，我给你拉腿。」
  - 「会吵到隔壁」→ 「那小声点，只做地面动作。」
- 接着做：把地上清空，鞋子收起来，控制在十分钟。
- 做对了：身体松了，气氛也松了。
- 红线：不要在房间做有摔倒风险的动作，不要在床上跳。
- 依据：C。轻度共同活动能改善情绪与互动。
- 来源：S13、S06
- 相关：3.2、2.6

### 2.6 拍一支十五秒的短片

- 情况：想记录，但拍照已经拍腻了。
- 判断：十五秒短片比九宫格更有记忆点：一个动作、一个转场、一句台词就够。
- 原话：「我们拍一个十五秒的：你开门、我递水、然后我们一起倒床上。一遍过。」
- 回应：
  - 「我不会演」→ 「不用演，就做你平时会做的。」
  - 「发出去吗」→ 「先拍，发不发回头再说。」
- 接着做：定一个镜头、一个动作，最多拍三遍。
- 做对了：拍完两个人都笑了。
- 红线：不拍私密画面，不把对方不雅的镜头留着。
- 依据：A。影像涉及肖像与隐私，需双方同意。
- 来源：S03、S04
- 相关：3.5、4.6
