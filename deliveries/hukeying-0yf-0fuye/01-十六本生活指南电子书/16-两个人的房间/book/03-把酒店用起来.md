# 3. 把酒店用起来

[← 回总目录](../README.md)

房费里已经包含的东西，不用就浪费了。这一章讲酒店里那些免费或已付费的资源。

### 3.1 泳池：最容易浪费的一项

- 情况：住了两晚，直到退房才想起有泳池。
- 判断：泳池的价值在「一起做一件不熟练的事」。带泳衣、问清水温与开放时间。
- 原话：「泳池开到十点，我们八点去，人少。你不想游就泡着。」
- 回应：
  - 「我没带泳衣」→ 「楼下有卖，或者我陪你坐着。」
  - 「我不会游」→ 「浅水区站着就行。」
- 接着做：出发前查开放时间，带泳衣与拖鞋。
- 做对了：没有因为「没准备」而错过。
- 红线：不要在无救生员的时段下水，不要酒后游泳。
- 依据：A。泳池安全提示与救生要求是公开规定。
- 来源：S04、S13
- 相关：3.2、3.3

### 3.2 健身房：二十分钟的约定

- 情况：健身房就在楼下，谁都不想去。
- 判断：把门槛降到二十分钟：各做各的，一起开始一起结束。比「练一小时」现实。
- 原话：「下去二十分钟，你跑步我拉伸，然后一起上来洗澡。」
- 回应：
  - 「我累了」→ 「那就走十分钟，算完成。」
  - 「我不会用器械」→ 「只用跑步机和垫子。」
- 接着做：定二十分钟，带一条毛巾。
- 做对了：动过，但不累到影响晚上。
- 红线：不要互相指导对方的动作，容易变成指手画脚。
- 依据：C。低门槛的共同活动更容易持续。
- 来源：S13、S06
- 相关：2.5、3.1

### 3.3 早餐与下午茶：把时间花在慢上

- 情况：早餐随便扒两口就出门。
- 判断：自助早餐是酒店最值的一项。规则很简单：一次拿少、多走两趟、坐着吃完。
- 原话：「我们九点半下去，慢慢吃，吃到十点半，上午就不安排别的了。」
- 回应：
  - 「浪费时间」→ 「早餐就是拿来浪费的。」
  - 「人太多」→ 「那错峰，八点或十点。」
- 接着做：先看一圈再拿，热食最后拿。
- 做对了：吃到了想吃的，也没剩一堆。
- 红线：不要打包带走自助餐食物。
- 依据：C。错峰与少量多次能提高用餐体验。
- 来源：S13、S05
- 相关：5.3、3.4

### 3.4 大堂与公共空间怎么用

- 情况：房间待腻了，又不想出门。
- 判断：大堂、书吧、露台是「换场景」最便宜的方式：不用花钱，十分钟就能换个心情。
- 原话：「我们下去大堂坐二十分钟，换个地方说话，再上来。」
- 回应：
  - 「有什么好坐的」→ 「换个场景，话就好说了。」
  - 「有人看」→ 「坐角落就行。」
- 接着做：找一个人少的位置，待十五到二十分钟。
- 做对了：小矛盾在换场景后自然降温。
- 红线：不要穿浴袍、拖鞋进大堂等公共区域。
- 依据：C。场景切换有助于情绪降温。
- 来源：S06、S13
- 相关：6.3、1.2

### 3.5 窗边发呆与看街

- 情况：窗外有夜景，你们在刷手机。
- 判断：窗边是房间里最好的位置。定一个「只看外面不说话」的五分钟。
- 原话：「我们关灯，坐窗边看五分钟，谁都不说话。」
- 回应：
  - 「有什么好看的」→ 「看车流也行。」
  - 「我想说话」→ 「那你说，我听着。」
- 接着做：关掉房间主灯，只留窗外光。
- 做对了：安静了五分钟，没有尴尬。
- 红线：不要对着窗外居民楼拍照。
- 依据：C。共同静默能降低互动压力。
- 来源：S13、S01
- 相关：4.4、2.6

### 3.6 洗衣、熨衣与收拾

- 情况：衣服堆了一天，第二天没得穿。
- 判断：把收拾变成合作任务：一个洗、一个晾，十分钟完成，第二天省事。
- 原话：「我洗，你晾，十分钟搞定，明天就不用赶着洗。」
- 回应：
  - 「我不想动」→ 「那你只负责晾。」
  - 「拿回家洗」→ 「湿的带回去更麻烦。」
- 接着做：分两工，设十分钟计时。
- 做对了：第二天早上不慌。
- 红线：不要用酒店毛巾擦鞋、擦化妆品。
- 依据：C。旅行中的分工协作能减少摩擦。
- 来源：S13、S05
- 相关：7.6、1.3
