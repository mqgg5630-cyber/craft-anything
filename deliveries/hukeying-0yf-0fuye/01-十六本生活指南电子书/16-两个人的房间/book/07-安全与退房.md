# 7. 安全、合规与退房

[← 回总目录](../README.md)

房间私密，但门外面是公共空间。这一章讲六件必须做的事。

### 7.1 登记与访客

- 情况：想让朋友上来坐坐，或者她晚到没登记。
- 判断：住宿要按酒店要求登记实际入住人。访客按酒店规定，通常需要登记且有时限。
- 原话：「访客要去前台登记一下，酒店有规定，我们配合一下。」
- 回应：
  - 「这么麻烦」→ 「登记两分钟，省得被查。」
  - 「就坐一会儿」→ 「那也得登。」
- 接着做：提前问前台访客政策，按规定办。
- 做对了：不给前台和你们自己找麻烦。
- 红线：不要让未登记的人留宿；不要用他人身份登记。
- 依据：A。住宿实名登记是法定要求。
- 来源：S04、S07
- 相关：7.4、7.6

### 7.2 检查偷拍设备

- 情况：不确定房间里有没有摄像头。
- 判断：重点看正对床与浴室的位置：烟雾报警器、插座、路由器、闹钟、装饰摆件。关灯用手机相机扫一圈看有无红点，只是辅助手段。
- 原话：「我先看一下烟雾报警器和插座，两分钟。」
- 回应：
  - 「你想多了」→ 「看一眼，睡得踏实。」
  - 「真发现怎么办」→ 「立刻换房并报警。」
- 接着做：关灯、拉窗帘，重点检查三个位置；发现可疑就换房并报警 110。
- 做对了：隐私有基本保障。
- 红线：不要自行拆卸设备，保留现场并报警。
- 依据：A。偷拍涉嫌违法，可报警处理。
- 来源：S03、S04
- 相关：6.4、7.4

### 7.3 消防与逃生

- 情况：住了两晚，从没看过门后的逃生图。
- 判断：进门看三样：最近的安全出口、疏散方向、能不能走通。夜间把钥匙和手机放在固定位置。
- 原话：「逃生图在这儿，出口在走廊尽头左转，我们记一下。」
- 回应：
  - 「不会出事」→ 「记一下不费事。」
  - 「太吓人」→ 「知道了才不吓人。」
- 接着做：走一遍到安全出口的路，记步数。
- 做对了：真有事时不用找方向。
- 红线：不遮挡烟感、不堵塞通道、不在房间用明火。
- 依据：A。消防通道与烟感是法定要求。
- 来源：S04、S06
- 相关：1.3、7.5

### 7.4 陌生人敲门

- 情况：深夜有人敲门说「送东西」。
- 判断：先确认身份再开门。通过猫眼、内线电话或前台核实，不要让陌生人进房间。
- 原话：「东西放门口就行，我一会儿拿。」
- 回应：
  - 「你开门啊」→ 「放门口，谢谢。」
  - 「是前台让我送的」→ 「我打个电话确认一下。」
- 接着做：挂上门链再开门缝取物；可疑就通知前台。
- 做对了：没有任何人被迫开门。
- 红线：不要让陌生人进房间，不要跟着陌生人去「另一个房间」。
- 依据：A。住店安全提示普遍要求核实访客身份。
- 来源：S04、S07
- 相关：7.1、7.2

### 7.5 损坏与赔偿

- 情况：不小心把杯子打碎了，或者弄脏了床单。
- 判断：主动说，比被查出来便宜。多数酒店按成本收，隐瞒可能按更严的条款处理。
- 原话：「刚才我不小心打碎了一个杯子，我跟你报一下，怎么处理我配合。」
- 回应：
  - 「会不会罚很多」→ 「按价赔，比藏着好。」
  - 「不说算了」→ 「退房查出来更麻烦。」
- 接着做：拍一张照片留底，到前台说明并留凭据。
- 做对了：事情在小范围内解决。
- 红线：不要用毛巾擦鞋、擦化妆品、擦污渍。
- 依据：C。住宿合同中的物品损坏一般按约定赔偿。
- 来源：S05、S13
- 相关：5.4、7.6

### 7.6 退房与评价

- 情况：赶时间，东西落下了。
- 判断：退房前走三步：看抽屉与床头、看充电器与浴室、拍照留房态。
- 原话：「走之前我看一圈：抽屉、床头、充电器、浴室，你再看一遍。」
- 回应：
  - 「不会落」→ 「两分钟，落了更麻烦。」
  - 「落了怎么办」→ 「打电话给前台，多数能寄回。」
- 接着做：两人分头检查，一人看一半；离店后写一句真实评价。
- 做对了：没落下东西，也没留下烂摊子。
- 红线：不要把酒店用品、毛巾带走。
- 依据：C。物品清点与房态记录能减少纠纷。
- 来源：S05、S13
- 相关：7.5、1.3
