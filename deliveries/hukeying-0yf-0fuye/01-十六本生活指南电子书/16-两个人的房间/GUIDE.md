# 0. 导言：房间本身就是目的地


出去玩最容易忽略的一段，是回到房间以后那几个小时。很多人这时候只会刷手机，然后觉得「有点无聊」。其实酒店房间是很少有的空间：没有家务、没有外人、不用赶时间。会过的人，能在这里过出一天。

这本书给四十二个具体做法：能一起玩什么、怎么把房间用起来、吃什么、怎么定规则、哪些线不能越、退房前要检查什么。

## 读完能做到

- 一进门十分钟内把房间变成「你们的房间」。
- 说得出至少十件在房间里就能一起做的事，不用临时想。
- 把酒店的公共资源用起来：泳池、健身房、早餐、大堂。
- 定下三条相处规则：独处、作息、噪声。
- 把「不想」说得出口，也听得懂对方的「不想」。
- 知道怎么检查偷拍设备、走消防通道、退房不落东西。

## 四条底线

1. 亲密行为要明确同意，任何时候都可以喊停；「没拒绝」不等于同意。
2. 不拍摄、不传播对方的私密影像，也不要求对方拍。
3. 不给陌生人开门，不让未登记的人留宿，不遮挡烟感、不堵塞消防通道。
4. 不损坏酒店物品、不在禁烟房抽烟、不在深夜大声喧闹影响邻房。

## 这本书不做什么

- 不写露骨内容。这本书讲的是「怎么把时间过好」，不是情色指南。
- 不推荐具体酒店与房型。房型差异太大，书只给判断方法。
- 不替你做亲密关系的决定。第六章只讲同意、边界与照顾。
- 不承诺「按这个清单就能不无聊」。无聊是正常的，书给的是备选。

## 证据分级

- A：法律与官方规定可查：住宿登记、消防、隐私与影像。
- B：有成体系研究支撑：亲密关系中的共同活动、休息与睡眠、决策负担。
- C：实务与经验归纳：房间玩法、点餐、收拾与退房的具体做法。
- D：本书编写情境与话术：所有「原话」与具体场景。

## 怎么读

# 1. 把房间当成目的地


一进门的那十分钟，决定了这一晚是「将就睡一觉」还是「两个人过一天」。这一章先把房间变成你们的地方。

### 1.1 待在房间不算浪费

- 情况：你觉得不出门就是白来一趟。
- 判断：酒店房间是这趟行程里唯一不需要赶路的地方。在这里待着，是消费它，不是浪费它。
- 原话：「今天下午不出去了，我们就在房间待着，想干嘛干嘛。」
- 回应：
  - 「那多没意思」→ 「没意思我们就找点事做，慢慢来。」
  - 「你不怕无聊」→ 「无聊一会儿也挺好。」
- 接着做：把「待在房间」写进行程，标上时间。
- 做对了：不出门不需要理由。
- 红线：不要用「陪你」的姿态待在房间，那会变成一种施舍。
- 依据：B。共同进行的低强度活动与关系满意度正相关。
- 来源：S01、S13
- 相关：1.2、2.1

### 1.2 一天的时间骨架

- 情况：两个人在房间里从下午坐到天黑，什么都没做。
- 判断：房间也需要骨架：动一段、静一段、吃一顿、聊一段。有骨架才不会滑成刷手机。
- 原话：「下午两点到四点是活动时间，四点到五点半各干各的，六点吃饭，晚上再聊。」
- 回应：
  - 「像上课一样」→ 「有课表才不至于两小时都在滑手机。」
  - 「太刻意了」→ 「就定两个时间点，其他随便。」
- 接着做：只定「活动开始」和「吃饭」两个时间，其余留白。
- 做对了：一天有形状，但没变成任务。
- 红线：不要把时间表精确到每半小时。
- 依据：C。轻结构比无结构更容易产出共同体验。
- 来源：S13、S01
- 相关：1.1、2.6

### 1.3 进门十分钟：检查与布置

- 情况：进门就躺床上刷手机。
- 判断：十分钟做四件事：看逃生图、检查门锁、拉窗帘看窗外、把行李摊开。之后才是布置。
- 原话：「先看一下门锁和消防图，然后把灯调暖一点，桌子清出来放吃的。」
- 回应：
  - 「你这么谨慎」→ 「两分钟的事，睡得踏实。」
  - 「别查了」→ 「查完就放松。」
- 接着做：门口、窗、桌、卫生间各看一眼，再开始布置。
- 做对了：房间先是安全的，再是舒服的。
- 红线：不要跳过消防通道位置这一步。
- 依据：A。住店安全提示与消防要求是公开规定。
- 来源：S04、S13
- 相关：7.2、7.3

### 1.4 灯光、音乐与温度

- 情况：房间的顶灯白得刺眼，空调直吹床头。
- 判断：三个开关决定房间气氛：主灯关掉用台灯、音乐音量调到能说话、空调风向调开。
- 原话：「我们关大灯开台灯，放点轻的，空调风向往上打。」
- 回应：
  - 「太暗了」→ 「那留一盏，够看书就行。」
  - 「我不听歌」→ 「那放我这边小声，你听不见。」
- 接着做：先调温度，再调光，最后放音乐。
- 做对了：房间里能放松说话。
- 红线：不要把音量开到影响隔壁。
- 依据：C。环境光与噪声直接影响对话与睡眠质量。
- 来源：S13、S06
- 相关：1.5、4.6

### 1.5 零食饮料的采购清单

- 情况：晚上十点想吃东西，只能叫高价客房服务。
- 判断：入住当天买一批基础补给：水、水果、坚果、酸奶、纸巾、湿巾。花费不到餐厅一顿。
- 原话：「楼下便利店我买了水、水果和一包湿巾，晚上饿不着。」
- 回应：
  - 「你像搬家」→ 「省得半夜出门。」
  - 「酒店有」→ 「有，但贵三倍。」
- 接着做：按「喝、嚼、擦、装垃圾」四类各买一样。
- 做对了：房间里随时有得吃、有得收拾。
- 红线：不要买需要加热、气味大的食物。
- 依据：C。补给准备降低夜间决策成本。
- 来源：S13、S05
- 相关：5.2、5.4

### 1.6 手机放下的规则

- 情况：两个人都躺在床上，各刷各的。
- 判断：不需要戒手机，只需要一个「都不看」的时段。
- 原话：「九点到十点我们把手机放桌上，谁都不看，就聊天或者看个片。」
- 回应：
  - 「万一有人找」→ 「一小时而已，有事会再打。」
  - 「你管我」→ 「是约定，不是管制，你也可以定时间。」
- 接着做：定一个一小时的无手机时段，手机放到够不着的地方。
- 做对了：这一小时里对方是唯一的屏幕。
- 红线：不要偷偷看对方手机。
- 依据：C。设备在场的分心会降低对话质量。
- 来源：S01、S13
- 相关：2.2、4.5

# 2. 白天能一起做的六件事


这一章六个玩法，全部只需要一张床、一张桌和一部手机。每个都给了三个变体，挑你们不讨厌的那个。

### 2.1 桌游与扑克：一副牌能玩两小时

- 情况：什么都没带，房间只有电视。
- 判断：一副扑克至少能玩十种两人游戏：钓鱼、21 点、接龙对抗、抽鬼牌、记忆翻牌。没有牌就用手机记事本画井字棋。
- 原话：「我们玩抽鬼牌，输的人回答一个问题，或者明天去买早饭。」
- 回应：
  - 「太幼稚」→ 「幼稚的游戏才笑得出来。」
  - 「我总输」→ 「那换个运气成分大的。」
- 接着做：一局定规则，三局定输赢，赌注选「小事」不选「钱」。
- 做对了：两个人笑得像小孩。
- 红线：不要用游戏赌钱、赌亲密行为。
- 依据：C。规则简单的共同游戏最适合陌生空间。
- 来源：S01、S13
- 相关：2.3、4.5

### 2.2 电影马拉松：一部片子加一场讨论

- 情况：打开电视随便刷，刷到半夜什么都没看进去。
- 判断：选片两个人各提一部，轮着看；每次只看一部，看完聊十分钟。比连刷五部有记忆点。
- 原话：「一人选一部，先看你的。看完谁都不许吐槽，先说自己最喜欢的一场戏。」
- 回应：
  - 「我不想看你那部」→ 「那换类型，喜剧或悬疑你挑。」
  - 「看着看着睡着了」→ 「睡着也算过完了，明天继续。」
- 接着做：提前把零食、水、毯子备好，中途不起身。
- 做对了：看完有话说，而不是看完就忘。
- 红线：不要边看边刷手机评论剧情。
- 依据：B。共同观赏后的讨论能提高关系中的共享意义。
- 来源：S01、S13
- 相关：4.1、1.6

### 2.3 互相采访：二十个问题

- 情况：聊到没话说，气氛开始尴尬。
- 判断：问题要从「具体经历」开始，不要从「你觉得我怎么样」开始。后者会变成考试。
- 原话：「我问十个你问十个。第一个：你小时候最想干但现在干不了的事是什么。」
- 回应：
  - 「太正式了」→ 「那就一人问一个，轮流来。」
  - 「我不想聊小时候」→ 「那换：最近一次觉得自己厉害是什么时候。」
- 接着做：每人准备十个问题，写在备忘录里，不许问「你爱不爱我」。
- 做对了：听到了没听过的事。
- 红线：不要借问题审问对方的前任或过去。
- 依据：C。渐进式自我暴露能提升亲密感。
- 来源：S02、S13
- 相关：4.5、2.4

### 2.4 一起写一封给一年后的信

- 情况：想留下点东西，又不想只是拍照片。
- 判断：两个人各写一封，封好，约定一年后同一天拆。写三件事：现在的日子、担心的事、希望一年后怎样。
- 原话：「我们各写一封，写完互相不看，封起来，明年今天一起拆。」
- 回应：
  - 「写不出来」→ 「写三行也行，不求文采。」
  - 「万一分手了」→ 「那也留着，是那天的你。」
- 接着做：用酒店信纸或便签，写好封进信封，各自保管。
- 做对了：这一晚有了时间跨度。
- 红线：不要偷看对方那封。
- 依据：C。仪式性书写能固定共同记忆。
- 来源：S13、S01
- 相关：2.3、4.6

### 2.5 房间里的运动会：拉伸与摔跤

- 情况：坐了一天，两个人都僵。
- 判断：狭小空间适合三件事：双人拉伸、枕头大战、跟着视频做十分钟操。注意别撞到家具。
- 原话：「我们跟着视频做十分钟拉伸，谁先笑谁输。」
- 回应：
  - 「我不想动」→ 「那你躺着，我给你拉腿。」
  - 「会吵到隔壁」→ 「那小声点，只做地面动作。」
- 接着做：把地上清空，鞋子收起来，控制在十分钟。
- 做对了：身体松了，气氛也松了。
- 红线：不要在房间做有摔倒风险的动作，不要在床上跳。
- 依据：C。轻度共同活动能改善情绪与互动。
- 来源：S13、S06
- 相关：3.2、2.6

### 2.6 拍一支十五秒的短片

- 情况：想记录，但拍照已经拍腻了。
- 判断：十五秒短片比九宫格更有记忆点：一个动作、一个转场、一句台词就够。
- 原话：「我们拍一个十五秒的：你开门、我递水、然后我们一起倒床上。一遍过。」
- 回应：
  - 「我不会演」→ 「不用演，就做你平时会做的。」
  - 「发出去吗」→ 「先拍，发不发回头再说。」
- 接着做：定一个镜头、一个动作，最多拍三遍。
- 做对了：拍完两个人都笑了。
- 红线：不拍私密画面，不把对方不雅的镜头留着。
- 依据：A。影像涉及肖像与隐私，需双方同意。
- 来源：S03、S04
- 相关：3.5、4.6

# 3. 把酒店用起来


房费里已经包含的东西，不用就浪费了。这一章讲酒店里那些免费或已付费的资源。

### 3.1 泳池：最容易浪费的一项

- 情况：住了两晚，直到退房才想起有泳池。
- 判断：泳池的价值在「一起做一件不熟练的事」。带泳衣、问清水温与开放时间。
- 原话：「泳池开到十点，我们八点去，人少。你不想游就泡着。」
- 回应：
  - 「我没带泳衣」→ 「楼下有卖，或者我陪你坐着。」
  - 「我不会游」→ 「浅水区站着就行。」
- 接着做：出发前查开放时间，带泳衣与拖鞋。
- 做对了：没有因为「没准备」而错过。
- 红线：不要在无救生员的时段下水，不要酒后游泳。
- 依据：A。泳池安全提示与救生要求是公开规定。
- 来源：S04、S13
- 相关：3.2、3.3

### 3.2 健身房：二十分钟的约定

- 情况：健身房就在楼下，谁都不想去。
- 判断：把门槛降到二十分钟：各做各的，一起开始一起结束。比「练一小时」现实。
- 原话：「下去二十分钟，你跑步我拉伸，然后一起上来洗澡。」
- 回应：
  - 「我累了」→ 「那就走十分钟，算完成。」
  - 「我不会用器械」→ 「只用跑步机和垫子。」
- 接着做：定二十分钟，带一条毛巾。
- 做对了：动过，但不累到影响晚上。
- 红线：不要互相指导对方的动作，容易变成指手画脚。
- 依据：C。低门槛的共同活动更容易持续。
- 来源：S13、S06
- 相关：2.5、3.1

### 3.3 早餐与下午茶：把时间花在慢上

- 情况：早餐随便扒两口就出门。
- 判断：自助早餐是酒店最值的一项。规则很简单：一次拿少、多走两趟、坐着吃完。
- 原话：「我们九点半下去，慢慢吃，吃到十点半，上午就不安排别的了。」
- 回应：
  - 「浪费时间」→ 「早餐就是拿来浪费的。」
  - 「人太多」→ 「那错峰，八点或十点。」
- 接着做：先看一圈再拿，热食最后拿。
- 做对了：吃到了想吃的，也没剩一堆。
- 红线：不要打包带走自助餐食物。
- 依据：C。错峰与少量多次能提高用餐体验。
- 来源：S13、S05
- 相关：5.3、3.4

### 3.4 大堂与公共空间怎么用

- 情况：房间待腻了，又不想出门。
- 判断：大堂、书吧、露台是「换场景」最便宜的方式：不用花钱，十分钟就能换个心情。
- 原话：「我们下去大堂坐二十分钟，换个地方说话，再上来。」
- 回应：
  - 「有什么好坐的」→ 「换个场景，话就好说了。」
  - 「有人看」→ 「坐角落就行。」
- 接着做：找一个人少的位置，待十五到二十分钟。
- 做对了：小矛盾在换场景后自然降温。
- 红线：不要穿浴袍、拖鞋进大堂等公共区域。
- 依据：C。场景切换有助于情绪降温。
- 来源：S06、S13
- 相关：6.3、1.2

### 3.5 窗边发呆与看街

- 情况：窗外有夜景，你们在刷手机。
- 判断：窗边是房间里最好的位置。定一个「只看外面不说话」的五分钟。
- 原话：「我们关灯，坐窗边看五分钟，谁都不说话。」
- 回应：
  - 「有什么好看的」→ 「看车流也行。」
  - 「我想说话」→ 「那你说，我听着。」
- 接着做：关掉房间主灯，只留窗外光。
- 做对了：安静了五分钟，没有尴尬。
- 红线：不要对着窗外居民楼拍照。
- 依据：C。共同静默能降低互动压力。
- 来源：S13、S01
- 相关：4.4、2.6

### 3.6 洗衣、熨衣与收拾

- 情况：衣服堆了一天，第二天没得穿。
- 判断：把收拾变成合作任务：一个洗、一个晾，十分钟完成，第二天省事。
- 原话：「我洗，你晾，十分钟搞定，明天就不用赶着洗。」
- 回应：
  - 「我不想动」→ 「那你只负责晾。」
  - 「拿回家洗」→ 「湿的带回去更麻烦。」
- 接着做：分两工，设十分钟计时。
- 做对了：第二天早上不慌。
- 红线：不要用酒店毛巾擦鞋、擦化妆品。
- 依据：C。旅行中的分工协作能减少摩擦。
- 来源：S13、S05
- 相关：7.6、1.3

# 4. 晚上能一起做的六件事


晚上的房间容易滑向两种结局：各自刷手机，或者因为太累而吵架。这一章给六个把晚上接住的办法。

### 4.1 夜宵仪式

- 情况：晚上十点，两个人都想吃点东西。
- 判断：夜宵的重点不是吃什么，是「一起」：一起点、一起吃、一起收拾。三十分钟就够。
- 原话：「十点我们点一份夜宵，吃完一起收拾，然后刷牙睡觉。」
- 回应：
  - 「会胖」→ 「今天就一次，明天多走两站。」
  - 「我不想吃」→ 「那你陪我坐着，我吃。」
- 接着做：定一个时间、一份量、一个人收拾一个人擦桌。
- 做对了：夜宵是仪式，不是失控。
- 红线：不要在房间吃气味重、汤水多的东西。
- 依据：C。共同的小仪式能提高日常联结感。
- 来源：S01、S13
- 相关：5.2、5.4

### 4.2 泡澡的边界

- 情况：房间有大浴缸，你想一起泡。
- 判断：浴缸涉及身体与卫生，需要明确同意，也要先确认清洁与水温。对方犹豫就是不。
- 原话：「浴缸你想一起泡吗？不想就各泡各的，我去冲一下。」
- 回应：
  - 「有点害羞」→ 「那我们分开，你先来。」
  - 「不干净吧」→ 「我先冲一遍再用。」
- 接着做：先确认清洁，再把水温调到偏温，时间控制在十五分钟。
- 做对了：两个人都自愿，且没有勉强。
- 红线：不要在对方没明确同意时进入；饮酒后不泡热水澡。
- 依据：A。身体接触与性行为需明确同意。
- 来源：S03、S04
- 相关：6.1、6.3

### 4.3 按摩与同意

- 情况：她喊肩颈疼，你想帮她按。
- 判断：按摩也是身体接触，先问部位和力度，中途可以停。
- 原话：「我帮你按肩，只按肩，力度你随时说停。」
- 回应：
  - 「用力点」→ 「好，疼了你说。」
  - 「不用了」→ 「那你自己揉，我给你倒水。」
- 接着做：问部位、问力度、问时长，三个都得到答复再开始。
- 做对了：对方全程有掌控感。
- 红线：不要以按摩为由越过对方说过的边界。
- 依据：A。同意可按具体行为与范围界定，且随时可撤回。
- 来源：S03、S04
- 相关：6.1、6.4

### 4.4 夜景与阳台

- 情况：房间有阳台，你们只在里面看手机。
- 判断：阳台是稀缺资源：五分钟安静、一杯热饮、一张合照，就够。
- 原话：「我们去阳台站五分钟，带杯热茶，拍一张就回来。」
- 回应：
  - 「冷」→ 「披件外套，两分钟就回。」
  - 「我恐高」→ 「那在窗边，不开门。」
- 接着做：带外套与热饮，站五分钟，拍一张。
- 做对了：有了一个「这一晚」的画面。
- 红线：不要坐在栏杆上、不要探身拍照。
- 依据：A。高层阳台有明确的安全提示。
- 来源：S04、S13
- 相关：3.5、2.6

### 4.5 睡前聊天的问题

- 情况：躺下后各刷各的手机，然后各自睡着。
- 判断：睡前的对话要「轻」：今天最好的一个瞬间、明天想吃什么、最近在烦什么。不要谈分手、谈未来五年。
- 原话：「睡前三个问题：今天最好的一刻、明天想吃什么、最近有什么事烦。」
- 回应：
  - 「我不想聊」→ 「那说一件就行。」
  - 「聊这个会不会吵架」→ 「轻的才聊，重的明天。」
- 接着做：关灯前问三个，最多聊十五分钟。
- 做对了：带着轻松的话入睡。
- 红线：不在睡前谈指责、翻旧账、做重大决定。
- 依据：B。睡前情绪唤醒影响入睡质量。
- 来源：S01、S06
- 相关：1.6、4.6

### 4.6 睡前仪式与睡眠习惯

- 情况：一个要开灯看手机，一个要全黑安静。
- 判断：睡眠习惯的差异要靠安排解决，不靠忍。眼罩、耳塞、各自一盏小灯，成本很低。
- 原话：「我戴眼罩，你开小灯看书，声音别外放，行吗。」
- 回应：
  - 「你事真多」→ 「戴上就不吵了。」
  - 「我睡不着」→ 「那我们各自听点东西，戴耳机。」
- 接着做：把眼罩、耳塞、充电线放在床头，睡前十分钟不刷短视频。
- 做对了：两个人都睡够了。
- 红线：不要因为「他不睡」而赌气熬夜。
- 依据：B。睡眠环境差异是伴侣冲突的常见来源。
- 来源：S06、S13
- 相关：1.4、4.5

# 5. 吃在房间里


在房间吃饭，好处是不用打扮、不用排队；坏处是味道、垃圾和账单。这一章把三件事都管住。

### 5.1 客房送餐：什么时候值

- 情况：菜单上一碗面要一百多。
- 判断：客房送餐买的是「不出门」和「有人收」。累到不想动时值，精神好时不如出门。
- 原话：「今天太累了，我们叫客房送餐，贵一点但不用动。」
- 回应：
  - 「太贵了」→ 「那就下楼吃，我陪你走。」
  - 「不好吃」→ 「不好吃下次不叫。」
- 接着做：先看菜单价格与送餐时间，再决定。
- 做对了：花的是便利费，不是冤枉钱。
- 红线：不要让送餐员进房间，餐具放门口。
- 依据：C。服务溢价应按状态而非面子购买。
- 来源：S05、S13
- 相关：5.2、7.4

### 5.2 外卖怎么点

- 情况：想点外卖，但怕味道留在房间。
- 判断：避开三类：重油辣、汤汤水水、气味扩散强的。选好收拾、凉了也好吃的。
- 原话：「我们点两份饭加一份水果，别点汤和螺蛳粉，房间散不掉。」
- 回应：
  - 「我就想吃那个」→ 「那去楼下吃，房间真不行。」
  - 「随便点」→ 「那我按好收拾的点。」
- 接着做：点单时备注「不要汤、少油、多给纸巾」。
- 做对了：吃完房间还是能睡人。
- 红线：不要把外卖垃圾放在走廊或房门口过夜。
- 依据：C。气味与垃圾是酒店投诉的高频项。
- 来源：S13、S05
- 相关：5.4、4.1

### 5.3 早餐时间与忌口

- 情况：她不吃辣、不吃香菜，你没问就点了。
- 判断：忌口要在点单前问清，不要在菜上来后讨论。
- 原话：「点之前问一句：你不吃什么，我按你的来。」
- 回应：
  - 「我不挑」→ 「那我说两个我不吃的，剩下你定。」
  - 「你记不住」→ 「我写备忘录里。」
- 接着做：把对方的忌口存进手机备注，点单前看一眼。
- 做对了：桌上每样她都能吃。
- 红线：不要用「尝一口没事」逼对方吃忌口的东西。
- 依据：C。饮食禁忌涉及习惯与健康，不宜试探。
- 来源：S13、S05
- 相关：3.3、5.1

### 5.4 味道、垃圾与清洁

- 情况：房间一股外卖味，垃圾桶满了。
- 判断：三步收拾法：开窗或开排风、把垃圾装袋扎紧、把桌面擦一遍。五分钟。
- 原话：「我开窗，你把垃圾扎起来，桌子我擦一下。」
- 回应：
  - 「明天再说」→ 「明天更臭。」
  - 「叫保洁」→ 「我们自己两分钟。」
- 接着做：吃完立刻收，不留到睡前。
- 做对了：房间里没有隔夜味。
- 红线：不要把油污倒进洗手池或浴缸。
- 依据：C。及时清理能显著降低异味与虫害风险。
- 来源：S13、S06
- 相关：5.2、7.5

### 5.5 喝酒的分寸

- 情况：想开一瓶酒，气氛正好。
- 判断：酒是加分项，不是必需品。先吃东西、定好量、有一个人保持清醒。
- 原话：「我们一人一杯，喝完就算了，明天还要早起。」
- 回应：
  - 「再喝点」→ 「今天到这儿，明天再说。」
  - 「你不喝没意思」→ 「我陪你坐着，我喝一半。」
- 接着做：先吃主食再喝，酒放得离床远一点。
- 做对了：没有喝到断片，也没人在半夜难受。
- 红线：不劝酒；饮酒后不洗澡、不游泳、不独自外出。
- 依据：A。酒精影响判断与体温调节，泳池与浴缸风险更高。
- 来源：S04、S06
- 相关：4.2、7.3

### 5.6 咖啡与茶的小仪式

- 情况：房间有热水壶，只用来烧水泡面。
- 判断：一杯手冲或一壶茶，能把「等」变成「一起等」。三分钟的事，记忆点很强。
- 原话：「我带了挂耳，我们冲两杯，坐窗边喝完再决定要不要出门。」
- 回应：
  - 「麻烦」→ 「三分钟，比刷手机快。」
  - 「我睡不着」→ 「那给你泡茶，淡的。」
- 接着做：带两包挂耳或茶包，配两个纸杯。
- 做对了：有了一件只属于这个房间的小事。
- 红线：不要用酒店玻璃杯直接倒沸水。
- 依据：C。共同的小仪式提高日常满意度。
- 来源：S01、S13
- 相关：3.5、4.4

# 6. 亲密、边界与拒绝


房间私密，不等于默认会发生什么。这一章讲怎么问、怎么拒绝、怎么被拒绝、怎么照顾。

### 6.1 同意要说出口

- 情况：气氛到了，你伸手，她没说话。
- 判断：沉默不是同意。问一句不会破坏气氛，只会让两个人都放松。
- 原话：「我想亲近你，你现在愿意吗？不愿意就抱着睡，也很好。」
- 回应：
  - 「你还要问」→ 「问一句，比猜错好。」
  - 「今天不想」→ 「好，那就不。」
- 接着做：问一次，接受任何答案，不追问理由。
- 做对了：对方不需要用装睡来拒绝。
- 红线：不要在对方犹豫、醉酒、睡着、害怕时继续。
- 依据：A。性行为需基于真实、明确的同意，且随时可撤回。
- 来源：S03、S07
- 相关：6.3、6.4

### 6.2 避孕与安全

- 情况：谁都没提避孕。
- 判断：这件事要在发生之前说，不是之中或之后。方式由两个人一起定，不由一个人决定。
- 原话：「安全措施我们提前说好，用哪种你定，我准备。」
- 回应：
  - 「不用吧」→ 「用，这事不赌。」
  - 「你准备就好」→ 「我们一起确认。」
- 接着做：出行前把措施备好，放在拿得到的地方。
- 做对了：没有人需要临时紧张。
- 红线：不要用「就这一次」说服对方放弃安全措施。
- 依据：A。避孕与性健康属双方共同决定的事项。
- 来源：S07、S04
- 相关：6.1、6.6

### 6.3 说「今天不想」

- 情况：你很累，或者心情不对，但怕对方失望。
- 判断：「不想」不需要理由，但给一句温度会更好：拒绝行为，不拒绝这个人。
- 原话：「今天我确实不想，不是不喜欢你。我想抱着睡，别的明天再说。」
- 回应：
  - 「你是不是不爱我」→ 「爱，跟今天不想是两件事。」
  - 「那我睡沙发」→ 「不用，抱着睡就行。」
- 接着做：说清是「今天」还是「这段时间」，别让对方一直猜。
- 做对了：拒绝之后，关系没有变冷。
- 红线：不要用生病、装睡来替代说「不」。
- 依据：A。拒绝是权利的行使，不需要举证。
- 来源：S03、S07
- 相关：6.1、6.5

### 6.4 不拍照：影像的边界

- 情况：你想拍一张「纪念」，她明显不愿意。
- 判断：房间里的影像风险最高。不拍、不存、不发，是底线，不是保守。
- 原话：「不拍。想留纪念我们拍窗外的景，或者只拍手。」
- 回应：
  - 「就自己看」→ 「自己看也不拍。」
  - 「你不信任我」→ 「不是信任问题，是风险问题。」
- 接着做：把手机放到一边，需要记录就拍环境。
- 做对了：对方不需要为「拒绝被拍」解释。
- 红线：不偷拍、不保留对方要求删除的照片、不把私密影像存在云端。
- 依据：A。未经同意拍摄、传播私密影像可能承担法律责任。
- 来源：S03、S07
- 相关：6.1、7.2

### 6.5 身体评价这件事

- 情况：她说「我最近胖了」，或者你随口评价了一句。
- 判断：房间里的身体最容易变成敏感话题。不评价、不比较、不「建议减肥」。
- 原话：「我不评价你的身体。你要聊这个，我听；不需要我评价，我就不说。」
- 回应：
  - 「你是不是也觉得我胖」→ 「我没这么想，我只想你舒服。」
  - 「你就不能夸我」→ 「可以，我说具体的：今天你笑起来很好看。」
- 接着做：夸具体的事，不做身材打分。
- 做对了：身体在房间里是安全的。
- 红线：不要拿对方的身体开玩笑，也不要在亲密时评价。
- 依据：B。身体意象与关系满意度显著相关。
- 来源：S02、S07
- 相关：6.6、6.3

### 6.6 事后的照顾

- 情况：结束后各自翻身看手机。
- 判断：事后十分钟决定这段体验的记忆。三件事：水、清理、一句话。
- 原话：「我去倒水，你先躺着。刚才我很开心。」
- 回应：
  - 「不用管我」→ 「管一下，顺手的事。」
  - 「你别说了」→ 「那我不说，抱着。」
- 接着做：递水、递纸巾、问一句「有没有不舒服」。
- 做对了：对方感到被照顾，而不是被使用。
- 红线：不要结束后立刻讨论表现、开评价式玩笑。
- 依据：C。事后照顾影响亲密体验的整体评价。
- 来源：S07、S01
- 相关：6.2、4.6

# 7. 安全、合规与退房


房间私密，但门外面是公共空间。这一章讲六件必须做的事。

### 7.1 登记与访客

- 情况：想让朋友上来坐坐，或者她晚到没登记。
- 判断：住宿要按酒店要求登记实际入住人。访客按酒店规定，通常需要登记且有时限。
- 原话：「访客要去前台登记一下，酒店有规定，我们配合一下。」
- 回应：
  - 「这么麻烦」→ 「登记两分钟，省得被查。」
  - 「就坐一会儿」→ 「那也得登。」
- 接着做：提前问前台访客政策，按规定办。
- 做对了：不给前台和你们自己找麻烦。
- 红线：不要让未登记的人留宿；不要用他人身份登记。
- 依据：A。住宿实名登记是法定要求。
- 来源：S04、S07
- 相关：7.4、7.6

### 7.2 检查偷拍设备

- 情况：不确定房间里有没有摄像头。
- 判断：重点看正对床与浴室的位置：烟雾报警器、插座、路由器、闹钟、装饰摆件。关灯用手机相机扫一圈看有无红点，只是辅助手段。
- 原话：「我先看一下烟雾报警器和插座，两分钟。」
- 回应：
  - 「你想多了」→ 「看一眼，睡得踏实。」
  - 「真发现怎么办」→ 「立刻换房并报警。」
- 接着做：关灯、拉窗帘，重点检查三个位置；发现可疑就换房并报警 110。
- 做对了：隐私有基本保障。
- 红线：不要自行拆卸设备，保留现场并报警。
- 依据：A。偷拍涉嫌违法，可报警处理。
- 来源：S03、S04
- 相关：6.4、7.4

### 7.3 消防与逃生

- 情况：住了两晚，从没看过门后的逃生图。
- 判断：进门看三样：最近的安全出口、疏散方向、能不能走通。夜间把钥匙和手机放在固定位置。
- 原话：「逃生图在这儿，出口在走廊尽头左转，我们记一下。」
- 回应：
  - 「不会出事」→ 「记一下不费事。」
  - 「太吓人」→ 「知道了才不吓人。」
- 接着做：走一遍到安全出口的路，记步数。
- 做对了：真有事时不用找方向。
- 红线：不遮挡烟感、不堵塞通道、不在房间用明火。
- 依据：A。消防通道与烟感是法定要求。
- 来源：S04、S06
- 相关：1.3、7.5

### 7.4 陌生人敲门

- 情况：深夜有人敲门说「送东西」。
- 判断：先确认身份再开门。通过猫眼、内线电话或前台核实，不要让陌生人进房间。
- 原话：「东西放门口就行，我一会儿拿。」
- 回应：
  - 「你开门啊」→ 「放门口，谢谢。」
  - 「是前台让我送的」→ 「我打个电话确认一下。」
- 接着做：挂上门链再开门缝取物；可疑就通知前台。
- 做对了：没有任何人被迫开门。
- 红线：不要让陌生人进房间，不要跟着陌生人去「另一个房间」。
- 依据：A。住店安全提示普遍要求核实访客身份。
- 来源：S04、S07
- 相关：7.1、7.2

### 7.5 损坏与赔偿

- 情况：不小心把杯子打碎了，或者弄脏了床单。
- 判断：主动说，比被查出来便宜。多数酒店按成本收，隐瞒可能按更严的条款处理。
- 原话：「刚才我不小心打碎了一个杯子，我跟你报一下，怎么处理我配合。」
- 回应：
  - 「会不会罚很多」→ 「按价赔，比藏着好。」
  - 「不说算了」→ 「退房查出来更麻烦。」
- 接着做：拍一张照片留底，到前台说明并留凭据。
- 做对了：事情在小范围内解决。
- 红线：不要用毛巾擦鞋、擦化妆品、擦污渍。
- 依据：C。住宿合同中的物品损坏一般按约定赔偿。
- 来源：S05、S13
- 相关：5.4、7.6

### 7.6 退房与评价

- 情况：赶时间，东西落下了。
- 判断：退房前走三步：看抽屉与床头、看充电器与浴室、拍照留房态。
- 原话：「走之前我看一圈：抽屉、床头、充电器、浴室，你再看一遍。」
- 回应：
  - 「不会落」→ 「两分钟，落了更麻烦。」
  - 「落了怎么办」→ 「打电话给前台，多数能寄回。」
- 接着做：两人分头检查，一人看一半；离店后写一句真实评价。
- 做对了：没落下东西，也没留下烂摊子。
- 红线：不要把酒店用品、毛巾带走。
- 依据：C。物品清点与房态记录能减少纠纷。
- 来源：S05、S13
- 相关：7.5、1.3
