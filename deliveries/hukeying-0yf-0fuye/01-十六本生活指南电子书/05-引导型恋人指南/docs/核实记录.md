版本 1.0.0，2026-10-31。来源清单在 [SOURCES.md](../SOURCES.md)，这里记录“我们决定怎么处理一个说法”，以及为什么。

## 阅读状态

| 状态 | 意思 |
| --- | --- |
| 全文 | 读过原文，能指出具体段落 |
| 摘要 | 只读了期刊或数据库摘要 |
| 正文片段 | 读了作者站或机构页的节选 |
| 二手概述 | 通过综述、教材、可信科普转述，未回原文 |
| 检索摘要 | 只看到搜索结果摘要，用来了解公共叙述，不作证据 |

## 本版的处理

| 说法 | 处理 | 原因 |
| --- | --- | --- |
| “引导型恋人能让回避型 100% 回心转意” | 删除 | 没有任何研究支持对个体的保证 |
| “回应连接邀请 86% 对 33%” | 只作方向，不写数字 | 数字来自科普著作，本次未核到原始统计 |
| “5:1 是幸福婚姻的魔法比例” | 写成“观察到的比例，不是配额” | 原始研究是观察性预测，不是因果处方 |
| “爱的五种语言” | 不作为方法 | 2024 年综述指出核心假设缺乏实证支持（S20） |
| “多巴胺、催产素决定你们合不合适” | 删除 | 把复杂神经化学简化成匹配测试，证据不足 |
| “回避型就是渣” | 删除 | 标签化，且会掩盖真实的控制与暴力 |
| “伴侣治疗能解决家暴” | 明确反对 | 存在暴力时联合治疗可能增加风险（S23） |
| “断联 30 天一定挽回” | 改成“恢复边界” | 断联没有保证复合的效果证据 |
| “依恋类型一辈子不变” | 删除 | 分布会随年代与关系变化，约三成会移动（S03、S04） |
| “回避型的人没有情绪” | 删除 | 生理唤醒仍在，只是表达被压低（S01、S02） |

## 数字的处理

- 只保留能回到原始出处的数字，并写清它不能说明什么。
- 具体时长（十五分钟、二十分钟、四十八小时、三十天）都是示例，不是研究阈值。
- 比例、百分比、效应量不用来预测某一段关系。
- 没有核到原始文献的数字，不写。

## 复核节奏

- 每次改条目，检查它引用的来源是否还支持那句话。
- 每半年重看一次带数字的句子，尤其是政策、热线、法律条文。
- 热线与法律信息以官方最新公告为准：110、12338、12356，以及《反家庭暴力法》与人身安全保护令的现行规定。
