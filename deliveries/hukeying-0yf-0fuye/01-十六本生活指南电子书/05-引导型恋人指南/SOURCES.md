# 来源与核实记录

[← 回总目录](README.md)

这份记录借用了两本参考书和 leanrea 的做法：**每一条结论都能回到来源，每个来源都标明读到了什么程度。** 没读全文就说没读全文，没核对数字就不写成确定数字。

## 证据等级怎么打

| 等级 | 含义 | 例子 |
| --- | --- | --- |
| A | 多项 RCT、元分析或大样本纵向研究一致支持 | 伴侣治疗对关系痛苦的疗效；控制行为与心理伤害的关联 |
| B | 有同行评审研究，但证据有限、样本单一，或需要迁移 | 依恋维度与去激活策略；自我关怀与关系行为 |
| C | 临床共识、科普著作、相关研究，只能参考 | Gottman 的 5:1 与“连接邀请”；情感勒索 |
| D | 本书原创经验、示例话术，没有效果验证 | 所有“第一句”；具体时长与频率 |

等级评价的是**这一条主张**，不是这个作者或这本书的整体水平。同一个来源，在不同条目里可能是 B，也可能是 C。

## 核实记录：哪些话被删掉了

写这本书时，下面这些常见说法没有收进来，或者被降级了：

| 说法 | 处理 | 原因 |
| --- | --- | --- |
| “引导型恋人能让回避型 100% 回心转意” | 删除 | 没有任何研究支持对个体的保证 |
| “回应连接邀请 86% 对 33%” | 只作方向，不写数字 | 数字来自科普著作，本次未核到原始统计 |
| “5:1 是幸福婚姻的魔法比例” | 写作“观察到的比例，不是配额” | 原始研究是观察性预测，不是因果处方 |
| “爱的五种语言” | 不作为方法 | 2024 年综述指出核心假设缺乏实证支持（S20） |
| “多巴胺、催产素决定你们合不合适” | 删除 | 把复杂神经化学简化成匹配测试，证据不足 |
| “回避型就是渣” | 删除 | 标签化，且会掩盖真实的控制与暴力 |
| “伴侣治疗能解决家暴” | 明确反对 | 存在暴力时联合治疗可能增加风险（S23） |
| “断联 30 天一定挽回” | 改成“恢复边界” | 断联没有保证复合的效果证据 |
| “不联系就能看出谁更在乎你” | 改成“投入清单 + 直接问” | 试探属于操控，且没有证据能把沉默换算成在乎 |
| “你付出这么多，说明他是对的人” | 明确反对 | 沉没成本不能预测关系质量（S32 只描述承诺机制，不给个体建议） |

## 数字的处理

- 本书只保留少量数字，且都带“研究说什么、不能说什么”。
- 没有核对到原始文献的数字，不写。
- 具体时长（十五分钟、二十分钟、四十八小时、三十天）都是**示例**，不是研究阈值。
- 比例、百分比、效应量在这里一律不用来预测你这段关系。

## 怎么核对

1. 先看条目末尾的 `来源`，再回这张表。
2. 点开链接，看摘要或正文片段，确认它支持的是哪一句。
3. 如果表里写“二手概述”“检索摘要”，就把它当线索，不当定论。
4. 发现错误，开 issue 或在 `docs/核实记录.md` 里加一条，写清哪条、哪句、改成什么、依据是什么。

## 本书的立场

**研究能告诉你平均模式，不能告诉你眼前这个人。** 这本书把所有“第一句”都标成示例，就是这个原因。你可以用它们开口，但不能用它们替代观察、同意和对方自己的选择。
