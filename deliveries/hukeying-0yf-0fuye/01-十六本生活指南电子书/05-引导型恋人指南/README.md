# 引导型恋人指南

**一本可离线阅读、可检索、可练、可验收的亲密关系电子书。**

13 章，104 个具体处境。每条都写清：怎么判断、第一句怎么说、对方两种回法怎么接、接下来做什么、怎么算做对、哪条红线不能碰、依据有几成。

配套 10 个 agent skills：查书回答、毒舌参谋（狗头军师）、对话排练、回避型撤退协议、发消息前的验收、极简版，以及把指责改写成请求、写一句边界、画支持系统、算继续还是离开。

> **免责声明：** 本书是教育与人际沟通参考，不是心理治疗、医疗或法律意见。不保证对任何个人有效，也不承诺改变对方。涉及暴力、自伤、成瘾、精神疾病或法律问题，请找对应的专业渠道。

## 每条长什么样

```
### 5.2 不追着把话说清楚
- 情况：对方说“现在不想谈”，你更想立刻谈完。
- 判断：追着要答案，会把对方推到只能逃的位置。
- 第一句：“你现在不想谈，我不追。我们定一个最晚时间：明天晚上九点。”
- 回应：
  - 「明天再说」→ “好，明晚九点。我不在这之前发消息。”
  - 「你别走」→ “我不走，但我不在门口站着。九点我回来。”
- 接着做：物理上退开；到点只问一次；最多延两次。
- 做对了：你没有用追击换到一句敷衍的“好好好”。
- 红线：不堵门、不抢手机、不用自伤威胁。
- 依据：A。要求、退缩循环的研究一致显示，追压会强化退缩。
- 来源：S05、S06、S21
- 相关：2.4、5.3、3.5
```

## 四条底线

1. **同意可撤回。** 对方可以随时说“不想聊”“不想被安排”“不想继续”。
2. **不改造人格。** 只谈具体行为、具体影响、具体请求。
3. **不替代专业帮助。** 不诊断、不治疗，不处理暴力、成瘾、自伤。
4. **不监控、不操控。** 不查手机、不装定位、不伪造情境、不用冷暴力逼对方。

违反任何一条，技巧越熟，伤害越大。

## 和流行说法有什么不同

**第一，把“引导”和“控制”分开。** 网上很多“引导型恋人”内容只讲怎么接住、怎么带节奏，很少讲拒绝权。这本书把“对方能不能说不、说不有没有代价”放在第一条。

**第二，不把“回避型”当诊断。** 依恋是维度，不是四个盒子，更不是“渣”的同义词。书里只描述行为和时间点，不替任何人下诊断。

**第三，治愈的主体是对方。** 你能提供稳定、低评判、可退出的环境，不能替对方完成改变，也不承诺“我永远不会走”。

**第四，所有对话都是编写情境。** 不是从私信、群聊、帖子里搬来的真人记录。公开材料只用来提炼模式，并标明样本偏差。

## 证据分级

| 等级 | 含义 | 这本书里大概有多少 |
| --- | --- | --- |
| A | 多项 RCT、元分析或大样本纵向研究一致支持 | 安全、暴力、疗效、要求退缩等 |
| B | 有同行评审研究，但证据有限或需要迁移 | 依恋、自我关怀、修复、共同调节 |
| C | 临床共识、科普著作、相关研究 | Gottman 的具体技巧、家庭边界、金钱规则 |
| D | 本书原创经验与示例话术 | 所有“第一句”、具体时长与频率 |

每条末尾都标 `依据：X`，并给 `来源：SXX`。来源表在 [SOURCES.md](SOURCES.md)，标了“全文 / 摘要 / 二手概述 / 检索摘要”。没核到原始出处的数字，不写。

## 安装 skills

十个 skill 都在 `skills/` 下，自带 `SKILL.md` 和 Codex 的 `agents/openai.yaml`。逐项说明见 [skills/README.md](skills/README.md)。

```bash
cd guides/guiding-partner
./tools/install-skills.sh
```

默认软链到 `~/.claude/skills` 和 `~/.agents/skills`，`git pull` 后自动更新。`--copy` 只复制 skill 文件，正文由 skill 按仓库路径读取。也可以：

```bash
./tools/install-skills.sh --copy                  # 复制而不是软链
./tools/install-skills.sh --target ~/my-skills    # 装到指定目录
./tools/install-skills.sh --force                 # 覆盖同名目录
```

| Skill | 怎么触发 | 干什么 |
| --- | --- | --- |
| [`guiding-partner`](skills/guiding-partner/SKILL.md) | 模型自动，或 `/guiding-partner` | 查条目后回答具体处境，给判断、第一句、两种接法、红线 |
| [`doghead-strategist`](skills/doghead-strategist/SKILL.md) | 只由你 `/doghead-strategist` | 狗头军师：发消息前算三条路，给一句能今晚用的话，拦下操控与自欺 |
| [`dialogue-rehearsal`](skills/dialogue-rehearsal/SKILL.md) | 只由你 `/dialogue-rehearsal` | 演对方，三轮对话，按五维复盘 |

| [`partner-guide-audit`](skills/partner-guide-audit/SKILL.md) | 只由你 `/partner-guide-audit` | 验收草稿或计划：机械检查 + 人工三问，给 PASS / REVISE / BLOCK |

| [`support-map`](skills/support-map/SKILL.md) | 只由你 `/support-map` | 四圈支持系统地图，别把全部重量压在一个人身上 |

### 狗头军师怎么用

装好后，在要把一条消息发出去之前：

```
/doghead-strategist 他两天没回我，我该发什么？
```

军师会先泼一盆冷水，给三条路和代价，给一句原话，再给一个“别做”。它不接查手机、冷暴力、让对方吃醋、PUA 这类活。

## 自己构建

主构建只需要 Python 3.9+，没有第三方依赖。PDF 是可选目标，另外需要 `fpdf2` 和中文字体。

```bash
python3 tools/build.py          # 生成 index.html、selfcheck.html、GUIDE.md、EPUB
python3 tools/build.py --check  # 只校验，不写文件
python3 tools/build_pdf.py      # 生成 PDF，需要 fpdf2 和中文字体，见 tools/fonts/README.md
```

改了 `book/` 或 `data/selfcheck.json` 之后重新跑一次。`index.html`、`selfcheck.html`、`GUIDE.md`、`downloads/` 都是生成文件，不要手改。PDF 是可选的打印版，字体不入库。字段规范见 [docs/编写规范.md](docs/编写规范.md)。
