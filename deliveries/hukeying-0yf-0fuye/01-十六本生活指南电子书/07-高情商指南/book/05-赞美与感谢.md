# 5. 赞美与感谢：具体、及时、不比较

[← 回总目录](../README.md)

不会赞美的人，往往不是刻薄，是怕说假话。解决办法不是学夸张，是把赞美落在可验证的细节上。

### 5.1 具体赞美公式

- 情况：想说「你真棒」，说出来像敷衍。
- 判断：公式：具体行为 + 它带来的影响 + 你的感受。三者至少要有前两个。
- 原话：「你昨天把客户的问题整理成一页表，我今天沟通省了半小时，这个真管用。」
- 回应：
  - 「小事」→ 「小事最见功夫。」
  - 「你也行」→ 「我学一下你这个做法。」
- 接着做：每天给一个人一句带细节的赞美。
- 做对了：对方知道你具体夸的是什么。
- 红线：不要夸对方无法改变的东西（外貌、家境）作为主要赞美。
- 依据：C。具体反馈比笼统评价更有行为指向。
- 来源：S06、S11
- 相关：5.2、5.4

### 5.2 赞美不比较

- 情况：「你比小王强多了」。
- 判断：比较式赞美会制造敌人和警惕：听的人会想「你是不是也在背后这么说我」。改成只对这个人说。
- 原话：「你这个方案把成本拆得很细，我照着改了预算表。」
- 回应：
  - 「那小王呢」→ 「我不比较，我说的是你这个做法。」
  - 「你别捧我」→ 「我说的是具体的事。」
- 接着做：赞美时删掉所有「比……好」。
- 做对了：赞美没有让第三方难堪。
- 红线：不要用贬低他人来抬高对方。
- 依据：C。比较性评价会引发不安全感。
- 来源：S06、S11
- 相关：5.1、5.5

### 5.3 感谢要说出「因为什么」

- 情况：只会说「谢谢」。
- 判断：有效感谢=具体的事 + 对你的影响 + 你做了什么回应。三句话，比一句谢谢重。
- 原话：「谢谢你昨天帮我顶了那个电话，我才赶上了汇报。这个人情我记着，下周你那边忙我帮你。」
- 回应：
  - 「不用」→ 「要的，我确实受益了。」
  - 「太客气」→ 「应该的。」
- 接着做：重要帮助在 24 小时内表达，一周内给实质回报。
- 做对了：对方知道你感谢的是哪件事。
- 红线：感谢不要附带请求，那会变成交易。
- 依据：C。具体化的感谢提升关系满意度。
- 来源：S06、S11
- 相关：5.1、9.3

### 5.4 公开赞美与私下赞美

- 情况：当众夸一个人，他被夸得不自在。
- 判断：公开赞美适合「成果」，私下赞美适合「努力与品质」。内向的人更接受私下。
- 原话：「你这次顶了很多压力，别人不一定看见，我看见了。」（私下，一对一）
- 回应：
  - 「别说了」→ 「好，那我心里记着。」
  - 「大家都一样」→ 「你的那部分我确实看到了。」
- 接着做：观察对方被夸时的反应，决定下一次的场合。
- 做对了：对方接受得自然，没有尴尬。
- 红线：不要用公开赞美来施压或绑架对方。
- 依据：C。赞美的接受度受人格与场合影响。
- 来源：S06、S11
- 相关：5.1、6.2

### 5.5 接受赞美：不否认、不反夸

- 情况：别人夸你，你立刻说「没有没有」。
- 判断：否认会让对方尴尬。接受三步：谢谢 + 承认（这次确实花了功夫）+ 归功（也靠谁帮了忙）。
- 原话：「谢谢，这次确实下了功夫，也多亏你把数据理清楚了。」
- 回应：
  - 「你太谦虚」→ 「真不是谦虚，这次确实运气也好。」
  - 「你厉害」→ 「谢谢，我继续努力。」
- 接着做：练习只说「谢谢」，不加否定。
- 做对了：你接受了赞美，也把功劳分给了该分的人。
- 红线：不要用过度自谦来索取更多赞美。
- 依据：C。接受正面反馈是自尊稳定的表现。
- 来源：S06、S02
- 相关：5.1、12.2

### 5.6 对上级与长辈的赞美

- 情况：想夸领导，又怕像拍马屁。
- 判断：对上级的赞美要落在「具体决策或做法」上，且要有事实支撑；不夸人品、不夸外貌、不夸权力。
- 原话：「您上次坚持先做小范围试点，后面扩量时问题少了很多，这个顺序我学到了。」
- 回应：
  - 「你这是捧我」→ 「我说的是那件事的结果。」
  - 「少来这套」→ 「好，那我不说了。」
- 接着做：赞美前先找到一个可验证的结果。
- 做对了：你的赞美里有一件具体的事。
- 红线：不用赞美换取资源、机会、评价。
- 依据：C。向上赞美最易被解读为交换，需以事实为锚。
- 来源：S11、S06
- 相关：5.1、5.2
