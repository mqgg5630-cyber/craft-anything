# 0. 导言：情商不是会说话


**这本书只解决一件事：让你在冲突、拒绝、批评、安慰、道歉这五类最难开口的时刻，说得出话、说得准、说得下去。**

「高情商」在网上常被等同于嘴甜、会夸人、不得罪人。那套东西短期有效，长期会把人变成两种结局：要么憋出内伤，要么被当成滑头。

这本书给的是另一种定义，来自情绪研究里比较稳定的共识：

> **情商 = 认出情绪 + 理解情绪 + 表达情绪 + 调节情绪。会说话只是第四项的外壳。**

心理学者梅耶与萨洛维把情商拆成四个分支：感知情绪、用情绪促进思考、理解情绪、管理情绪。戈尔曼的普及版本归纳为自我觉察、自我管理、社会觉察、关系管理。两套划分不完全相同，但指向一件事：先认得出，才谈得上处理。

## 四条原则

1. **先处理情绪，再处理事情。** 一个人情绪高涨时，讲道理基本无效。
2. **描述行为，不评价人格。** 「你昨晚没回消息」和「你根本不在乎我」是两件事。
3. **给选择，不给命令。** 命令制造对抗，选择制造合作。
4. **不操控。** 凡是以「让他离不开我」为目的的技巧，最后都会反噬。

## 这本书不做什么

- 不教 PUA、不教精神控制、不教「拿捏」。
- 不把人贴标签（回避型、NPD、讨好型人格）。标签解释不了具体的人。
- 不替代心理治疗。持续两周以上的情绪低落、失眠、自伤念头，请找专业人士（心理援助热线 12356）。
- 不给「话术背诵」就完事。每条都给判断依据，让你能自己改词。

# 1. 情商到底指什么：四个能力


把情商当成「会说话」，就会去背话术。把情商当成四个能力，就知道该练哪一块。

### 1.1 四个分支：认、用、懂、管

- 情况：别人说你情商低，你不知道低在哪。
- 判断：情商分四块：感知情绪（认得出）、用情绪促进思考（知道情绪在影响判断）、理解情绪（知道为什么）、管理情绪（能调节）。先定位是哪一块弱。
- 原话：「我刚才是没认出你在生气，还是认出来了但不知道怎么接？你告诉我是哪一种。」
- 回应：
  - 「你自己想」→ 「我猜是第二种，我看见了但不知道怎么接。」
  - 「你根本不懂我」→ 「那你教我怎么接，下次我照做。」
- 接着做：回想最近三次「说错话」，标注是四块里的哪一块。
- 做对了：你能说出自己弱在哪一块，而不是笼统地说「我情商低」。
- 红线：不要把「会讨好」当情商，也不要把「会压人」当气场。
- 依据：B。Mayer 与 Salovey 的情绪智力四分支模型，以及 Goleman 的四维归纳。
- 来源：S01、S02
- 相关：1.2、12.1

### 1.2 情绪没有好坏

- 情况：一有情绪就觉得自己不专业。
- 判断：情绪是信息，不是缺陷。愤怒常在提示边界被侵犯，焦虑常在提示不确定性，羞耻常在提示暴露。先读信息，再决定动作。
- 原话：「我现在很烦，说明这件事碰到了我的底线，我们先把它说清楚再谈别的。」
- 回应：
  - 「你情绪化」→ 「我有情绪，但我在说事实。」
  - 「冷静点」→ 「我冷静，我只是要把话说清。」
- 接着做：情绪上来时先给它起个名字，再决定要不要说。
- 做对了：你能说出「我在生气，因为什么」，而不是直接发火或憋着。
- 红线：不要用「我性格直」当发火的通行证。
- 依据：B。情绪标注（affect labeling）有助于降低情绪强度。
- 来源：S03、S02
- 相关：3.1、12.2

### 1.3 自我觉察：身体的早期信号

- 情况：等到说出伤人的话才意识到自己已经炸了。
- 判断：情绪在身体上先出现：下颌发紧、呼吸变浅、语速变快、手心出汗。抓住信号，就有三秒钟的选择空间。
- 原话：「我先喝口水，我们慢一点说。」
- 回应：
  - 「你躲什么」→ 「我不躲，我怕说错话。」
  - 「说啊」→ 「给我十秒钟想清楚。」
- 接着做：练习在对话中每隔几分钟检查一次呼吸。
- 做对了：你能在爆发前说出「我需要缓一下」。
- 红线：不要把「我需要缓一下」变成长期回避问题。
- 依据：B。生理唤醒是情绪升级的早期指标。
- 来源：S03、S04
- 相关：8.1、12.3

### 1.4 自我管理：六秒与重新解释

- 情况：被当众批评，很想当场怼回去。
- 判断：两个工具：延迟（深呼吸六秒）与重新解释（把「他在针对我」换成「他在为结果着急」）。后者不是自我欺骗，是给自己多一种解释。
- 原话：「我先记下来，会后我跟您确认哪几条最优先。」
- 回应：
  - 「你还有意见？」→ 「有两条我想单独跟您核。」
  - 「受不了就滚」→ 不接这句，会后书面沟通。
- 接着做：准备一句「缓冲语」，任何冲突场合都能用。
- 做对了：你没有在情绪峰值做决定。
- 红线：不要用压抑代替管理，压久了会以更糟的方式爆出来。
- 依据：B。认知重评是情绪调节中被广泛验证的策略。
- 来源：S04、S03
- 相关：6.1、8.2

### 1.5 社会觉察：读懂房间

- 情况：会上你说得正起劲，其他人已经在看手机。
- 判断：社会觉察看三个信号：注意力（有没有人在听）、身体（转向、后仰、抱臂）、时间（是不是该收尾）。读到了就调整，不必自我否定。
- 原话：「我这边讲得有点长了，剩下两条我发文档，大家先看有没有问题。」
- 回应：
  - 「你继续说」→ 「好，我压缩成三句。」
  - 「有点跑题」→ 「是我跑偏了，拉回来。」
- 接着做：每次发言前先看一眼在场的人，发言中留一次停顿。
- 做对了：你能在别人失去耐心之前收住。
- 红线：不要因为读气氛就读成讨好，把自己要说的话全部咽下去。
- 依据：B。社会觉察涉及对非言语线索的解读。
- 来源：S02、S05
- 相关：1.6、11.4

### 1.6 关系管理：把情绪转成动作

- 情况：知道对方不高兴，但不知道下一步做什么。
- 判断：关系管理的动作只有几种：确认、澄清、道歉、设界、给选项、暂缓。任选一种，别停在「我感觉到了」。
- 原话：「我感觉你不太舒服，是我哪句话说得不对，还是现在不方便聊？」
- 回应：
  - 「没什么」→ 「那我等你方便的时候再说。」
  - 「你自己知道」→ 「我猜是刚才那句，我道歉。」
- 接着做：情绪识别之后，逼自己做一个具体动作。
- 做对了：对话有了下一步，而不是停在尴尬里。
- 红线：不要用「我都道歉了」逼对方立刻原谅。
- 依据：B。关系修复依赖于具体行为而非态度表白。
- 来源：S05、S06
- 相关：9.1、4.3

# 2. 先听懂：倾听的三层


大多数人不是在听，是在等对方说完，好接自己的话。倾听是情商里最便宜也最稀缺的能力。

### 2.1 三层倾听：内容、情绪、需求

- 情况：对方说了十分钟，你只记住了事实。
- 判断：一句话里有三层：他说了什么（内容）、他什么感受（情绪）、他想要什么（需求）。回应哪一层，决定他觉得你懂不懂。
- 原话：「你说了这两件事，听起来最让你难受的是第二件。你是希望我帮你出主意，还是先听你说完？」
- 回应：
  - 「你根本没在听」→ 「我在听，我复述一遍你看对不对。」
  - 「算了不说了」→ 「别，我想听你说完。」
- 接着做：每次对话结束前，用一句话复述对方的内容与情绪。
- 做对了：对方说「对，就是这样」。
- 红线：不要在对方讲情绪时抢着讲自己的类似经历。
- 依据：B。倾听包含内容、情感与意图三个层面。
- 来源：S07、S08
- 相关：2.2、4.1

### 2.2 不打断的三个动作

- 情况：总忍不住接话、给建议。
- 判断：三个动作：数三秒再开口、把建议写下来最后再问、用「嗯」「然后呢」代替评价。
- 原话：「嗯，然后呢？」
- 回应：
  - 「你倒是说点什么」→ 「我在想你说的这件事。」
  - 「你怎么看」→ 「我先确认我理解对了没有。」
- 接着做：一天练习三次「只回应不评价」。
- 做对了：对方说得比你多。
- 红线：不要用「嗯嗯」敷衍，要有具体的回问。
- 依据：B。积极倾听强调不打断与反映式回应。
- 来源：S07、S09
- 相关：2.1、10.1

### 2.3 反映式回应：把话还回去

- 情况：不知道怎么接，只能说「我懂」。
- 判断：反映式回应=复述关键词 + 说出你听到的情绪 + 留一个开口。
- 原话：「你说你连着加了三周班，最后方案还被否了。是不是觉得白干了，还特别委屈？」
- 回应：
  - 「差不多吧」→ 「那最委屈的是哪一点？」
  - 「你不懂」→ 「那你告诉我，哪里我理解偏了。」
- 接着做：把「我懂」全部替换成「你的意思是……对吗」。
- 做对了：对方开始说得更具体。
- 红线：不要替对方下结论，比如「你就是想开点」。
- 依据：B。反映式倾听（reflective listening）是动机式访谈的核心技术之一。
- 来源：S07、S10
- 相关：4.2、10.2

### 2.4 提问：开放式与封闭式

- 情况：一问一答，聊死了。
- 判断：开放式问题（怎么、什么、哪部分）打开话题；封闭式问题（是不是、对不对）用来确认。开场用开放，收尾用封闭。
- 原话：「这件事最让你卡住的是哪一部分？」（开放）「所以主要是流程那一段，对吗？」（封闭）
- 回应：
  - 「不知道」→ 「那我们从最烦的那件事说起？」
  - 「你问这么多干嘛」→ 「我就是想弄清楚，不方便说就跳过。」
- 接着做：准备五个开放式问题，随时能用。
- 做对了：对方说的信息量明显变多。
- 红线：不要用连环追问审讯式聊天。
- 依据：B。问题的开放程度影响信息产出与关系感受。
- 来源：S07、S08
- 相关：2.1、3.2

### 2.5 沉默也是回应

- 情况：对方哭了，你慌了，拼命找话说。
- 判断：情绪上来时，沉默和陪伴比语言有效。给三十秒的安静，递纸巾、倒水，比任何安慰话都好。
- 原话：「我在，你慢慢说，不着急。」
- 回应：
  - 「你怎么不说话」→ 「我在听，你需要我说什么我就说。」
  - 「说点啥」→ 「那我陪你坐会儿。」
- 接着做：练习在对方情绪激动时先沉默三十秒。
- 做对了：对方自己接着说下去了。
- 红线：不要用「别哭了」打断情绪表达。
- 依据：B。情绪表达需要空间，过早干预会阻断表达。
- 来源：S10、S07
- 相关：10.1、10.4

### 2.6 听懂「不是字面意思」的话

- 情况：对方说「没事」，你知道不是没事。
- 判断：中文沟通里大量信息在字面之外：「随便」可能是失望，「你忙吧」可能是被忽略。处理方式不是猜，而是给一个安全的确认。
- 原话：「你说没事，但我感觉你不太高兴。是我哪里没做好吗？」
- 回应：
  - 「真没事」→ 「那好，你有想说的时候随时找我。」
  - 「你自己想」→ 「我怕猜错，你直接告诉我一句就行。」
- 接着做：把「没事」当作一个邀请，而不是结论。
- 做对了：对方说出了真实的感受。
- 红线：不要把「读心」当能力，猜错了要认。
- 依据：B。高语境沟通中，字面与意图常不一致。
- 来源：S08、S05
- 相关：3.1、4.3

# 3. 情绪识别：他到底在说什么


认不出情绪，就会把求助听成指责、把羞耻听成愤怒。这一章给一套可操作的识别方法。

### 3.1 情绪的四个家族

- 情况：分不清对方是生气、委屈还是害怕。
- 判断：先分四族：愤怒（边界被侵犯）、悲伤（失去）、恐惧（威胁不确定）、羞耻（被看见缺陷）。四族的应对完全不同。
- 原话：「你现在是生气，还是有点委屈？我不太确定，你告诉我。」
- 回应：
  - 「都有」→ 「那我们先说最重的那一个。」
  - 「你觉得呢」→ 「我猜是委屈，猜错了你纠正我。」
- 接着做：把最近一次冲突里对方的情绪归到四族之一。
- 做对了：你选对了应对方式（愤怒要设界，悲伤要陪伴，恐惧要信息，羞耻要保密）。
- 红线：不要对所有情绪都用同一套安慰话术。
- 依据：B。基本情绪分类研究支持愤怒、悲伤、恐惧、羞耻的区分。
- 来源：S03、S10
- 相关：3.2、3.3

### 3.2 从行为反推情绪

- 情况：对方不说话、摔门、阴阳怪气。
- 判断：行为是情绪的出口：沉默可能是受伤或抗议，攻击可能是恐惧，过度解释可能是羞耻。先假设，再验证。
- 原话：「你刚才没说话，是觉得说了也没用，还是不想在这儿说？」
- 回应：
  - 「你自己不知道？」→ 「我猜不准，所以问你。」
  - 「说了有用吗」→ 「那我们换个方式说。」
- 接着做：把观察到的行为写下来，配一个假设的情绪。
- 做对了：你的假设被对方确认或修正。
- 红线：不要用行为直接给对方定性（「你就是冷暴力」）。
- 依据：B。行为与情绪之间是多对多关系，需要验证。
- 来源：S05、S10
- 相关：3.3、8.3

### 3.3 情绪强度决定说什么

- 情况：对方正在气头上，你讲道理。
- 判断：强度分三档：轻微（可讲事实）、中度（先接情绪再讲）、爆发（只做安全与降温）。搞错档位，说什么都错。
- 原话：「我看你现在很气，我先不解释。你需要我做什么，喝水还是出去走一圈？」
- 回应：
  - 「你别管我」→ 「那我在这儿，你需要就叫我。」
  - 「你说啊」→ 「等你不那么气了我说，我怕说错。」
- 接着做：对话前先给对方的情绪打一个 1–10 分。
- 做对了：你在爆发档没有讲道理。
- 红线：不要在对方爆发时讲「你冷静点」，那通常更激怒人。
- 依据：B。高唤醒状态下认知加工能力下降。
- 来源：S04、S10
- 相关：8.1、10.3

### 3.4 别把焦虑读成不信任

- 情况：伴侣反复问「你到哪了」，你觉得被查岗。
- 判断：反复确认常是焦虑，不是控制。回应焦虑要给确定性：时间、地点、下一次联系点。
- 原话：「我十点半到家，路上不方便回消息。到了我发你一条。」
- 回应：
  - 「你是不是有事」→ 「没有，就是想让你放心。」
  - 「你嫌我烦」→ 「不嫌，我给个准点你就安心了。」
- 接着做：提前给一个明确的时间点，而不是含糊的「马上」。
- 做对了：追问的次数下降。
- 红线：如果对方要求实时定位、查手机、限制社交，那就是控制，要设界。
- 依据：B。不确定性是焦虑的主要来源之一。
- 来源：S10、S05
- 相关：3.5、12.4

### 3.5 愤怒背后常有羞耻

- 情况：指出同事一个错误，他突然发火。
- 判断：当众被指出错误容易触发羞耻，羞耻会转成攻击。处理方式是给台阶：把问题归到事上，把改正放到私下。
- 原话：「这事我们先按流程改，细节我私下跟你说，不在群里说。」
- 回应：
  - 「你什么意思」→ 「我的意思是不用当众说，我们私下对。」
  - 「我没错」→ 「那就一起看数据。」
- 接着做：批评前先问自己「这话当众说会不会让他难堪」。
- 做对了：对方没有继续对抗，开始讨论事实。
- 红线：不要用羞辱来推动改变，那会换来报复或沉默。
- 依据：B。羞耻与愤怒在人际冲突中常相互转化。
- 来源：G06、S05
- 相关：6.1、6.3

### 3.6 识别自己的情绪触发点

- 情况：某些话一说你就炸，事后觉得反应过度。
- 判断：触发点通常来自旧经验：被否定、被忽视、被比较。列出三条，遇到时先提醒自己「这是触发，不是事实」。
- 原话：「这句话让我反应很大，可能是我自己的点，我们先停一下。」
- 回应：
  - 「你太敏感」→ 「我承认这是我的点，但感受是真的。」
  - 「那我不说了」→ 「不是不说，是换个说法。」
- 接着做：写一张「触发点清单」：什么话、什么反应、更好的应对。
- 做对了：你能在反应升级前说出「这是我的触发点」。
- 红线：不要把触发点当免罪牌，用来要求别人永远小心。
- 依据：B。情绪触发与早期经验相关，识别后可降低自动反应。
- 来源：S04、S06
- 相关：12.3、8.2

# 4. 共情表达：把「我理解」说具体


共情不是一句「我理解你」。共情是让对方感到「你确实看见了我的处境」，具体才可信。

### 4.1 共情三句：命名、承认、不评价

- 情况：想说点共情的话，说出来像念稿。
- 判断：三句结构：命名情绪（你现在很难受）、承认合理性（换我也会）、不评价（不说「但是」）。
- 原话：「这事儿换我我也憋屈，你难受是正常的。我不劝你，你先说。」
- 回应：
  - 「你不懂」→ 「我可能不懂全部，但我知道你不好受。」
  - 「说这些有什么用」→ 「没用，我就是想让你知道我在。」
- 接着做：把「但是」换成「同时」或直接省略。
- 做对了：对方没有觉得被说服，只觉得被看见。
- 红线：共情之后不要立刻转为说教。
- 依据：B。共情性回应强调理解而非解决问题。
- 来源：S10、S11
- 相关：4.2、10.1

### 4.2 具体化：说出细节才算懂

- 情况：对方说「压力大」，你回「别压力太大」。
- 判断：共情要落在细节上：哪个环节、什么时候、最难受的点。细节让对方感到你真的在听。
- 原话：「是月底那批报表，还是领导天天改需求让你最累？」
- 回应：
  - 「都有」→ 「那最想先解决哪一个？」
  - 「你怎么知道」→ 「你上次也提过这个。」
- 接着做：每次共情至少说出一个对方提过的具体细节。
- 做对了：对方说「对，就是这个」。
- 红线：不要编造细节来假装理解。
- 依据：B。具体化的回应更能提升被理解感。
- 来源：S07、S10
- 相关：2.3、4.1

### 4.3 「我理解」失效的三种情况

- 情况：你说「我理解」，对方更火。
- 判断：三种失效：①对方在爆发档，任何话都是噪音；②你紧接着说「但是」；③你在比较（「我比你更惨」）。
- 原话：「我不说理解了，我就在这儿听着。」
- 回应：
  - 「你就是敷衍」→ 「可能真是，我换个说法：你现在最气的是什么？」
  - 「你不懂」→ 「我确实没经历过，你讲讲。」
- 接着做：把「我理解」列为禁用词，改用具体描述。
- 做对了：对方开始讲细节。
- 红线：不要用「我比你更惨」来抢情绪的主角位置。
- 依据：B。共情失效常来自过早评价与自我中心。
- 来源：S10、S11
- 相关：4.1、10.3

### 4.4 认知共情与情感共情

- 情况：你能理解对方的处境，但没有感觉，觉得自己很冷。
- 判断：共情有两种：认知共情（我知道你怎么想）与情感共情（我感受到你的感受）。专业场合更需要前者，亲密关系更需要后者。
- 原话：「我能想象这件事对你意味着什么。我不装感同身受，但我愿意帮你把它解决掉。」
- 回应：
  - 「你好冷」→ 「我表达得不好，但我确实在意。」
  - 「你只是理性」→ 「理性也是我在帮你的方式。」
- 接着做：判断场合需要哪一种，别硬演情感共情。
- 做对了：对方接受了你的方式，而不是觉得你虚伪。
- 红线：不要假装情绪来换取信任。
- 依据：B。认知共情与情感共情在神经机制与功能上有所不同。
- 来源：S11、S02
- 相关：4.5、10.2

### 4.5 共情不等于同意

- 情况：对方做了明显不对的事，你要不要共情。
- 判断：共情是理解他的感受，不是认可他的行为。两句可以并存：「我理解你为什么这么做」+「但这件事的结果我要说清楚」。
- 原话：「我理解你当时急了，才说了那句话。但这句话确实伤到人了，我们得处理。」
- 回应：
  - 「那你还怪我」→ 「我不怪你动机，我说的是结果。」
  - 「你到底站哪边」→ 「我站事实这边。」
- 接着做：把「理解」和「同意」分成两句说，中间不要用「但是」连接太急。
- 做对了：对方接受了你的边界，也没有觉得被否定。
- 红线：不要用共情为不当行为开脱。
- 依据：B。共情与道德判断可以分离。
- 来源：S11、S06
- 相关：6.4、9.1

### 4.6 共情的边界：不要被吸进去

- 情况：每次听完朋友的痛苦，你自己也垮了。
- 判断：共情耗竭是真实存在的。设置边界：时长（聊多久）、频率（多久一次）、角色（我是朋友不是治疗师）。
- 原话：「我今天能陪你聊半小时，之后我得处理自己的事。你要是夜里撑不住，可以打 12356。」
- 回应：
  - 「你也不管我了」→ 「我管，但我不能一直在线。」
  - 「只有你能听我说」→ 「那我们一起找更稳的支持。」
- 接着做：给自己定共情的时长与频率上限。
- 做对了：你帮了人，也没有把自己耗空。
- 红线：不承担他人的生命责任；出现自伤风险应立即联系专业与紧急渠道。
- 依据：B。共情耗竭（compassion fatigue）在助人者中普遍存在。
- 来源：S12、S13
- 相关：12.4、10.5

# 5. 赞美与感谢：具体、及时、不比较


不会赞美的人，往往不是刻薄，是怕说假话。解决办法不是学夸张，是把赞美落在可验证的细节上。

### 5.1 具体赞美公式

- 情况：想说「你真棒」，说出来像敷衍。
- 判断：公式：具体行为 + 它带来的影响 + 你的感受。三者至少要有前两个。
- 原话：「你昨天把客户的问题整理成一页表，我今天沟通省了半小时，这个真管用。」
- 回应：
  - 「小事」→ 「小事最见功夫。」
  - 「你也行」→ 「我学一下你这个做法。」
- 接着做：每天给一个人一句带细节的赞美。
- 做对了：对方知道你具体夸的是什么。
- 红线：不要夸对方无法改变的东西（外貌、家境）作为主要赞美。
- 依据：C。具体反馈比笼统评价更有行为指向。
- 来源：S06、S11
- 相关：5.2、5.4

### 5.2 赞美不比较

- 情况：「你比小王强多了」。
- 判断：比较式赞美会制造敌人和警惕：听的人会想「你是不是也在背后这么说我」。改成只对这个人说。
- 原话：「你这个方案把成本拆得很细，我照着改了预算表。」
- 回应：
  - 「那小王呢」→ 「我不比较，我说的是你这个做法。」
  - 「你别捧我」→ 「我说的是具体的事。」
- 接着做：赞美时删掉所有「比……好」。
- 做对了：赞美没有让第三方难堪。
- 红线：不要用贬低他人来抬高对方。
- 依据：C。比较性评价会引发不安全感。
- 来源：S06、S11
- 相关：5.1、5.5

### 5.3 感谢要说出「因为什么」

- 情况：只会说「谢谢」。
- 判断：有效感谢=具体的事 + 对你的影响 + 你做了什么回应。三句话，比一句谢谢重。
- 原话：「谢谢你昨天帮我顶了那个电话，我才赶上了汇报。这个人情我记着，下周你那边忙我帮你。」
- 回应：
  - 「不用」→ 「要的，我确实受益了。」
  - 「太客气」→ 「应该的。」
- 接着做：重要帮助在 24 小时内表达，一周内给实质回报。
- 做对了：对方知道你感谢的是哪件事。
- 红线：感谢不要附带请求，那会变成交易。
- 依据：C。具体化的感谢提升关系满意度。
- 来源：S06、S11
- 相关：5.1、9.3

### 5.4 公开赞美与私下赞美

- 情况：当众夸一个人，他被夸得不自在。
- 判断：公开赞美适合「成果」，私下赞美适合「努力与品质」。内向的人更接受私下。
- 原话：「你这次顶了很多压力，别人不一定看见，我看见了。」（私下，一对一）
- 回应：
  - 「别说了」→ 「好，那我心里记着。」
  - 「大家都一样」→ 「你的那部分我确实看到了。」
- 接着做：观察对方被夸时的反应，决定下一次的场合。
- 做对了：对方接受得自然，没有尴尬。
- 红线：不要用公开赞美来施压或绑架对方。
- 依据：C。赞美的接受度受人格与场合影响。
- 来源：S06、S11
- 相关：5.1、6.2

### 5.5 接受赞美：不否认、不反夸

- 情况：别人夸你，你立刻说「没有没有」。
- 判断：否认会让对方尴尬。接受三步：谢谢 + 承认（这次确实花了功夫）+ 归功（也靠谁帮了忙）。
- 原话：「谢谢，这次确实下了功夫，也多亏你把数据理清楚了。」
- 回应：
  - 「你太谦虚」→ 「真不是谦虚，这次确实运气也好。」
  - 「你厉害」→ 「谢谢，我继续努力。」
- 接着做：练习只说「谢谢」，不加否定。
- 做对了：你接受了赞美，也把功劳分给了该分的人。
- 红线：不要用过度自谦来索取更多赞美。
- 依据：C。接受正面反馈是自尊稳定的表现。
- 来源：S06、S02
- 相关：5.1、12.2

### 5.6 对上级与长辈的赞美

- 情况：想夸领导，又怕像拍马屁。
- 判断：对上级的赞美要落在「具体决策或做法」上，且要有事实支撑；不夸人品、不夸外貌、不夸权力。
- 原话：「您上次坚持先做小范围试点，后面扩量时问题少了很多，这个顺序我学到了。」
- 回应：
  - 「你这是捧我」→ 「我说的是那件事的结果。」
  - 「少来这套」→ 「好，那我不说了。」
- 接着做：赞美前先找到一个可验证的结果。
- 做对了：你的赞美里有一件具体的事。
- 红线：不用赞美换取资源、机会、评价。
- 依据：C。向上赞美最易被解读为交换，需以事实为锚。
- 来源：S11、S06
- 相关：5.1、5.2

# 6. 批评与反馈：对事不对人


批评的目的不是让对方难受，是让事情变好。绝大多数批评失败，是因为把「行为」说成了「人品」。

### 6.1 SBI：情境、行为、影响

- 情况：下属连续两次漏交报表，你憋着火。
- 判断：SBI 三段：什么情境、他做了什么、造成了什么影响。不加评价词，让对方自己得出结论。
- 原话：「昨天下午的例会上（情境），报表里第二页的数据没更新（行为），客户当场问了我一个答不上来的问题（影响）。」
- 回应：
  - 「你什么意思」→ 「我的意思是这份报表要再核一遍。」
  - 「又不是大事」→ 「对你不是大事，对客户是。」
- 接着做：批评前先写三行 SBI，检查有没有形容词。
- 做对了：对方开始解释原因，而不是防御。
- 红线：不用「你总是」「你从来」这类全称判断。
- 依据：B。SBI（情境-行为-影响）是反馈培训中的经典结构。
- 来源：S06、S09
- 相关：6.2、6.3

### 6.2 公开表扬、私下批评

- 情况：在群里指出同事的错误。
- 判断：表扬可以公开（具体成果），批评尽量私下（涉及尊严）。必须公开纠正时，只讲事实与改法，不追责。
- 原话：「这条数据口径我更新一下，之前那份作废，按新口径来。」（群内）→ 私下再说「刚才是你没核，下次注意」。
- 回应：
  - 「你刚才不是说我错了吗」→ 「群里说的是口径，你的事我们私下说。」
  - 「为什么不当面说」→ 「当众说解决不了问题，只会让你难做。」
- 接着做：涉及人的问题，一律转私聊或一对一。
- 做对了：问题解决了，对方没有丢面子。
- 红线：不要在群里 @ 全员指责某一个人。
- 依据：C。公开批评会触发羞耻与防御。
- 来源：S06、S03
- 相关：3.5、6.4

### 6.3 给改进路径，不只给问题

- 情况：你说了一堆问题，对方不知道怎么改。
- 判断：有效反馈必须包含下一步：改什么、怎么改、什么时候看结果、谁能帮。
- 原话：「这份报表下次发出前，你先用模板核三遍：日期、口径、合计。周五我再和你过一遍，卡住随时找我。」
- 回应：
  - 「我做不到」→ 「那我们先只做日期这一项。」
  - 「太麻烦」→ 「麻烦一次，比返工三次省事。」
- 接着做：每次反馈都以一个可执行动作结尾。
- 做对了：对方离开时知道下一步做什么。
- 红线：不要用「你自己想」当反馈。
- 依据：B。目标设定与具体行动计划能提升行为改变率。
- 来源：S06、S09
- 相关：6.1、6.6

### 6.4 接受批评：三段式回应

- 情况：被批评，你想解释，越解释越像顶嘴。
- 判断：先接住、再澄清、最后给方案。别在情绪峰值辩解，也别一句话不说。
- 原话：「这条我接受，确实是我漏了。我想确认一下：您更在意的是时间还是准确性？我按那个优先级改。」
- 回应：
  - 「你还有理由」→ 「不是理由，我想确认标准。」
  - 「态度不错」→ 「我把方案发您。」
- 接着做：被批评时先记在本子上，不当场反驳。
- 做对了：你拿到了明确的标准，而不是一肚子委屈。
- 红线：不要用「我知道了」敷衍，也不要把批评转成对对方的攻击。
- 依据：B。接受反馈的能力与成长型思维相关。
- 来源：S09、S06
- 相关：1.4、8.2

### 6.5 给上级提意见

- 情况：上级的方案有问题，你要不要说。
- 判断：对上级的反馈要点：私下、给数据、给选项、留决定权。不要在公开场合证明他错。
- 原话：「按这个方案我算了一下，成本会高两成。我准备了两个调整方案，您看要不要看一眼？」
- 回应：
  - 「你在教我做事」→ 「不敢，我是把风险摆出来。」
  - 「就按我说的」→ 「好，我执行，风险我记录在案。」
- 接着做：把意见写成「一个风险 + 两个选项」，一页纸。
- 做对了：你的意见被听见，且你保留了执行记录。
- 红线：不当众否定上级，不越级告状。
- 依据：C。向上反馈的接受度取决于场合与选择权保留。
- 来源：S11、S06
- 相关：6.4、11.3

### 6.6 反馈之后的跟进

- 情况：批评完就完了，问题再犯。
- 判断：反馈要有回访：三天看动作、两周看结果、一个月看是否稳定。没有跟进的反馈会被当成情绪发作。
- 原话：「上次说的三条，这两天我看前两条已经改了，第三条我们周五对一下。」
- 回应：
  - 「你还记着」→ 「说好的事我记着。」
  - 「又来查我」→ 「不是查，是确认有没有卡住。」
- 接着做：在日历上给每次重要反馈设两个回访点。
- 做对了：对方知道这件事没有过去，但也没有被追着骂。
- 红线：不要用反复翻旧账来施压。
- 依据：C。反馈闭环决定行为改变能否持续。
- 来源：S06、S09
- 相关：6.3、6.1

# 7. 拒绝：不解释过度，不道歉成瘾


不会拒绝的人有两个毛病：解释太多，道歉太多。解释多显得心虚，道歉多显得有罪。

### 7.1 一句话拒绝 + 一个替代

- 情况：同事让你周末加班帮他赶活。
- 判断：拒绝要短：一句不行 + 一个替代。解释超过两句就开始像商量。
- 原话：「周末我来不了。周一早上我可以帮你把前半部分过一遍。」
- 回应：
  - 「就半天」→ 「半天也不行。」
  - 「你为什么不来」→ 「有安排，不方便说。」
- 接着做：把拒绝话术压缩到 20 字以内。
- 做对了：对方没有继续劝第三次。
- 红线：不要编造重大理由（生病、家人出事）来拒绝。
- 依据：C。过度解释会削弱拒绝的确定性。
- 来源：S06、S09
- 相关：7.2、7.4

### 7.2 拒绝不必道歉三次

- 情况：「不好意思不好意思，真的抱歉……」
- 判断：道歉一次足够，且只为自己的部分道歉（占用时间、回复晚），不为「拒绝」本身道歉。
- 原话：「抱歉这么晚回你，这件事我做不了。」
- 回应：
  - 「你都不帮」→ 「我确实做不了。」
  - 「你道什么歉」→ 「为回复晚道歉，不为拒绝道歉。」
- 接着做：数一数自己一次拒绝里说了几个「不好意思」，压到一个。
- 做对了：你的拒绝干脆，对方也没有觉得被亏欠。
- 红线：不要用道歉换取对方的谅解义务。
- 依据：C。过度道歉会降低话语的可信度。
- 来源：S06、S09
- 相关：7.1、9.1

### 7.3 拒绝请求，不拒绝人

- 情况：拒绝之后对方疏远你。
- 判断：区分「这件事我不做」与「我不在乎你」。把后者说出来，前者才站得住。
- 原话：「这事我帮不了，但你这个人我认。以后有别的事你还可以找我。」
- 回应：
  - 「说得好听」→ 「我说到做到，下次你看。」
  - 「算了」→ 「你别急着算，我确实想帮你别的。」
- 接着做：拒绝后一周内主动联系一次，不谈那件事。
- 做对了：关系没有因为一次拒绝降温。
- 红线：不要用承诺未来帮忙来换取当下的脱身。
- 依据：C。关系维持依赖持续的非功利互动。
- 来源：S09、S06
- 相关：7.1、9.4

### 7.4 对强势者的拒绝

- 情况：领导或长辈用命令口气让你做分外的事。
- 判断：对强势者不硬顶，用「事实 + 影响 + 请示」：说明手上有什么、做了会有什么后果、请他排序。
- 原话：「这件事我可以做，但手上的〔项目〕今天要交。您希望我先做哪个？」
- 回应：
  - 「都要」→ 「那我需要有人接其中一件，您看谁合适？」
  - 「你自己安排」→ 「好，我把优先级写下来发您确认。」
- 接着做：把手上任务列成清单，冲突时拿出来对。
- 做对了：选择权回到了对方手上，你也没有被动加班。
- 红线：不要用消极怠工来表达不满。
- 依据：C。把冲突转为排序问题能降低对抗。
- 来源：S11、S06
- 相关：7.1、11.3

### 7.5 拒绝亲密关系的过度要求

- 情况：伴侣要求你随时报备、查看手机。
- 判断：亲密关系里的拒绝要说需求不说指控：「我需要一点自己的时间」，而不是「你控制欲太强」。
- 原话：「我需要每周有一个晚上自己待着，这跟你爱不爱我没关系。」
- 回应：
  - 「你就是不爱我」→ 「我爱你，但我也需要独处。」
  - 「那我也这样」→ 「你可以，我们都留一点空间。」
- 接着做：把边界说成具体的安排（时间、频率），不是抽象的态度。
- 做对了：你们有了一个可执行的约定。
- 红线：如果对方用威胁、自伤、辱骂来阻止你设界，这是危险信号，要外部支持。
- 依据：B。具体化的边界比态度声明更容易被接受。
- 来源：S05、S10
- 相关：12.4、7.4

### 7.6 拒绝之后的内疚怎么处理

- 情况：拒绝完心里难受一整天。
- 判断：内疚常来自「我应该有求必应」的信念。处理方式：写下你拒绝了什么、代价是什么、你保住了什么。
- 原话：「我拒绝这件事，保住的是我的休息和交付质量，代价是他可能不高兴。这个代价我认。」
- 回应：
  - 「你太自私」→ 「我这次优先自己，这是有意的选择。」
  - 「你变了」→ 「我在学怎么不硬撑。」
- 接着做：每次内疚时写三行：拒绝什么、代价、保住什么。
- 做对了：内疚还在，但不再驱动你反悔。
- 红线：不要用过度补偿（送礼、请客、加倍帮忙）来消解内疚。
- 依据：B。认知重构有助于降低不合理的 guilt。
- 来源：S06、S11
- 相关：7.2、12.2

# 8. 冲突：降温、复述、给选项


冲突本身不可怕，可怕的是升级。升级只有三个加速器：人身攻击、翻旧账、争输赢。拆掉这三个，冲突就能落地。

### 8.1 降温：先把音量降下来

- 情况：两人越说越大声。
- 判断：降温四个动作：降低音量、放慢语速、坐下、换地点。谁先降，谁掌握节奏。
- 原话：「我们都小点声，坐下说，我怕说重了伤感情。」
- 回应：
  - 「你别装好人」→ 「我不装，我确实不想吵。」
  - 「有什么好说的」→ 「那就先说这一件。」
- 接着做：冲突时先坐下，再开口。
- 做对了：争吵没有升级成互相攻击。
- 红线：不摔东西、不堵门、不动手；出现人身威胁立即离开并求助。
- 依据：B。非言语的降级能显著降低对抗强度。
- 来源：S04、S10
- 相关：8.2、12.4

### 8.2 复述对方的立场，直到他说「对」

- 情况：各说各话，谁也听不进。
- 判断：冲突中最有效的一步：把对方观点复述到他说「对」，再讲自己的。这不是认输，是拆掉对立。
- 原话：「我复述一下你的意思：你觉得我事先没跟你说就定了，让你在中间很难做。是这个意思吗？」
- 回应：
  - 「对，就是这样」→ 「那我明白了，我说说我的部分。」
  - 「你根本不懂」→ 「那你补充，我哪里说得不对。」
- 接着做：冲突中至少复述一次对方的完整立场。
- 做对了：对方开始听你说话。
- 红线：不要在复述里夹带嘲讽（「所以你觉得都是我的错咯」）。
- 依据：B。反映式复述能降低防御并提升问题解决率。
- 来源：S07、S10
- 相关：8.3、2.3

### 8.3 把「你」句换成「我」句

- 情况：「你从来不管孩子」→ 立刻开战。
- 判断：「你」句是判决，「我」句是陈述。结构：当……发生时，我感到……，我需要……。
- 原话：「这周三次接孩子都是我去的，我有点撑不住，我需要我们排个表。」
- 回应：
  - 「你怪我」→ 「我在说我累，不是在给你定罪。」
  - 「我也很累」→ 「那我们排表，都减一点。」
- 接着做：把想说的指责句改写成「我」句，写三遍。
- 做对了：对方开始谈安排，而不是反驳指控。
- 红线：不要用「我觉得你……」伪装我句。
- 依据：B。非暴力沟通强调观察、感受、需要、请求四要素。
- 来源：S10、S09
- 相关：8.2、8.4

### 8.4 给选项，不给最后通牒

- 情况：谈不拢，你甩出「要么这样要么分手」。
- 判断：最后通牒会逼对方选择对抗。改成两三个可执行的选项，把决定权交回去。
- 原话：「我有三个想法：一是每周固定两个晚上我接孩子，二是请个小时工，三是我们轮流。你倾向哪个？」
- 回应：
  - 「都不行」→ 「那你提一个，我们对比。」
  - 「你在逼我」→ 「我在给方案，不是下命令。」
- 接着做：冲突前先写三个方案，别只带一个。
- 做对了：讨论从「谁对」转向「选哪个」。
- 红线：不要把「分手/离职/断绝关系」当谈判筹码反复使用。
- 依据：B。选择感能降低对抗并提升承诺度。
- 来源：S09、S10
- 相关：8.5、7.4

### 8.5 暂停机制：约定停战线

- 情况：越吵越狠，说了不可挽回的话。
- 判断：提前约定暂停规则：谁都可以喊停、停多久、什么时候回来谈。没有回归时间的暂停是冷战。
- 原话：「我们先停二十分钟，我出去走一圈，八点我们接着说，我不会不谈。」
- 回应：
  - 「你就是逃避」→ 「我八点一定回来，说到做到。」
  - 「不用谈了」→ 「那我八点还是回来，你想谈就谈。」
- 接着做：和重要的人约定一个暂停词与回归时间。
- 做对了：暂停之后你们真的继续谈了。
- 红线：不用失联、拉黑、冷暴力作为惩罚。
- 依据：B。情绪泛滥时暂停并约定回归，有助于问题解决。
- 来源：S10、S04
- 相关：8.1、9.2

### 8.6 冲突之后：不翻旧账

- 情况：每次吵架都把三年前的事搬出来。
- 判断：冲突解决后要「结账」：说清这次的问题、达成的约定、下次怎么做。结过账的事不再作为弹药。
- 原话：「这次的事我们说清了，约定是每周排表。以后我不提今天这些话。」
- 回应：
  - 「你上次也这么说」→ 「这次我们写下来，做不到你提醒我。」
  - 「我记着呢」→ 「记着可以，别当武器。」
- 接着做：把约定写成一条可检查的规则。
- 做对了：同样的冲突没有再重复第三次。
- 红线：不把对方的隐私与软肋在下次冲突中当武器。
- 依据：B。反复翻旧账会阻断关系修复。
- 来源：S10、S09
- 相关：9.4、8.4

# 9. 道歉与修复


道歉失败通常不是因为不诚恳，而是因为掺了太多辩解。好的道歉只有四句话。

### 9.1 道歉四句：认事、认影响、认责任、给行动

- 情况：你想道歉，一开口就是「如果我让你不舒服」。
- 判断：四句结构：我做了什么、造成了什么影响、这是我的责任、我接下来怎么做。不加「但是」。
- 原话：「我昨天在会上打断了你两次。这让你后面没再开口，是我的问题。下次你有话说，我等你说完再补充。」
- 回应：
  - 「你早干嘛去了」→ 「是我反应慢了，现在补上。」
  - 「说说而已」→ 「我下周就这么做，你看。」
- 接着做：把道歉写成四句，删掉所有「如果」「但是」「你也」。
- 做对了：对方说「我知道了」，而不是继续追责。
- 红线：不用「我都道歉了」要求对方立刻原谅。
- 依据：B。有效道歉包含责任承担与修复行动。
- 来源：S10、S09
- 相关：9.2、9.4

### 9.2 五种假道歉

- 情况：「对不起，但是你也……」
- 判断：五种假道歉：条件式（如果你觉得）、辩解式（我也是为了你）、转移式（别人也这样）、索取式（你还想怎样）、表演式（当众哭诉）。
- 原话：「我不加但是了。这件事是我做错了。」
- 回应：
  - 「你又在演」→ 「那我不说了，我做给你看。」
  - 「你根本不服」→ 「我服不服不重要，我先改。」
- 接着做：复盘自己上一次道歉，找找有没有「但是」。
- 做对了：你的道歉里没有任何转折。
- 红线：不在道歉里顺带提出对方的问题。
- 依据：B。「但是」会抵消前面的责任承担。
- 来源：S10、S09
- 相关：9.1、9.3

### 9.3 道歉的时机

- 情况：气头上道歉，对方不接受。
- 判断：三种时机：立刻（小失误）、冷静后（涉及情绪）、行动后（涉及伤害）。涉及伤害要先停止行为，再道歉。
- 原话：「我知道现在说你可能听不进去，我先把那件事停下来。明天你愿意的话，我当面跟你说清楚。」
- 回应：
  - 「现在就说」→ 「好，我说：这件事是我错了。」
  - 「不想听」→ 「那我等你。」
- 接着做：判断这次该「立刻」还是「先行动」。
- 做对了：道歉的时机让对方接得住。
- 红线：不要用道歉来换取立刻和好。
- 依据：C。道歉效果受时机与行为改变影响。
- 来源：S09、S10
- 相关：9.1、9.5

### 9.4 修复：道歉之后的三十天

- 情况：道完歉，关系还是别扭。
- 判断：修复靠行为重复：连续四周做一致的改变，比一次煽情的道歉有效。
- 原话：「这一个月我按说的做：每周三我接孩子，你有事直接说。」
- 回应：
  - 「你坚持不了」→ 「那就看四周。」
  - 「还行吧」→ 「我继续。」
- 接着做：给自己设一个四周的行为检查表。
- 做对了：对方开始主动提起别的事，不再提那件。
- 红线：不要用一次大礼或一次旅行替代持续改变。
- 依据：B。信任修复依赖一致性行为。
- 来源：S10、S09
- 相关：9.1、8.6

### 9.5 被道歉时怎么回应

- 情况：对方道歉，你不知道该不该原谅。
- 判断：三个选项都合法：接受、接受但要观察、暂不原谅。不必为了体面立刻说「没事」。
- 原话：「我听到了。我现在还没完全过去，但我愿意看你接下来的做法。」
- 回应：
  - 「你还要怎样」→ 「我要的是时间，不是条件。」
  - 「那就算了」→ 「我没说算了，我说我需要时间。」
- 接着做：把「我需要时间」和「我原谅了」分开说。
- 做对了：你没有假装没事，也没有把门关死。
- 红线：不要用不原谅来长期惩罚，也不要强迫自己立刻和好。
- 依据：B。原谅是一个过程而非单次决定。
- 来源：S10、S09
- 相关：9.3、9.4

### 9.6 不可道歉的事：越界与伤害

- 情况：对方做了违法或严重越界的事，然后道歉。
- 判断：道歉不能替代责任。涉及暴力、性骚扰、诈骗、威胁，要保留证据、报警或走法律程序，而不是接受一句对不起。
- 原话：「道歉我收到了，但这件事我要按程序处理，证据我已经保存。」
- 回应：
  - 「我都道歉了」→ 「道歉不等于没发生。」
  - 「你别闹大」→ 「这不是闹，这是维权。」
- 接着做：保存聊天记录、录音、转账凭证，告知可信任的人。
- 做对了：你既没有被情绪绑架，也没有放弃权利。
- 红线：不私下收钱私了严重侵害；不独自赴约处理威胁。
- 依据：A。暴力、性骚扰、诈骗等行为可依法追究责任。
- 来源：S13、S14
- 相关：12.4、9.5

# 10. 安慰与陪伴：不急着给方案


安慰人最常见的错误是：对方要的是陪伴，你给的是方案。给错了，他会觉得你只想让这件事快点结束。

### 10.1 先问「你想让我听，还是想让我出主意」

- 情况：朋友诉苦，你给了一堆建议，他不说话了。
- 判断：开场先确认需求：倾听、建议、帮忙、还是只想有人在。问一句，省掉后面所有的错。
- 原话：「你现在是想让我听着，还是想一起想办法？」
- 回应：
  - 「就想说说」→ 「那你说，我不打断。」
  - 「你帮我想想」→ 「好，我先问几个问题。」
- 接着做：每次安慰前先问这一句。
- 做对了：你给的是对方要的。
- 红线：不要在对方要倾听时输出一堆人生道理。
- 依据：B。支持类型与需求匹配度决定安慰效果。
- 来源：S10、S12
- 相关：10.2、2.1

### 10.2 安慰的三句可用话

- 情况：不知道说什么，只会说「会好的」。
- 判断：三句最稳：这确实很难、我在、你想说说吗。避免：别难过、想开点、至少你还……。
- 原话：「这确实很难。我在这儿，你想说就说，不想说我就陪你坐会儿。」
- 回应：
  - 「你不懂」→ 「我可能不懂，但我不走。」
  - 「说了也没用」→ 「那就不说，我陪你待着。」
- 接着做：把「想开点」列入禁用词。
- 做对了：对方继续说下去了，或者安静地待着也不尴尬。
- 红线：不用「至少……」做比较式安慰。
- 依据：B。无效安慰常来自淡化痛苦与过早正面化。
- 来源：S10、S12
- 相关：10.1、10.3

### 10.3 不要在别人的痛苦里讲自己的故事

- 情况：对方说失业了，你开始讲自己当年更惨。
- 判断：把话题转到自己身上，会夺走对方的主角位置。想分享经历，先问一句「我有个类似的事，你要听吗」。
- 原话：「我经历过类似的，你要听我说说吗？不想听我就不讲。」
- 回应：
  - 「你说」→ 「那我讲两句，你看有没有用。」
  - 「不想听」→ 「好，那你说你的。」
- 接着做：分享自己经历前，先获得许可。
- 做对了：对方没有觉得被抢戏。
- 红线：不要用「我比你更惨」来证明你理解。
- 依据：C。自我暴露需要对方的许可与容量。
- 来源：S10、S11
- 相关：4.3、10.2

### 10.4 陪伴的具体动作

- 情况：说不出话，干坐着尴尬。
- 判断：陪伴可以很具体：倒水、做饭、接送、代办一件小事、陪着走一段。动作比语言更能承载情绪。
- 原话：「我不劝你了，我给你做点吃的，你吃完睡一觉，明天我送你去医院。」
- 回应：
  - 「不用麻烦」→ 「不麻烦，我闲着也是闲着。」
  - 「你别管我」→ 「那我坐这儿，你需要就叫我。」
- 接着做：每次陪伴至少做一件具体的事。
- 做对了：对方事后记得的是你做了什么。
- 红线：不要替对方做重大决定（辞职、离婚、投资）。
- 依据：C。工具性支持是情绪支持的重要补充。
- 来源：S12、S10
- 相关：10.5、10.1

### 10.5 危机识别：什么时候必须求助

- 情况：朋友说「活着没意思」。
- 判断：出现自伤、自杀表达、严重失眠、完全无法工作超过两周，要当作危机处理：直接问、不独自承担、联系专业与紧急渠道。
- 原话：「你刚才说活着没意思，我很在意。你现在有伤害自己的念头吗？我想陪你一起找专业的人。」
- 回应：
  - 「你别管」→ 「我管定了，我不能让你一个人待着。」
  - 「开玩笑的」→ 「那我也要确认一下，你现在安全吗？」
- 接着做：记住渠道：心理援助热线 12356，急救 120，报警 110；陪同就医，不承诺保密。
- 做对了：你把这件事交给了专业系统，而不是自己硬扛。
- 红线：不对自杀风险保密；不独自一人处理危机；不提供具体方法信息。
- 依据：A。危机干预伦理要求突破保密、转介专业与紧急救助。
- 来源：S13、S14
- 相关：12.4、4.6

### 10.6 安慰之后：不要追问进展

- 情况：安慰完天天问「好点没」。
- 判断：持续追问会变成压力。改成不施压的在场：偶尔发一条不带问题的消息，需要时随时能找。
- 原话：「不用回我，我就是告诉你我在。需要的时候喊我。」
- 回应：
  - 「你怎么不理我」→ 「我不需要你回，我在就行。」
  - 「我最近好多了」→ 「那就好，我不多问了。」
- 接着做：安慰后一周内发一条「不需要回复」的消息。
- 做对了：对方主动找你的时候变多了。
- 红线：不要用「我这么关心你」制造亏欠。
- 依据：C。低压力支持更易被接受。
- 来源：S12、S10
- 相关：10.4、4.6

# 11. 文字沟通：微信、群聊、邮件


文字丢掉了语气、表情和停顿，所以同样一句话，在微信上会比当面重三分。这一章给可复制的写法。

### 11.1 文字降温三招

- 情况：想发一段质问，手指已经按下去了。
- 判断：三招：删掉评价词、加一个具体事实、把「你」换成「我」。发之前读一遍：如果对方这样发给你，你会怎么想。
- 原话：「我下午发了三条，你有空回我一句就行，我有点担心。」（草稿原句是「你为什么不回我消息」，删掉评价词再发）
- 回应：
  - 「你阴阳怪气」→ 「我改一下说法：我现在有点着急。」
  - 「不用回了」→ 「那我等你。」
- 接着做：重要消息写完先存草稿十分钟。
- 做对了：对方回的是内容，不是情绪。
- 红线：不用冷暴力式的「哦」「随便」结束对话。
- 依据：C。文本缺失语调线索，易被解读为更强负面。
- 来源：S11、S10
- 相关：11.2、8.3

### 11.2 微信礼仪：三件事

- 情况：发「在吗」，对方半天不回。
- 判断：三件事：直接说事（不发「在吗」）、一次说完（不分十条）、给对方时间（不连环催）。
- 原话：「有个事想请你帮看下，不急，今天之内回我就行：〔具体问题〕」
- 回应：
  - 「怎么不早说」→ 「怕打扰你，先说个大概。」
  - 「在吗」→ 「在，你说。」
- 接着做：把「在吗」从输入法里删掉。
- 做对了：对方一次就能理解并回应。
- 红线：不在非工作时间用「急」施压同事。
- 依据：C。异步沟通应以信息完整为先。
- 来源：S11、S09
- 相关：11.3、11.4

### 11.3 语音、电话与见面的选择

- 情况：发六十秒语音轰炸同事。
- 判断：按事情轻重选渠道：复杂情绪与冲突要当面或电话；简单确认用文字；长内容用文档。语音只对熟悉且方便的人用。
- 原话：「这事文字说不清，方便的话我打个电话，五分钟。」
- 回应：
  - 「直接说吧」→ 「好，那我打字，可能有点长。」
  - 「发语音」→ 「我打字吧，方便你转给别人。」
- 接着做：冲突类沟通一律不用文字开场。
- 做对了：重要的事没有在文字里被误解。
- 红线：不用语音消息传达批评、分手、辞退这类高冲突内容。
- 依据：C。媒介丰富度应与任务复杂度匹配。
- 来源：S09、S11
- 相关：11.1、11.5

### 11.4 群聊里的分寸

- 情况：在群里被点名批评，很想回怼。
- 判断：群聊是公开场合：不解释、不辩论、不 @ 全员。私聊处理，群里只回一句「收到，我私聊您」。
- 原话：「收到，我私下跟您对一下细节。」
- 回应：
  - 「就在这儿说」→ 「涉及个人细节，我私下说更合适。」
  - 「你什么意思」→ 「我的意思是按您说的改。」
- 接着做：任何带情绪的群消息，先私聊再说。
- 做对了：群里没有留下你的情绪记录。
- 红线：不在群里公开他人隐私、工资、绩效、病历。
- 依据：A。公开他人个人信息可能构成侵权。
- 来源：S11、S13
- 相关：6.2、11.5

### 11.5 邮件与正式沟通

- 情况：要发一封投诉或催办邮件。
- 判断：正式沟通四要素：事实与时间线、诉求、期限、抄送对象。不带情绪词，全部可核查。
- 原话：「3 月 5 日我提交了申请（附件 1），3 月 12 日电话确认已收到。请于 3 月 20 日前回复处理结果，如需补充材料请告知。」
- 回应：
  - 「你这是在告状」→ 「我在走流程，抄送是规定。」
  - 「至于吗」→ 「书面确认对双方都好。」
- 接着做：所有重要沟通留一封书面记录。
- 做对了：你有完整的时间线与凭证。
- 红线：不在邮件里使用侮辱、威胁性语言。
- 依据：A。书面记录是主张权利的重要证据。
- 来源：S13、S11
- 相关：11.4、12.4

### 11.6 已读不回与延迟回复

- 情况：对方已读不回，你开始胡思乱想。
- 判断：先分清：忙、不知道怎么回、不想回。处理方式：给一次低压力的跟进，然后放下，不连环追问。
- 原话：「不着急，你有空再看。我先按原计划推进，有变化你说一声。」
- 回应：
  - 「你怎么不回」→ 「我怕催得紧，给你留点时间。」
  - 「我不想回」→ 「明白，那我按自己的来了。」
- 接着做：同一条消息最多跟进一次。
- 做对了：你没有把沉默解读成人格否定。
- 红线：不用连环消息、电话轰炸、朋友圈内涵来施压。
- 依据：B。对模糊信息做敌意归因会放大焦虑。
- 来源：S10、S11
- 相关：11.1、11.2

# 12. 自我情绪管理与求助


对别人情商高、对自己狠，是最常见的失衡。这一章讲怎么把自己也当成需要照顾的人。

### 12.1 情绪记账：一天三次一分钟

- 情况：说不清自己为什么累。
- 判断：情绪记账：早中晚各一分钟，记三件事：发生了什么、我的情绪是什么、强度几分。一周后能看出模式。
- 原话：「今天第三次被临时改需求，烦 7 分。规律看是「被打断」这一类最耗我。」
- 回应：
  - 「记这个有什么用」→ 「看清楚谁在耗我，才知道怎么调。」
  - 「太矫情」→ 「跟记体重一样，是个工具。」
- 接着做：用手机备忘录建一个「情绪账本」，坚持七天。
- 做对了：你能说出一周里最耗你的三类事。
- 红线：不要把记账变成自我批判的清单。
- 依据：B。情绪日记有助于提升觉察与调节能力。
- 来源：S02、S04
- 相关：12.2、1.3

### 12.2 恢复期：把休息当任务

- 情况：周末躺两天，周一更累。
- 判断：恢复需要三样：睡眠、身体活动、无目的的时间。刷手机不算恢复，是低强度刺激。
- 原话：「周六上午我不安排任何事，手机静音，出去走一小时。」
- 回应：
  - 「你不回消息」→ 「我上午静音，急事打电话。」
  - 「浪费时间」→ 「这是我恢复的方式。」
- 接着做：每周固定两小时「无产出时间」写进日历。
- 做对了：周一你的疲惫感下降了。
- 红线：不要用酒精、暴食、通宵游戏当恢复手段。
- 依据：B。心理恢复需要脱离工作情境与主动休闲。
- 来源：S04、S12
- 相关：12.1、12.3

### 12.3 情绪急救：四步

- 情况：突然被一句话击中，整个人发慌。
- 判断：四步：停（不动作）、呼吸（四秒吸六秒呼）、命名（我现在的情绪是什么）、选择（现在最该做的一件小事）。
- 原话：「我现在很慌，我先出去走五分钟，回来再说。」
- 回应：
  - 「你逃什么」→ 「我需要五分钟，回来我接着说。」
  - 「至于吗」→ 「对我来说挺大的。」
- 接着做：把四步写在便签上，贴在工位。
- 做对了：你没有在慌乱中做决定。
- 红线：不要用自伤、酗酒、冲动消费来缓解情绪。
- 依据：B。延长呼气能激活副交感神经，降低唤醒。
- 来源：S04、S12
- 相关：1.4、12.5

### 12.4 边界：什么情况必须求助

- 情况：不确定自己是不是需要看医生。
- 判断：出现以下任一条就该求助：持续两周以上情绪低落或失眠、明显影响工作生活、有自伤念头、遭遇暴力或骚扰、依赖酒精药物。
- 原话：「我这两个月一直睡不好，也没什么劲，我想去看看。」
- 回应：
  - 「想开点就行」→ 「我试过了，所以想找专业的。」
  - 「没那么严重」→ 「早点看更好。」
- 接着做：记住渠道：心理援助热线 12356，急救 120，报警 110，法律援助 12348。
- 做对了：你把求助当成正常医疗行为。
- 红线：有自伤念头时不要独处；不把危机干预交给非专业人士。
- 依据：A。心理危机干预与精神卫生服务有明确的专业路径。
- 来源：S13、S14
- 相关：10.5、12.5

### 12.5 向人求助怎么说

- 情况：想找人帮忙，又怕麻烦别人。
- 判断：求助要具体：说清你现在的状态、你需要什么、需要多久；给对方拒绝的空间。
- 原话：「我这两天状态不太好，能不能今晚陪我打个电话，二十分钟就行？不方便你直接说。」
- 回应：
  - 「你怎么了」→ 「说不上来，就是想有人在。」
  - 「我没空」→ 「好，我找别人，谢谢你。」
- 接着做：列出三个可以求助的人，标上他们能提供什么。
- 做对了：你开口了，也接受了对方可能的拒绝。
- 红线：不要把一个人当成唯一的支持来源。
- 依据：B。社会支持的可获得性是心理健康的重要保护因素。
- 来源：S12、S13
- 相关：12.4、4.6

### 12.6 长期：把情商练成习惯

- 情况：看完书，过两周又回到原样。
- 判断：习惯化需要三件事：一个场景（只在冲突时练）、一个动作（只用复述）、一个反馈（每周复盘一次）。
- 原话：「这周我只练一件事：冲突时先复述对方。复盘记在本子上。」
- 回应：
  - 「太慢了」→ 「一次练一个，才不会退回去。」
  - 「有用吗」→ 「四周后再看。」
- 接着做：每四周只挑一个能力练，写四条复盘。
- 做对了：四周后这个动作变成了默认反应。
- 红线：不要同时改十个习惯，那等于没改。
- 依据：B。单目标、短周期、带反馈的训练更容易形成习惯。
- 来源：S09、S12
- 相关：1.1、12.1
