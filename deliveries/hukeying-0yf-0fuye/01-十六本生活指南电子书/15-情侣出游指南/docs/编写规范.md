# 编写规范

[← 回总目录](../README.md)

## 一、条目的十个字段

每条必须是 `### 章.序 标题`，随后按顺序给全十个字段：

| 字段 | 写什么 | 长度 |
| --- | --- | --- |
| 情况 | 一个具体到能想象画面的处境 | 1 到 2 句 |
| 判断 | 这件事的性质、风险在哪 | 1 到 3 句 |
| 原话 | 能直接说出口的一句话 | 20 到 60 字，带场合暗示 |
| 回应 | 对方两种可能的反应，各配一句接法 | 正好 2 条 |
| 接着做 | 1 到 3 个有先后的动作 | 短句 |
| 做对了 | 怎么算这一步过了 | 1 句 |
| 红线 | 一个具体不能做的动作 | 1 句 |
| 依据 | A / B / C / D 加理由 | 1 句 |
| 来源 | S01 这类编号，必须在 SOURCES.md 里 | 1 到 3 个 |
| 相关 | 其他条目的编号，必须真实存在 | 1 到 3 个 |

## 二、证据分级

- **A**：法律、规章、官方渠道原文可查。
- **B**：有成体系的研究支撑，结论方向稳定。
- **C**：实务与经验归纳，给的是做法不是定理。
- **D**：本书编写情境与话术，没有效果验证。

涉及法律、景区规定与禁飞区的，正文必须写「以当地最新公告为准」。

## 三、写作纪律

1. 不推荐具体店铺、景点与路线。地点变化快，书只给判断方法。
2. 不编数据。没有可靠来源的百分比、评分一律不写。
3. 不写真实人名、账号、照片。所有对话标注为编写情境。
4. 不给危险机位，不写翻越围栏、进入未开放区域、禁飞区航拍的做法。
5. 住宿、亲密行为、照片发布，一律要求明确同意；「没拒绝」不算同意。
6. 涉及安全、天气、人群拥挤，先给安全提示，再谈怎么玩。

## 四、语言

- 全角标点，不用破折号（`build.py` 会报错）。
- 「原话」用「」包住，句中不要出现第二层引号。
- 章节标题 `# N. 标题`，条目标题 `### N.M 标题`。
- 不写「你应该」「你必须」，写「你可以」「更稳的做法是」。

## 五、来源表要求

`SOURCES.md` 至少 15 行，每行以 `| S01 |` 这种格式开头，写明类型、读到什么程度、用在哪。末尾必须有「哪些说法被删掉了」一节。
