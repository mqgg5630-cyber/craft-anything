# 2. 简历与投递：二十秒里让人停住

[← 回总目录](../README.md)

筛简历的人平均看一份不超过二十秒，而且多数是先扫「最近一份工作的职位和公司」，再扫「有没有做过同类的事」，最后才看细节。所以简历不是自传，是一份对人眼和机器都友好的索引。

本章的顺序按阅读顺序排：版式、证据、数字、异常段落、关键词、真实性。


### 2.1 一页纸的版式

- 情况：工作五年，简历写了三页，投出去没回音。
- 判断：简历的每一行都要争抢那二十秒。通用的有效顺序是：姓名与联系方式一行、一句话定位一行、最近两段经历占七成篇幅、技能与教育各两行。
- 原话：「我这份简历的重点是最近三年做的〔方向〕，前面的经历我压缩成两行，您看这样够不够判断？」
- 回应：
  - 「太短了，看不清」→ 「那我补一版项目附录，简历本体保持一页。」
  - 「你前面那家公司也不错」→ 「那段我留了一行，是因为和这个岗位关系不大，需要的话我展开。」
- 接着做：把简历打印成黑白 A4，站远两步看，如果三秒内找不到「你是谁、做过什么、联系方式」，就重排。
- 做对了：别人能在十秒内说出你的核心方向和最近一段经历。
- 红线：不要用花哨模板、进度条技能图、证件照配艺术字标题。
- 依据：C。招聘从业者的公开经验与结构化筛选流程一致指向「最近经历优先」。
- 来源：S16、S17
- 相关：2.2、2.5

### 2.2 项目经历写结果，不写职责

- 情况：简历上写「负责用户增长，参与活动运营」，面试官问「所以你到底做了什么」，答不上来。
- 判断：「负责」是职责，「把某指标从 X 做到 Y」才是证据。同一条经历，写成「动作加结果加范围」最容易被追问，也最容易证明。
- 原话：「这个项目里我主要负责〔具体动作〕，覆盖〔范围〕，结果是〔指标〕从〔前〕到〔后〕，代价是〔时间或成本〕。」
- 回应：
  - 「这个数字是你一个人的功劳吗」→ 「不是，我负责的是其中〔部分〕，团队一共五个人，具体分工是这样。」
  - 「数据怎么统计的」→ 「后台口径是这样，我每周导出一次，对比的是同类活动基线。」
- 接着做：每条项目经历写成三行：背景一句、动作两句、结果一句，每个数字都能说出统计口径。
- 做对了：面试官追问数字来源时，你能说出统计周期和对比基线。
- 红线：不要把团队成果写成个人成果，不要用无法解释来源的百分比。
- 依据：C。行为面试与结构化评估普遍要求可核查的具体行为与结果。
- 来源：S12、S16
- 相关：2.3、3.3、4.1

### 2.3 没有数据怎么办

- 情况：岗位没有量化指标，或者数据不能对外说。
- 判断：量化不等于百分比。可以从四个替代维度找证据：规模、频率、时长、影响人数。
- 原话：「我们部门没有对外指标，我用三个数说明工作量：每月处理〔数量〕单，平均时效〔时长〕，覆盖〔人数〕个业务方。」
- 回应：
  - 「这不算成绩」→ 「对，它说明的是稳定性和承载量，成绩部分是这两件：〔举两件具体事〕。」
  - 「有提升吗」→ 「有，我把重复环节合并后，单量处理时间从〔A〕降到〔B〕。」
- 接着做：翻自己过去一年的周报和聊天记录，找出所有带数字的句子，直接搬进简历，再补一句口径。
- 做对了：你用规模、频率、时长、影响面里至少两个维度描述同一件事。
- 红线：不要编造行业基准，不要说「提升显著」却不给数。
- 依据：D。写作组的改写方法。
- 来源：S27
- 相关：2.2、6.4

### 2.4 空窗、跳槽、转行怎么写

- 情况：有一段八个月空窗，或者三年换了两家公司，简历一投就被问。
- 判断：异常段落不会因为隐藏而消失，反而会因为「简历看不出来」在面试里变成突袭。主动写一句，等于提前拆弹。
- 原话：「〔某年某月到某年某月〕我在处理家里的事，同时考了〔证书〕、做了〔两个可交付的小项目〕，现在可以全职投入。」
- 回应：
  - 「为什么这么久」→ 「前四个月是家里必须我在，后面我在补技能，具体做了这两件事。」
  - 「你会不会又很快走」→ 「我上一份离开是因为〔客观原因〕，这次我看重的是〔具体的稳定性因素〕。」
- 接着做：在简历里用一行标注空窗期的产出，面试时准备两个可展示的东西，别只说「在休息」。
- 做对了：你能用一次呼吸的时间说清空窗原因和这段时间的产出。
- 红线：不要把空窗说成在职，不要伪造在职证明。
- 依据：D。写作组整理的案例；B。招聘方对就业断档的关注度在多个平台报告中出现。
- 来源：S09、S27
- 相关：6.2、6.3

### 2.5 关键词与筛选系统

- 情况：简历内容不错，但投大公司总是卡在初筛。
- 判断：中大型公司的初筛常先过系统再过人。系统匹配的是 JD 里的名词，人匹配的是动词和结果。两个都要有。
- 原话：「我把 JD 里的〔三个关键词〕对应到这三段经历上了，如果系统侧重〔某个词〕，我可以再调整表述。」
- 回应：
  - 「我们不看关键词」→ 「明白，那我按业务结果重写一版给您。」
  - 「你这个词写得太泛」→ 「具体是这套系统，我在里面做的是〔模块〕。」
- 接着做：把目标 JD 复制进表格，逐条标「我有证据」「我有相邻经验」「我没有」，第二列写成一句话补上，第三列不要硬编。
- 做对了：你的简历里出现的关键词，每一个都能在面试里讲三十秒。
- 红线：不要为了过系统罗列自己不会的技术名词，面试第一轮就会露馅。
- 依据：C。申请者跟踪系统按关键词初筛是行业通行做法。
- 来源：S09、S16
- 相关：1.1、2.1

### 2.6 造假的代价

- 情况：同事把职级从「专员」写成「主管」，把三个月写成一年，拿到了面试。
- 判断：背景调查、社保记录、离职证明、个税记录四者互相印证，造假被查出的概率随职级上升。offer 阶段查出来是撤回，入职后查出来是解除，且通常无补偿。
- 原话：「我这段经历的准确说法是〔真实职级和时长〕，当时团队只有三个人，我实际承担了一部分管理职责，但没有正式任命。」
- 回应：
  - 「那不算管理经验」→ 「对，所以我说的是承担，不是担任，具体做的是这三件事。」
  - 「你为什么不早说」→ 「简历上我写得简，是我的问题，现在把准确版本给您。」
- 接着做：把简历里所有可能被核实的字段列出来：公司、职位、起止时间、学历、证书、项目归属。逐项对照社保或个税记录，改到完全一致。
- 做对了：你的简历每一行都能被第三方核实，且核实结果与写法一致。
- 红线：不伪造学历、证书、离职证明、银行流水，不买「背调包过」服务。
- 依据：A。以欺诈手段订立的劳动合同可被认定无效，用人单位可解除；B。背景调查在中高端岗位已是常规环节。
- 来源：S01、S24
- 相关：9.2、10.3
