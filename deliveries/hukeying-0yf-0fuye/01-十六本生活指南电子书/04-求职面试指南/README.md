# 求职面试指南

**一本可离线阅读、可检索、可练、可验收的求职电子书。**

13 章，82 个具体处境。每条都写清：怎么判断、原话怎么说、面试官两种追问怎么接、接下来做什么、怎么算过关、哪条红线不能碰、依据有几成。

按岗位分：技术、产品、运营、市场、设计、销售、职能、应届转行，八类各给考察重点与必问题。问题按阶梯排：自我介绍、项目深挖、行为面试、难答的问题、连环追问。钱的部分单独成章：薪资谈判、offer 与合同、招聘陷阱、试用期。

配套 7 个 agent skills：查条目回答、模拟面试、谈薪计算、合同审查、offer 决策、极简版，以及把这个结构复刻到其他主题上的 `guide-forge`。

> **免责声明：** 本书是求职与劳动关系参考，不是法律意见。涉及具体金额、竞业、仲裁时效的纠纷，请咨询当地劳动仲裁机构或律师。所有案例都是编写情境，不是真人记录。

## 每条长什么样

```
### 9.2 试用期的三个数字
- 情况：公司说「先试用六个月，表现好再转正」，合同只签一年。
- 判断：试用期时长有法定上限，一年以上不满三年的合同，试用期不超过两个月。
- 原话：「我这份合同是一年，按试用期不超过两个月，能改成两个月吗？」
- 回应：
  - 「我们统一六个月」→ 「六个月对应的是三年以上的合同，如果合同期限不改，这一条可能不合规。」
  - 「试用期不缴社保」→ 「社保是从用工之日起就要缴的，麻烦人事确认一下。」
- 接着做：核对合同期限、试用期长度、试用期工资比例、是否只约定一次。
- 做对了：试用期长度与合同期限匹配，工资不低于转正后的 80% 且不低于当地最低工资。
- 红线：不接受「试用期不签合同」「不缴社保」「转正再签合同」。
- 依据：A。试用期上限按合同期限分级，工资不得低于约定工资的 80%。
- 来源：S01、S02
- 相关：11.2、11.3
```

## 四条底线

1. **不撒谎。** 学历、职级、在职时间、离职原因、项目归属，可以少说，不能说假。
2. **不违法。** 不伪造离职证明，不带走原公司客户名单和源代码，不签两份不同金额的合同。
3. **不自我贬低。** 被压价、被否能力，可以接受也可以拒绝，不需要用「我确实不行」换一个机会。
4. **不签看不完的合同。** 签字前不看条款，等于把解释权和钱一起交出去。

## 和流行面试攻略有什么不同

**第一，按岗位分开。** 「面试技巧」混在一起讲等于没讲。技术岗要证据链，销售岗要数字，职能岗要原则与协作的平衡。

**第二，把合同单独成章。** 大部分攻略只讲怎么拿到 offer，不讲拿到之后怎么不踩坑。试用期上限、违约金范围、竞业补偿、社保基数，这四条出错，损失按月算。

**第三，案例标明来源等级。** 法条是 A，行业报告是 B，方法论是 C，写作组的情境是 D。读者能判断哪句话可以拿去跟 HR 对质，哪句话只是建议。

**第四，所有话术都可替换。** 每条给的是句式，不是台词。填进去的必须是自己的真事，否则第一个追问就穿。

## 证据分级

| 等级 | 含义 | 这本书里大概有什么 |
| --- | --- | --- |
| A | 法条、司法解释、官方文件原文可查 | 试用期、二倍工资、竞业补偿、经济补偿 |
| B | 有公开数据或同行评审研究支撑 | 招聘漏斗、结构化面试效度、薪资数据 |
| C | 行业共识、权威方法论著作 | STAR、结构化面试设计、谈判锚点 |
| D | 本书编写情境与话术 | 所有「原话」、具体问法与接法 |

每条末尾标 `依据：X`，并给 `来源：SXX`。来源表在 [SOURCES.md](SOURCES.md)。没核到出处的数字不写。

### guide-forge 怎么用

它是这本书的「元技能」：拆任何一本指南的结构，再用同一骨架复刻一个新的。

```bash
# 拆：输出结构档案 JSON
python3 skills/guide-forge/scripts/deconstruct.py ../guiding-partner --json /tmp/gp.json

# 造：按档案生成新指南骨架（含构建工具）
python3 skills/guide-forge/scripts/scaffold.py --profile /tmp/gp.json --out ../my-guide \
    --title "我的指南" --chapters "先看地图,核心方法,常见处境,怎么收尾" \
    --per-chapter 6 --tools-from .

# 验：结构、字段、引用、排版卫生
python3 skills/guide-forge/scripts/audit.py ../my-guide
```

拆解输出长这样：

```
条目 104 条，章 13 个，来源 33 条
字段：情况(1.0)、判断(1.0)、第一句(1.0)、接着做(1.0)、做对了(1.0)、红线(1.0)…
回应：每条 2.0 组（quote-arrow）
证据：ABCD，来源 33 条
层次：{"web": true, "epub": true, "pdf": true, "build": true, "skills": 10, "selfcheck": 32, "patterns": 22}
```

## 自己构建

主构建只需要 Python 3.9+，没有第三方依赖。PDF 需要 `fpdf2` 和字体（`tools/fonts/` 已带子集字体，OFL 授权）。

```bash
python3 tools/build.py          # 生成 index.html、selfcheck.html、GUIDE.md、EPUB
python3 tools/build.py --check  # 只校验，不写文件
python3 tools/build_pdf.py --out "$PWD/downloads/job-interview.pdf"
```

改了 `book/` 或 `data/selfcheck.json` 之后重新跑一次。`index.html`、`selfcheck.html`、`GUIDE.md`、`downloads/` 都是生成文件，不要手改。
