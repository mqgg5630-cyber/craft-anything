# 健康饮食指南

**一本可以离线读、可以检索、可以照着配餐的饮食手册。**

13 章，78 个具体处境。每条都写清：怎么判断、原话怎么说、别人劝你吃时两种反应怎么接、接下来做什么、怎么算过关、哪条红线不能碰、依据有几成。

结构固定成三件事：每餐有没有蛋白质、蔬菜够不够、主食是不是全谷物。围绕这三件事展开：量化、外食、备餐、减脂、慢病配合、辟谣、就医边界。

配套 7 个 agent skills：查条目、一餐搭配、标签判读、减重计划、就医准备、极简版，以及把这个结构复刻到其他主题上的 `guide-forge`。

> **免责声明：** 本书是日常饮食参考，不是医疗建议，也不构成诊断。有确诊疾病、正在服药、孕期或术后，请以医生与注册营养师的意见为准。推荐量以《中国居民膳食指南》与相关国家标准为准。所有案例都是编写情境，不是真人记录。

## 构建

```bash
python3 tools/build.py --check
python3 tools/build.py
/tmp/v/bin/python tools/build_pdf.py --out "$PWD/downloads/healthy-eating.pdf"
python3 skills/guide-forge/scripts/audit.py .
```

字体是霞鹜文楷的子集，只打包本书用到的字。改完正文重新切一次：

```bash
python3 tools/make_fonts.py .
```

## skills

```bash
./tools/install-skills.sh
```

| Skill | 干什么 |
| --- | --- |
| `meal-adviser` | 查条目后回答一个具体处境 |
| `plate-builder` | 按餐盘结构给一餐的搭配 |
| `label-check` | 营养标签与配料表判读 |
| `weight-plan` | 能量与蛋白质目标、四周计划 |
| `doctor-prep` | 体检异常与就医前的问题清单 |
| `lean-diet` | 极简版：四行答案 |
| `guide-forge` | 拆解、复刻、验收别的指南 |
