# Field guides

Long-form, self-contained guides that live beside the engineering skills. Each one is built from the same skeleton (13 chapters, 6 to 8 entries per chapter, ten fields per entry, A to D evidence grades, source table, self-check, pattern library, and its own agent skills), with completely independent content and sources.

## The skeleton itself

All sixteen guides are instances of one reusable structure. The `guide-forge` skill in the job-interview guide can deconstruct any guide-like document and scaffold a new one from the same shape:

```bash
python3 job-interview/skills/guide-forge/scripts/deconstruct.py ./guiding-partner --json /tmp/profile.json
python3 job-interview/skills/guide-forge/scripts/scaffold.py --profile /tmp/profile.json \
    --out ./my-guide --title "我的指南" --chapters "先看地图,核心方法,常见处境,怎么收尾" \
    --per-chapter 6 --tools-from ./job-interview
python3 job-interview/skills/guide-forge/scripts/audit.py ./my-guide
```

Each guide owns its build, its skills and its licences. See the guide's own README before installing anything.
