# 编写规范

[← 回总目录](../README.md)

## 一、条目的十个字段

每条必须是 `### 章.序 标题`，随后按顺序给全十个字段：

| 字段 | 写什么 | 长度 |
| --- | --- | --- |
| 情况 | 一个具体到能想象画面的处境 | 1 到 2 句 |
| 判断 | 这件事的性质、风险在哪 | 1 到 3 句 |
| 原话 | 能直接说出口的一句话 | 20 到 60 字，带场合暗示 |
| 回应 | 对方两种可能的反应，各配一句接法 | 正好 2 条 |
| 接着做 | 1 到 3 个有先后的动作 | 短句 |
| 做对了 | 怎么算这一步过了 | 1 句 |
| 红线 | 一个具体不能做的动作 | 1 句 |
| 依据 | A / B / C / D 加理由 | 1 句 |
| 来源 | S01 这类编号，必须在 SOURCES.md 里 | 1 到 3 个 |
| 相关 | 其他条目的编号，必须真实存在 | 1 到 3 个 |

## 二、证据分级

- **A**：法律、规章、官方渠道原文可查。
- **B**：有成体系的研究支撑，结论方向稳定。
- **C**：实务与培训经验归纳，给的是做法不是定理。
- **D**：本书编写情境与话术，没有效果验证。

每条都要标等级，不许全部标 B。涉及法律与热线的，正文必须写「以最新规定为准」。

## 三、写作纪律

1. 不编数据。没有可靠来源的百分比、相关系数一律不写。
2. 不写真实人名、账号、机构个案。所有对话标注为编写情境。
3. 不教操控。冷处理、激将、制造嫉妒、情绪勒索一律不写进「原话」。
4. 不替读者做决定。书给判断素材与下一步，不给「你应该分手 / 复合」。
5. 每条必须有红线，且红线是可执行的否定动作。
6. 出现暴力、威胁、自伤、诈骗，先给安全与求助渠道，再谈其他。

复合类内容额外要求：不承诺复合成功率；涉及跟踪、威胁、自伤威胁时，先给安全与求助渠道。

## 四、语言

- 全角标点，不用破折号（`build.py` 会报错）。
- 「原话」用「」包住，句中不要出现第二层引号。
- 章节标题 `# N. 标题`，条目标题 `### N.M 标题`。
- 不写「你应该」「你必须」，写「你可以」「更稳的做法是」。

## 五、来源表要求

`SOURCES.md` 至少 15 行，每行以 `| S01 |` 这种格式开头，写明类型、读到什么程度、用在哪。末尾必须有「哪些说法被删掉了」一节。
