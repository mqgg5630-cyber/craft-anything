# 人情世故指南

**一本可以离线读、可以检索、可以照着念的人情往来手册。**

12 章，72 个具体处境。每条都写清：怎么判断、原话怎么说、对方两种反应怎么接、接下来做什么、怎么算得体、哪条红线不能碰、依据有几成。

按顺序走一遍就是完整的人情流程：先把人情算清楚、见面与称谓、送礼、请客与饭桌、红包与随礼、求人办事、亲戚与家庭、职场人情、邻里、红白喜事、拒绝，最后一章是必须停下的红线。

配套 7 个 agent skills：查条目、送礼合规检查、饭局方案、拒绝话术、礼账与人情账、极简版，以及把这套结构复刻到其他主题上的 `guide-forge`。

> **免责声明：** 本书是人情经验参考，不是法律意见，也不是任何地方风俗的裁判。涉及行贿受贿、借贷担保、婚丧喜庆报备的具体问题，请咨询律师或相应主管部门。所有案例都是编写情境，不是真人记录。风俗与规定各地不同，一律以本地与本单位的现行规定为准。

## 结构

```
renqing/
├── book/                 正文，一章一个文件，条目用 ### 编号
├── data/                 selfcheck.json 与构建产物 entries.json
├── docs/                 编写规范与验收报告
├── downloads/            PDF / EPUB / 单文件 HTML / 纯文本
├── skills/               7 个 agent skills
├── tools/                build.py（校验+渲染）、build_pdf.py、模板、字体
├── SOURCES.md            来源与核实记录
├── PATTERNS.md           20 个人情模式
├── GUIDE.md              构建生成的全文
├── index.html            检索页（构建生成）
└── selfcheck.html        自查页（构建生成）
```

## 重新构建

```bash
cd guides/renqing
python3 tools/build.py --check      # 只校验：字段、条数、来源编号
python3 tools/build.py              # 生成 index.html、selfcheck.html、GUIDE.md、EPUB
python3 tools/build_pdf.py          # 生成 downloads/renqing.pdf（需要 fpdf2）
python3 tools/audit.py              # 链接、词表、占位符检查
./tools/install-skills.sh           # 装 7 个 skills
```

字体是霞鹜文楷（SIL OFL 1.1）的两个子集，放在 `tools/fonts/`。PDF 不联网。
