# 编写规范

[← 回总目录](../README.md)

## 一、条目字段

每条固定 10 个字段，顺序不变，缺一个 `build.py --check` 就会报错。

| 字段 | 写什么 | 长度 |
| --- | --- | --- |
| 情况 | 一个具体处境，带场景细节（谁、在哪、说了什么） | 15–40 字 |
| 判断 | 这件事的性质与处理原则，一到三句 | 30–80 字 |
| 原话 | 一句能直接说出口的话，用「」包住 | 20–60 字 |
| 回应 | 对方最常见的两种反应 → 你怎么接，缩进两格 | 每行 20–50 字 |
| 接着做 | 一到三个可执行动作，按先后 | 20–60 字 |
| 做对了 | 怎么算这一步过了，可观察的标准 | 15–40 字 |
| 红线 | 一个具体不能做的动作 | 15–40 字 |
| 依据 | A/B/C/D + 一句理由，法律类写明条款 | 15–60 字 |
| 来源 | S01 这类编号，对应 SOURCES.md | 1–3 个 |
| 相关 | 两到三个条号 | 2–3 个 |

## 二、证据分级

| 等级 | 含义 | 写法 |
| --- | --- | --- |
| A | 法律、党纪、部门规章原文可查 | 写明法律名称与条款位置；不确定就不给 A |
| B | 有社会学、心理学研究支撑 | 写概念名与作者，不写编造的比例数字 |
| C | 行业惯例与地方风俗观察 | 必须带「各地差异大，先问再定」 |
| D | 本书编写情境与话术 | 只能用于「原话」与具体场景 |

**禁止**：把 D 级话术写成 A 级结论；用「研究表明」却不给研究；把地方风俗写成全国规矩；编造统计数字。

## 三、红线怎么写

红线必须是**动作**，不是态度。

- 好：「不向公职人员及其近亲属赠送可能影响公正执行公务的财物。」
- 差：「要注意分寸。」

每条红线都要能回答：如果做了，后果是什么（违法、违纪、赔钱、关系破裂）。

## 四、话术怎么写

1. 短。一句能说完，不超过两口气。
2. 有场合。标明当面、微信还是电话。
3. 不阴阳。不用反问、不用嘲讽、不用「你自己想」。
4. 给出替代。拒绝的时候尤其要给一个能做的事。
5. 不承诺做不到的事。

## 五、案例纪律

- 所有对话为编写情境，不挂真人姓名、单位名、地名细节。
- 不把网络流传的「真实案例」当一手材料，最多按 C 级引用。
- 不写具体礼金数额、不写「某地必须怎么随」。

## 六、合规自查（每章写完过一遍）

- [ ] 没有任何一条教人送礼换利益、请托干预程序
- [ ] 没有把「劝酒」「担保」「传话」写成可以变通的事
- [ ] 涉及法律的说法都有条款依据，或标为 C 级经验
- [ ] 涉及心理与情绪的说法没有诊断性表述
- [ ] 危机类内容给出了 110 / 120 / 12356 / 12348 等渠道
