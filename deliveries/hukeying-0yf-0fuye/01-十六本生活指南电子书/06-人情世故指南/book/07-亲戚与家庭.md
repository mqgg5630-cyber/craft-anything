# 7. 亲戚与家庭：催婚、借钱、比较

[← 回总目录](../README.md)

亲戚关系的特点是：不能选、躲不开、评价多。处理原则只有一条：把「关系」和「议题」分开。

### 7.1 催婚催生怎么接

- 情况：一桌人轮流问「什么时候结婚」。
- 判断：催婚的本质是话题习惯，不是真要答案。给一个体面但不承诺的回答，然后把问题抛回去。
- 原话：「在处着，有消息第一个告诉您。倒是您家〔孩子〕最近怎么样？」
- 回应：
  - 「要求别太高」→ 「我心里有数，您放心。」
  - 「再拖就晚了」→ 「晚不晚我认，您先吃菜。」
- 接着做：准备两三句「万能回答」，每次用同一句，问的人会腻。
- 做对了：你没有生气，也没有给出虚假承诺。
- 红线：不要当众跟长辈吵架，也不要用「关你什么事」伤人。
- 依据：C。重复使用同一套回答能降低追问频率。
- 来源：S14、S07
- 相关：7.2、1.6

### 7.2 亲戚借钱怎么处理

- 情况：表弟开口借五万，说三个月还。
- 判断：先分清救命钱、周转钱、消费钱。救命钱在能力内可以给，但要写清；周转钱看用途与还款来源；消费钱基本等于送。
- 原话：「五万我拿不出来。我能拿出〔数〕，这笔不着急还，你按自己的节奏来，但要写个条。」
- 回应：
  - 「还要写条？」→ 「写条是为了以后还能做亲戚。」
  - 「你不信我」→ 「跟信不信没关系，金额大了得有个凭证。」
- 接着做：约定金额、用途、时间、还款方式，写借条，转账留痕。
- 做对了：有一张双方签字的借条和转账记录。
- 红线：不替亲戚做贷款担保，不用自己的名义帮人借款。
- 依据：A。借款合同与保证合同都产生法律责任，书面凭证是主张权利的基础。
- 来源：S02、S03
- 相关：1.5、12.3

### 7.3 被比较时怎么应对

- 情况：亲戚说「你看你表哥都买房了」。
- 判断：比较的背后是攀比秩序。接住但不接招：承认对方的好，说明自己的节奏，不辩解细节。
- 原话：「表哥确实厉害，我这行节奏不一样，我先把手上的事做扎实。」
- 回应：
  - 「你就是不上进」→ 「我上进的方式可能跟您想的不一样。」
  - 「你看看人家」→ 「我看看，也学学。」
- 接着做：把「不解释、不比较、给出自己的节奏」当作固定句式。
- 做对了：对话在两轮内结束，没有升级成争吵。
- 红线：不要为了争一口气去借债消费、攀比排场。
- 依据：C。比较性话题通常不需要事实回应，只需要体面收场。
- 来源：S14、S07
- 相关：7.1、7.4

### 7.4 长辈的「为你好」

- 情况：父母坚持让你回老家考编，你觉得不合适。
- 判断：先接情绪、再谈事实、最后给方案：承认他们担心什么，说明你的计划与退路，给出可验证的时间点。
- 原话：「我知道你们担心我漂着。我给自己两年，做到〔具体目标〕；做不到我就按你们说的回去考，我们到时候再谈。」
- 回应：
  - 「你就是不听」→ 「我听，所以才跟你们商量时间点。」
  - 「外面有什么好」→ 「我先试一次，试过才知道。」
- 接着做：把计划写成三条可验证的指标，让父母看见进度。
- 做对了：争论变成了一个有期限的约定。
- 红线：不要用断绝关系、经济威胁来逼对方让步。
- 依据：C。家庭冲突中，接住担忧比反驳观点更有效。
- 来源：S07、S14
- 相关：7.3、11.5

### 7.5 家庭群与人情通知

- 情况：家族群里天天转谣言和养生文，还有人@你表态。
- 判断：家族群的原则是「少辩论、多回应」：问候要回，谣言不接，敏感话题转移。
- 原话：「看到了，谢谢关心。最近天气转凉，您注意身体。」
- 回应：
  - 「你怎么看」→ 「我不太懂这个，您说得对我就听着。」
  - 「转发一下」→ 「我这边不方便转。」
- 接着做：把群消息设置为免打扰，每天固定时间看一次。
- 做对了：你没有在群里和人吵起来，也没有被拉进是非。
- 红线：不要在家族群转发未经核实的募捐、寻人、健康信息。
- 依据：C。群聊的公开性放大了冲突成本。
- 来源：S14、S10
- 相关：9.4、12.5

### 7.6 兄弟姐妹之间的赡养与分摊

- 情况：父母生病，费用怎么分说不清。
- 判断：赡养是法定义务，分摊要落到纸面：谁出钱、谁出力、怎么记账、有争议找谁。
- 原话：「我们按收入比例分摊医药费，出力多的那份折算进去，每个月对一次账，写下来大家签字。」
- 回应：
  - 「都是一家人算什么账」→ 「正因为是一家人，才要算清楚，免得以后翻脸。」
  - 「我出不了那么多」→ 「那就按比例，把你能出的部分写清楚。」
- 接着做：建一个共享账本，票据拍照上传，每月对一次。
- 做对了：每个人都知道自己该出多少、出到什么时候。
- 红线：不要以「不分摊」为由阻止他人探望，也不要把赡养义务推给一个人。
- 依据：A。成年子女对父母负有赡养义务，费用分担可协商但义务不可免除。
- 来源：S02、S14
- 相关：7.2、10.5
