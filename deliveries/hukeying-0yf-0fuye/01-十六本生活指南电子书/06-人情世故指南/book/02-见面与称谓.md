# 2. 见面与称谓：第一次打交道的十分钟

[← 回总目录](../README.md)

第一次见面的十分钟决定后面几个月怎么相处。做对三件事就够：称呼对、时间对、话题对。

### 2.1 称呼怎么选

- 情况：不知道叫「老师」「总」「哥」还是全名。
- 判断：称呼按场合与资历：正式场合用姓加职务或「老师」，熟人圈子跟随在场多数人的叫法，宁可比实际关系更客气一档。
- 原话：「我跟着大家叫您〔称呼〕，如果不合适您告诉我。」
- 回应：
  - 「叫名字就行」→ 「那我叫您〔名字〕，您别介意。」
  - 「叫老了」→ 「那我改口，叫您〔称呼〕。」
- 接着做：见面前问一句中间人「大家平时怎么称呼他」。
- 做对了：你用的称呼和在场多数人一致。
- 红线：不要用「美女」「帅哥」称呼正式场合的陌生人。
- 依据：C。称谓是场合规则的一部分，跟随即稳妥。
- 来源：S14、S05
- 相关：1.4、2.2

### 2.2 自我介绍的三句话

- 情况：一开口就是「我是做市场的」，对方接不下去。
- 判断：自我介绍给三个信息：我是谁、我做什么具体的事、我为什么在这里。具体的事比头衔好接话。
- 原话：「我是〔名字〕，在做〔具体的事，比如给门店做线上投放〕，今天来是想听听大家怎么做复购。」
- 回应：
  - 「哦，同行」→ 「算半个同行，我们主要做〔细分〕。」
  - 「你们公司做什么的」→ 「一句话：帮门店把老客户叫回来。」
- 接着做：把自我介绍压缩到二十秒，练三遍。
- 做对了：对方能顺着你的话问出下一个问题。
- 红线：不要在自我介绍里塞满头衔和成绩。
- 依据：C。初次交流的信息密度应低而具体。
- 来源：S14、S07
- 相关：2.1、8.1

### 2.3 交换联系方式的分寸

- 情况：饭局上被要求扫一圈微信，扫完再没说过话。
- 判断：加联系方式要有由头：后续有事要对接、同一个兴趣、对方主动提出。没有由头就加，多半是负担。
- 原话：「我加您个微信，回头把今天的资料发您。」
- 回应：
  - 「都加一下」→ 「好，我加您，回头有需要随时说。」
  - 「你怎么不加」→ 「我微信主要用于工作对接，怕打扰您。」
- 接着做：加完当天发一条「我是谁 + 今天场合 + 一句话」，方便对方备注。
- 做对了：对方知道你是谁、为什么加他。
- 红线：不要用加来的联系方式做群发营销。
- 依据：C。弱关系维护需要明确的后续由头。
- 来源：S14、S06
- 相关：2.4、12.4

### 2.4 第一次见面的三类安全话题

- 情况：不知道该聊什么，冷场。
- 判断：安全话题三类：现场（怎么来的、这个地方）、共同点（中间人、行业、孩子或宠物）、对方擅长的事。避开收入、婚育、健康、政治。
- 原话：「您是从〔地点〕过来的？路上堵不堵？我刚在楼下找了半天车位。」
- 回应：
  - 「你做什么工作」→ 「我做〔具体的事〕，您呢？」
  - 「你结婚了吗」→ 「我还单着，先把工作弄明白。您家孩子多大了？」
- 接着做：准备五个开放式问题，现场挑一个。
- 做对了：十分钟里没有出现让对方面露难色的问题。
- 红线：不要用「你多大了」「买房了吗」开场。
- 依据：C。初次交流以低风险、可退可进的话题为宜。
- 来源：S14、S05
- 相关：7.2、2.2

### 2.5 准时与迟到

- 情况：迟到十五分钟，进门就被冷脸。
- 判断：准时是人情里成本最低的尊重。真迟到，提前告知 + 到场先道歉 + 不解释太多。
- 原话：「路上耽搁了，抱歉让您等。我先自罚一杯茶，咱们直接说正事。」
- 回应：
  - 「你怎么才来」→ 「是我的问题，路上预留不够，下次提前半小时出门。」
  - 「没事没事」→ 「还是不好意思，耽误大家时间了。」
- 接着做：把出发时间按最坏路况提前三十分钟设闹钟。
- 做对了：重要场合你比约定时间早到十分钟。
- 红线：不要用「堵车」当万能理由，也不要把迟到当身份象征。
- 依据：C。守时是关系中的基础信用。
- 来源：S14、S07
- 相关：4.1、8.4

### 2.6 记住对方的三件事

- 情况：第二次见面，对方记得你孩子名字，你连他做什么都忘了。
- 判断：人情靠记忆。见完面记三样：称呼、做什么、上次聊到的事。下次提一句，比送礼有用。
- 原话：「上次您说在给孩子找幼儿园，后来定了吗？」
- 回应：
  - 「你还记得」→ 「记了一下，怕下次见面接不上话。」
  - 「随口说的」→ 「那我也记着。」
- 接着做：微信备注里写一句「某年月日 + 场合 + 聊了什么」。
- 做对了：第二次见面你能自然接上上次的话题。
- 红线：不要记录对方的隐私信息并四处转述。
- 依据：C。记住细节是关系维护中成本最低的方式。
- 来源：S14、S06
- 相关：2.3、8.3
