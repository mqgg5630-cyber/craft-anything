# 5. 费用与隐形成本：租金之外还要付什么

[← 回总目录](../README.md)

租金是明的，费用是暗的。同一套 2500 的房子，有人每月实付 2700，有人实付 3200，差的不是运气，是签字前有没有问。

本章把「住进去第一个月要掏多少」和「每个月还会多掏多少」分开算。

### 5.1 入住总支出清单

- 情况：以为押一付三就是四个数，结果还要付中介费、门禁卡、水电预存、宽带安装。
- 判断：入住当天的总支出通常是：押金 + 首期租金 + 中介费 + 水电燃气预存 + 门禁卡/钥匙押金 + 宽带。
- 原话：「我今天入住一共要付多少？麻烦列个清单：押金、租金、中介费、水电预存、卡费，一项一项写。」
- 回应：
  - 「先付了再说，多的退你」→ 「请写在收据上，注明哪项可退、什么时候退。」
  - 「卡费不退」→ 「那我记下来，退租时这张卡我带走还是要还？」
- 接着做：让中介或房东写一张「入住费用清单」，逐项签字，留一份给自己。
- 做对了：你能背出「第一笔一共付了多少、其中多少是可退的」。
- 红线：不付没有名目的「管理费」「服务费」，不交现金不开票。
- 依据：C。费用名目与金额应在签约前明确列出。
- 来源：S09、S15
- 相关：1.1、5.2

### 5.2 水电燃气与物业费

- 情况：住进去第一个月电费七百，才知道是商用电价。
- 判断：住宅民用电价与商业电价差得远。还要确认：水电是否独立表、物业费谁出、公摊怎么算、燃气是否已开户。
- 原话：「水电是民用价还是商用价？是不是独立表？物业费含在租金里吗？燃气开户了没有？」
- 回应：
  - 「按度数收，一度一块二」→ 「这个价格是商业电价，我按民用价签，或者租金里扣。」
  - 「物业费你出」→ 「那写进合同，写明每月多少，避免涨价。」
- 接着做：入住时拍电表水表读数，问清缴费方式（自己线上缴还是交给房东），每月对一次账。
- 做对了：你手上有电价类型、表底读数、物业费归属三条书面记录。
- 红线：不接受房东自行加价转售水电，不接受「电费按人头平摊」却不给表。
- 依据：A。转供电主体不得在电费中加收其他费用；C。商水商电显著高于民用。
- 来源：S10、S01
- 相关：3.4、5.1

### 5.3 宽带与网络

- 情况：房东说「有网」，住进去发现是隔壁分出来的 WiFi，晚上卡到打不开视频。
- 判断：宽带的三个问题：是不是独立入户、带宽多少、费用谁出。分线 WiFi 在多人同时使用时不稳。
- 原话：「这套房宽带是独立拉的吗？多少兆？费用含在租金里还是我自己办？能不能现在测个速？」
- 回应：
  - 「有 WiFi 就行」→ 「我工作要开视频会议，想测一下高峰期速度。」
  - 「你自己办」→ 「那入户线有没有？能不能装机？」
- 接着做：现场用手机测速，晚上八点再测一次；确认光纤是否已入户。
- 做对了：你知道宽带归属、带宽和高峰期实际速度。
- 红线：不要为「送宽带」多付租金，自己办通常更便宜更稳。
- 依据：C。共享网络在高并发时段速率下降明显。
- 来源：S14、S15
- 相关：5.1、5.5

### 5.4 租金贷与各类「分期」

- 情况：签约时被要求下载一个 App 做「租金分期」，说只是方便付款。
- 判断：只要是让你签署借款协议、授权征信查询的，就不是付款方式，是贷款。房子退租了，贷款合同仍然有效。
- 原话：「这个分期需要我签借款协议吗？会上征信吗？如果我提前退租，贷款怎么结清？」
- 回应：
  - 「不影响，我们都这么办」→ 「那我选择按月直付，不接受任何借贷协议。」
  - 「不办分期要多付两百」→ 「那我按这个价租，或者换一家。」
- 接着做：付款只用银行转账到合同上的收款账户，备注「×年×月房租」，保留每笔凭证。
- 做对了：你名下没有因租房产生的任何贷款或分期。
- 红线：不为租房签任何借贷、分期、白条类协议，不把身份证与银行卡交给中介「代办」。
- 依据：A。借款合同的义务不因租赁关系终止而消灭。
- 来源：S18、S02
- 相关：2.4、5.1

### 5.5 家电维修与更换

- 情况：空调坏了，房东说「你自己修，修好算你的」。
- 判断：出租人有维修义务，承租人可以要求其在合理期限内维修；出租人未修复的，承租人可自行维修，费用由出租人负担。自然损耗与人为损坏要区分。
- 原话：「家电自然损坏由您负责维修，这个能写进合同吗？如果超过几天没修好，我能不能自己找人修、费用从租金里扣？」
- 回应：
  - 「用坏了你负责」→ 「正常老化不算我用坏，我们写明「非人为损坏由出租人维修」。」
  - 「家电很旧了」→ 「那请在交接清单上写明品牌、型号和使用状况。」
- 接着做：入住时把所有家电试一遍，拍照记录型号与状态，写进交接清单。
- 做对了：合同里有维修责任条款，清单上有每台家电的状态。
- 红线：不替房东垫付大额维修费却不留票据，不自行拆改燃气与电路。
- 依据：A。出租人应当履行租赁物的维修义务；承租人可以要求出租人在合理期限内维修；出租人未履行维修义务的，承租人可以自行维修，维修费用由出租人负担。
- 来源：S01
- 相关：7.2、3.4

### 5.6 公积金与个税：租房也能省钱

- 情况：每个月交房租，不知道租房支出可以提取公积金、也可以在个税里扣除。
- 判断：多数城市允许无自有住房的缴存职工提取公积金支付房租；住房租金也可作为个人所得税专项附加扣除。具体额度与条件以当地公积金中心与税务部门最新规定为准。
- 原话：「我在福州无房租房住，公积金租房提取需要什么材料？个税专项附加扣除怎么填？」
- 回应：
  - 「很麻烦」→ 「我先看官方要求，材料齐了再跑一趟。」
  - 「要房东配合」→ 「如果需要合同和发票，我提前和房东说清楚。」
- 接着做：查福州住房公积金中心官网的租房提取指南，以及个人所得税 App 的「住房租金」专项附加扣除填报。
- 做对了：你知道自己能提取多少、需要哪些材料。
- 红线：不伪造租赁合同或发票去提取，属于违规甚至违法。
- 依据：A。住房公积金提取与个税专项附加扣除均有明确的政策规定，条件与额度以当地最新公告为准。
- 来源：S05、S11
- 相关：1.1、5.1
