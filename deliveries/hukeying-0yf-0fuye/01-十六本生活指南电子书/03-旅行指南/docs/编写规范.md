# 编写规范

[← 回总目录](../README.md)

这本书的每一条都按同一套字段写。字段固定，才能被 `tools/build.py` 解析、被检索页渲染、被 skill 引用。

## 十个字段

| 字段 | 写什么 | 不能写什么 |
| --- | --- | --- |
| 情况 | 一个具体处境，第二人称 | 「很多人都会遇到」这类泛泛描述 |
| 判断 | 这个处境的真实机制，两三句 | 情绪安慰、道德评价 |
| 原话 | 一句能直接说出口的话，用「」包住，占位用〔〕 | 讲道理的长段落 |
| 回应 | 两种最可能的反应，各配一句接法，格式 `「对方」→ 「你」` | 第三种、第四种可能 |
| 接着做 | 一到三个可执行动作，按顺序 | 「多留意」「多比较」 |
| 做对了 | 怎么算这一步过了，可验证 | 「心里有底了」 |
| 红线 | 一个具体不能做的动作 | 「注意安全」 |
| 依据 | 等级 A/B/C/D 加一句理由 | 没有出处的数字 |
| 来源 | 一到三个 S 编号，必须出现在 SOURCES.md | 编造的编号 |
| 相关 | 一到三个条号，必须真实存在 | 指向自己 |

## 写作纪律

1. **一条只讲一个处境。** 两种情况塞进一条，读者会不知道先做哪个。
2. **原话要能念出来。** 写完读一遍，拗口就重写。
3. **数字必须有出处。** 租金、比例、天数，能查到才写，查不到写「以官方公告为准」。
4. **不做预测。** 不写「明年会涨」「这个片区会火」。
5. **不用破折号。** 中文正文里的「——」一律改成逗号或句号。
6. **地名与政策写清时效。** 涉及福州的具体政策，写「以当地最新公告为准」，并给出官方查询入口。
7. **案例标明等级 D。** 所有情境与对话都是编写材料，不指向任何真实的人。

## 证据分级

| 等级 | 含义 | 示例 |
| --- | --- | --- |
| A | 法律、部门规章、政府公开政策原文可查 | 民法典租赁合同章、商品房屋租赁管理办法 |
| B | 有公开数据或行业报告支撑，但样本有偏差 | 租赁市场报告、气象资料 |
| C | 行业通行做法与本地经验 | 中介费惯例、验房流程、片区感受 |
|  D | 本书编写情境与话术，没有效果验证 | 所有原话、具体案例 |

## 章节规范

- 每章 6 条，不多不少（构建脚本只接受 6 或 8）。
- 每章开头一段导语，说清这章解决什么问题，不重复条目内容。
- 条号 `章.序`，一旦发布不再改号，避免读者引用错位。
