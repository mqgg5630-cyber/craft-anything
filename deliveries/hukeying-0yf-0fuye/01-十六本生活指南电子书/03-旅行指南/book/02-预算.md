# 2. 预算：钱花在哪几块

[← 回总目录](../README.md)

旅行超支很少是因为「买了一件贵的东西」，而是因为五块费用里有一块没算：机票、住宿、当地交通、门票餐饮、保险与应急。

### 2.1 先算总预算，再分块

- 情况：只算了机票和酒店，回来发现门票和吃饭才是大头。
- 判断：一次旅行的花费大致按五块分：交通（含往返与当地）、住宿、餐饮、门票与体验、保险与杂费。每块定一个上限。
- 原话：「我人均总预算〔数〕，先按交通四成、住宿三成、吃玩两成、保险杂费一成分配。」
- 回应：
  - 「分这么细不累吗」→ 「分块才知道哪块超了。」
  - 「住宿可以省」→ 「那交通和体验就多留一点。」
- 接着做：做一张五行表，出发前填预算，回来后填实际。
- 做对了：你知道每一块花了多少、哪块超了。
- 红线：不要把全部预算压在机票上，导致到了地方不敢吃不敢玩。
- 依据：C。分块预算是控制旅行支出的通行方法。
- 来源：S15、S09
- 相关：2.2、13.1

### 2.2 交通费怎么省

- 情况：临时订票，价格是平时的两倍。
- 判断：交通费的弹性最大：提前订、避开周末与节假日前后、接受一次中转、用铁路替代短途航班，通常能省不少。
- 原话：「我愿意接受一次中转，时间多两小时，价格能低〔数〕，这个交换我接受。」
- 回应：
  - 「中转太麻烦」→ 「那就多花钱买直飞，看哪个更值。」
  - 「提前多久订」→ 「热门线路越早越好，淡季提前两三周也够。」
- 接着做：同一航线查三个日期，比较价差再决定。
- 做对了：你的交通支出在你设定的区间内。
- 红线：不要为省钱买「无行李额」的票却带了托运行李，现场补费更贵。
- 依据：B。机票价格随供需波动，提前与错峰是有效策略。
- 来源：S13、S04
- 相关：4.1、4.3

### 2.3 住宿费的取舍

- 情况：为了省钱住得离市区很远，每天通勤两小时。
- 判断：住宿的价值 = 位置 + 睡眠质量 + 安全。省下的钱如果换来两小时通勤或睡不好，通常不值。
- 原话：「我宁愿多花一点住在地铁站附近，把每天两小时省下来。」
- 回应：
  - 「酒店只是睡觉」→ 「睡不好第二天全废，这不是小事。」
  - 「民宿更有味道」→ 「可以，但先看位置和评价。」
- 接着做：把「住宿到主要景点/车站的时间」写进比价表。
- 做对了：你比价时把通勤时间算进去了。
- 红线：不要为了便宜住到治安不明的区域。
- 依据：C。位置与睡眠质量直接影响旅行体验。
- 来源：S15、S09
- 相关：5.1、5.4

### 2.4 门票与体验怎么分配

- 情况：每个景点都买票，结果最想去的那个没时间。
- 判断：门票分两类：必去的（提前订）、顺便的（现场看情况）。体验类（潜水、演出、向导）通常需要提前预约。
- 原话：「必去的两个提前订，其他现场看时间，体验项目只留一个。」
- 回应：
  - 「都想去」→ 「那就砍到两个必去，剩下当备选。」
  - 「现场买更贵」→ 「热门景点确实如此，提前订有折扣。」
- 接着做：列出「必去」「可选」「备选」三档，只订第一档。
- 做对了：你的行程里有两个确定的核心体验。
- 红线：不要通过非官方渠道买「内部票」「免排队票」。
- 依据：C。核心体验提前预约能降低行程风险。
- 来源：S09、S15
- 相关：6.1、7.5

### 2.5 保险与应急金

- 情况：觉得保险是浪费钱，结果行李延误赔不了。
- 判断：旅行保险要看三块：医疗与紧急救援、行程延误与取消、行李与财物。保额与免赔额比价格重要。
- 原话：「我看这三项保额够不够，尤其是境外医疗和紧急救援，再看免赔额。」
- 回应：
  - 「我身体很好」→ 「医疗险保的是意外，不是体质。」
  - 「信用卡送的够用」→ 「先看它保什么，再看缺什么。」
- 接着做：预留总预算的 10% 作为应急金，不动用。
- 做对了：你知道自己的保险保什么、不保什么。
- 红线：不要参加保险明确除外的高风险活动却不加保。
- 依据：A。保险责任以条款为准，除外责任需逐条确认。
- 来源：S10、S09
- 相关：10.1、11.2

### 2.6 汇率、手续费与现金

- 情况：境外刷卡被收了两笔手续费，取现又被扣一笔。
- 判断：境外消费的成本包括：汇率、货币转换费、取现手续费。提前查清卡的规则，比临时换钱划算。
- 原话：「我这张卡境外消费收不收货币转换费？取现手续费多少？当地刷卡普及吗？」
- 回应：
  - 「到处都能刷卡」→ 「小店和交通可能只收现金，备一点。」
  - 「机场换钱方便」→ 「机场汇率通常最差，先换少量。」
- 接着做：出发前查卡的境外规则，准备一张备用卡和少量现金。
- 做对了：你知道自己每笔境外消费的额外成本。
- 红线：不要在街头私人处换汇，也不要携带大量现金。
- 依据：C。境外支付成本由发卡行规则与当地习惯决定。
- 来源：S09、S15
- 相关：9.1、9.2
