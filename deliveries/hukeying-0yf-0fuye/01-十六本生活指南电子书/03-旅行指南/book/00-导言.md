# 0. 导言：旅行是可以被设计的

[← 回总目录](../README.md)

**这本书只解决一件事：让你把一次旅行从「想象」变成「可执行的七天」，并且在出问题时知道该找谁。**

旅行被讲成心情，所以大多数人的准备只有三步：订机票、看攻略、收拾行李。真实的旅行是一串决策：去哪儿、几天、多少钱、怎么走、住哪、证件齐不齐、出了事谁负责。每一步都可能因为一个没确认的细节多花钱或者毁掉行程。

这本书把旅行重新定义成一个可检查的动作：

> **每一段行程都要能回答三个问题：怎么去、到了住哪、出问题找谁。**

## 四条底线

1. **证件不冒险。** 护照有效期、签证类型、过境要求，以官方渠道为准，不听中介口头承诺。
2. **不为省钱买风险。** 无保险的高风险活动、无资质的包车、无合同的跟团，省下的钱不够一次意外。
3. **不越界。** 不闯禁区、不拍敏感设施、不带走文物与动植物制品。
4. **留一条退路。** 每天留出可调整的时间，账户里留出应急的钱，手机里存好紧急联络方式。

## 这本书不做什么

- 不做目的地种草，不推荐具体商家。
- 不给「必去清单」，因为每个人想要的旅行不同。
- 不教逃票、不教骗保、不教伪造行程。
- 不替代法律与医疗意见。纠纷、伤病、证件问题，以官方渠道与专业人士为准。

## 证据分级

| 等级 | 含义 | 这本书里大概有什么 |
| --- | --- | --- |
| A | 法律、国际公约、政府部门规章 | 护照与签证规则、航班延误、旅游合同、领保 |
| B | 有公开数据或行业规则支撑 | 机票价格规律、行李赔偿上限、保险条款结构 |
| C | 行业惯例与旅行者共识 | 行程节奏、住宿选择、打包清单 |
| D | 本书编写情境与话术 | 所有「原话」与具体场景 |
