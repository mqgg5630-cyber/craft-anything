# 4. 机票与火车：比价、退改、行李

[← 回总目录](../README.md)

交通票是旅行里规则最硬的一块：退改、行李、超售、联程，每一条都写在运输条件里，出问题时只看条款不看情理。

### 4.1 比价要看总价

- 情况：看到低价票，订完发现没有行李额，加购后比别家贵。
- 判断：比价要算总价：票价 + 行李 + 选座 + 餐食 + 到机场的交通。低价票常常在附加项上找回来。
- 原话：「我把行李和选座加进去，再和另一家比总价，不只看票面。」
- 回应：
  - 「便宜三百」→ 「加一件托运行李就没了。」
  - 「我不带行李」→ 「那就按这个价订，记得称重。」
- 接着做：用表格列三家：票面、行李、退改条件、到机场时间。
- 做对了：你比的是到手总价，不是票面价。
- 红线：不要在没有确认行李额的情况下带大件行李去机场。
- 依据：B。航空公司的行李与附加服务收费规则公开可查。
- 来源：S13、S04
- 相关：4.3、5.1

### 4.2 退改签规则

- 情况：临时有事要改签，发现特价票不能退。
- 判断：票价越低，退改限制越多。订票前先看退改规则，尤其是「不可退」与手续费比例。
- 原话：「这张票的退改规则是什么？起飞前多久改最便宜？」
- 回应：
  - 「到时候再说」→ 「到时候只能按最贵的规则来。」
  - 「可以买退票险」→ 「先看险的除外条款。」
- 接着做：订票前截图退改规则，存在订单文件夹里。
- 做对了：你知道这张票最坏情况下损失多少。
- 红线：不要指望「到机场再商量」，特价票的规则通常没有弹性。
- 依据：A。运输条件与票价规则构成合同内容。
- 来源：S13、S05
- 相关：4.4、11.1

### 4.3 行李规则与超重

- 情况：值机时被告知超重，现场补费比票还贵。
- 判断：行李规则看三样：件数、重量、尺寸。联程航班可能按最严格的一段执行。
- 原话：「这段联程的行李额是按哪一段算的？我这一件会不会被收两次费？」
- 回应：
  - 「应该没事」→ 「联程按最严的算，我先确认。」
  - 「到机场再买」→ 「线上加购通常更便宜。」
- 接着做：出发前用行李秤称一次，把规则截图存好。
- 做对了：你的行李在件数、重量、尺寸三项上都符合。
- 红线：不要在托运行李里放充电宝、锂电池与打火机。
- 依据：A。锂电池运输有明确的航空安全规定。
- 来源：S13、S05
- 相关：8.2、11.1

### 4.4 转机时间留多少

- 情况：转机只留一小时，前一段延误，后一段赶不上。
- 判断：同一机场转机至少留两小时，跨航站楼或需重新安检留三小时，跨国入境转机留更多。
- 原话：「这个转机时间够不够？需要重新过安检或入境吗？行李要重新托运吗？」
- 回应：
  - 「够，我们常这样」→ 「我按最坏情况留，误机成本更高。」
  - 「同一张票会负责」→ 「负责是改签，不是不耽误行程。」
- 接着做：查转机机场的航站楼与安检要求，把时间加到行程表。
- 做对了：你的转机时间在建议值以上。
- 红线：不要分开买两段票却按联程来安排时间。
- 依据：A。联程票与非联程票的承运人责任不同。
- 来源：S05、S06
- 相关：11.1、1.2

### 4.5 选座与红眼航班

- 情况：为了省钱坐红眼，第二天全程昏沉。
- 判断：红眼航班省的是钱，花的是恢复时间。选座看四件事：靠窗/过道、是否靠近洗手间、是否有电源、是否是紧急出口（部分航司收费）。
- 原话：「这趟红眼我第二天不安排行程，只做轻松的；座位我选过道，方便起身。」
- 回应：
  - 「睡一觉就到」→ 「飞机上睡不好，第二天要留恢复时间。」
  - 「选座要加钱」→ 「长途值得，短途无所谓。」
- 接着做：订完票立刻选座，长途优先过道。
- 做对了：红眼之后的第二天没有硬性安排。
- 红线：不要连续两晚红眼或过夜交通。
- 依据：C。睡眠不足会显著影响判断力与体力。
- 来源：S10、S15
- 相关：6.4、8.3

### 4.6 火车与高铁

- 情况：以为火车票随时能买，节前一周发现只剩站票。
- 判断：火车按座位类型与退改规则分层：提前订、避开高峰、看清是否需要换乘与换站。
- 原话：「这趟车是同一个车站换乘吗？中间留多久？退改规则是什么？」
- 回应：
  - 「到了再买」→ 「热门线路当天基本没票。」
  - 「站票也行」→ 「三小时以上站票会很痛苦。」
- 接着做：订票时确认出发站与到达站，别把「东站」「南站」搞混。
- 做对了：你知道自己从哪个站出发、在哪个站换乘。
- 红线：不要买「买短乘长」却指望补票有座，超员时可能被要求下车。
- 依据：A。铁路旅客运输规程对越站、补票有明确规定。
- 来源：S12、S05
- 相关：2.2、6.2
