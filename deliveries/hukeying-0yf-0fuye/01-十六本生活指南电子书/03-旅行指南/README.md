# 旅行指南

**一本可以离线读、可以检索、可以照着查的旅行手册。**

13 章，78 个具体处境。每条都写清：怎么判断、原话怎么说、对方两种反应怎么接、接下来做什么、怎么算过关、哪条红线不能碰、依据有几成。

按顺序走一遍就是完整的旅行流程：定形状、算预算、选季节、订票、订房、排行程、核证件、打包、路上、安全与保险、应急、拍照与复盘。

配套 7 个 agent skills：查条目、行程骨架、打包清单、预算分配、应急卡、极简版，以及把这个结构复刻到其他主题上的 `guide-forge`。

> **免责声明：** 本书是旅行参考，不是法律与医疗意见。签证、入境、保险与赔偿规则以官方公告与合同条款为准。境外遇险先联系当地警方与中国驻当地使领馆，外交部全球领事保护热线 12308。所有案例都是编写情境，不是真人记录。

## 构建

```bash
python3 tools/build.py --check
python3 tools/build.py
/tmp/v/bin/python tools/build_pdf.py --out "$PWD/downloads/travel.pdf"
python3 skills/guide-forge/scripts/audit.py .
```

字体是霞鹜文楷的子集，只打包本书用到的字。改完正文重新切一次：

```bash
python3 tools/make_fonts.py .
```

## skills

```bash
./tools/install-skills.sh
```

| Skill | 干什么 |
| --- | --- |
| `trip-adviser` | 查条目后回答一个具体处境 |
| `trip-planner` | 按天生成行程骨架 |
| `pack-check` | 生成打包清单 |
| `budget-split` | 五块预算与超支复盘 |
| `crisis-card` | 突发状况的应急卡 |
| `lean-trip` | 极简版：四行答案 |
| `guide-forge` | 拆解、复刻、验收别的指南 |
