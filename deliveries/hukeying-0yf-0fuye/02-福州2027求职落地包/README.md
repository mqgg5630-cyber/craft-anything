## 五、三条硬提醒

1. **福州一中 2027 校招本轮没有生物岗**（6 人：语文 1 / 数学 1 / 英语 3 / 物理 1）。别把精力押在它上面，盯 12 月—1 月的市属研究生专场。
2. **市疾控走 3 月底市事业单位统考，只能报一个岗**；省疾控、省微生物所、福建师大/福大生科院岗位都要求博士，硕士无入口。
3. **社保一交，应届身份就有争议**。企业 offer 到手先问清楚：是否当月缴社保、能否延后入职到 7 月、三方怎么签。事业编/教师编的政审看的是档案和三方，别自己先破局。
