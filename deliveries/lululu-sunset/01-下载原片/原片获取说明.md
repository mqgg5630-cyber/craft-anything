## 状态：未能获取原片

GitHub Actions runner（匿名、非登录）尝试多种方式后仍无法下载原片：

- xhslink.cn 解析后跳转到 `rednote.com/login`（登录墙）
- 回退到 `xiaohongshu.com` / `rednote.com` 的 `explore` 与 `discovery/item` 公开页
  （带与不带 `xsec_token` 分享令牌各试一次）
- 返回 `error_code=300031`「当前笔记暂时无法浏览」

该错误表示笔记在服务端已被下架 / 转为私密 / 限制访问，**匿名访问不可得**。因此本文件夹暂无作者原图，
`02-复刻无手机UI` 与 `03-复刻有手机UI` 下的是按同一主题的**原创风格复刻**，并非作者原图的精确复制。

## 如何补回真实原片

若你能在已登录的小红书 App / 网页中打开该笔记并复制图片直链（或以其他方式提供可公开访问的链接），
把图片 URL 列表写入本交付目录下的 `source-manifest.json`：

```json
{ "image_urls": [ "https://.../01.webp", "https://.../02.webp" ] }
```

然后在仓库根目录运行（或在 GitHub Actions 中推送 `download_lululu.py` 的改动以触发流水线）：

```sh
python tools/wallpaper-job/download_lululu.py
```

脚本会逐张经有界 `fetch` 校验器下载、写回 `01-下载原片/`，并更新 `下载记录.json`。
随后重新运行 `package_lululu.py` 即可把真实原片纳入总预览与验收记录。
