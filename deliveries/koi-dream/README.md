# 锦鲤入梦｜原片与复刻

- 原笔记：[锦鲤入梦｜锁屏壁纸](https://xhslink.cn/o/3qz2uQpojFp)，作者 Nihility，笔记 ID `6acb2a3800000000120390ba`。
- 原片为公开页面轮播中的 3 张 CDN 图片，GitHub Actions [运行记录](https://github.com/mqgg5630-cyber/craft-anything/actions/runs/45521991356) 下载、解码并验证：01 和 03 为壁纸画面，02 为锁屏／桌面对照展示图。图片非确认的作者无损母版，原图保留原有署名及文字。
- `images/01–05.png` 参考原片 01 的右侧水流留白构图；`images/06–10.png` 参考原片 03 的环形双锦鲤构图。十张均为 AI 参考再创作、细节与原图有差异，同一构图内是相近变体；06–10 后期叠加“时来运转”。02 为去除生成的多余字样裁去了底部 24 像素。
- `ui/` 是在相应成品上叠加日期、时间和图标的静态模拟锁屏，不是真实设备截图或安装主题。两个版本各有一张总览，另有原片总览。
- 输出尺寸：01、03、04、08–10 为 768×1376，02 为 768×1352，05 为 848×1264，06 为 720×1456，07 为 704×1504；无拉伸到统一尺寸。
- [Google Drive 总文件夹](https://drive.google.com/drive/folders/1qcfB9vH1hUnun2wykwtqhOCy5JwJgMzC)：原片、无 UI、模拟 UI 各放独立文件夹，每类含 ZIP 单图与总览。ZIP 数量及 CRC 校验、Drive 二次列出文件和 MD5 对比均通过。
