# 秋天和秋千｜十张壁纸

- 参考：[秋天和秋千很配哦～](https://xhslink.cn/o/C5WkFiFa1r)，公开页面仅有 1 张可见图片，使用 [GitHub Actions](https://github.com/mqgg5630-cyber/craft-anything/actions/runs/45967631923) 获取和核验，参考图不是经确认的作者无损母版。
- 参考图是 **852 × 1848**；10 张 AI 再创作壁纸及其静态模拟 UI 均等比裁切、重采样至相同尺寸，并非原生生成像素。围绕羊、树、秋千和夕阳保留相近画风，调整表情、秋叶、河流、花草和构图；由于 AI 再创作，角色细节会有变化，不能保证与参考完全一致。
- `source/` 保存原始公开展示字节，`generated/` 是 AI 底图，`images/` 是 10 张无设备 UI 壁纸，`ui/` 是后期静态锁屏模拟，并非真实手机截图。三种预览在项目根目录。`render.py` 记录适配步骤；`output-manifest.json`、`source-manifest.json` 记录尺寸和哈希。
- Drive [总目录](https://drive.google.com/drive/folders/1qlEHIu1yaSQguWyeeGojm734t62wAMBI)：参考、无 UI、模拟 UI 分开；后两组各含 10 张单图、完整 ZIP 和总预览。原图、全部单图、ZIP 和预览已重列并与本地 MD5 对照一致；ZIP 通过条目数量与 CRC 检查。
