## 尺寸与排版

- 原图4张与成品10张：**1080×2343**，不套用上一轮884×1851或默认9:16。
- 本轮10张模型背景的实际原生尺寸全部为704×1520。
- 交付前一次等比Lanczos放大并做极少量居中裁切至1080×2343，无横纵非等比变形。此处涉及插值，不能把最终像素称作模型原生像素或“无损新增细节”。每张尺度系数在 `output-manifest.json`。
- 适配后以本地Ma Shan Zheng书法字体排入黑色主句及旁边小字，依据每张实际纸条范围单独定位，保留类似原图的淡灰偏移墨影。字体及OFL在仓库 `assets/fonts/cjk/`。
- 脚本检查每一个主副文案字在字体cmap中存在，避免方框缺字；文字图层不再被缩放。
- 本轮未叠加手机系统UI、时钟或广告角标，保持用户参考的原图式壁纸。
