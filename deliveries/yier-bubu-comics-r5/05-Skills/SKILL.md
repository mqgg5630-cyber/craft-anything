# 同图同款、跨图不同款：治愈漫画

用户最新规则优先：一张图内两位角色的头套必须同款同色同造型；不同图之间不重复。不要再用一图两种头套的旧规则。

1. 选择上一轮认可风格的单张作参考，固定白色一二和棕色布布圆脸、腮红、暖棕线和奶油柔和配色。
2. 先列10种头套，每种分配给同一张的双方。为每张安排新场景、新的两句对白。
3. 每次generate_image只生成一张竖版。提示中重复强调 BOTH wear EXACT SAME IDENTICAL matching hood，同款同色同形；禁止其他头套。
4. 每张保留原生PNG，不强拉统一尺寸；本轮02和09为848×1264、07为768×1376，其余896×1200。
5. 制作1600×900总预览，打开逐对目检同款，跨图核对不同款，检查中文气泡。哈希不同不能替代视觉检查。
6. 10张独立PNG、总预览、SKILL和配方上传同一Drive文件夹，不用PDF/ZIP代替。每批最多3文件，间隔至少16秒，遇平台停止提示立即遵守。
7. 上传后重新列目录确认数量、无下一页，逐项核对云端MD5与本地。

配方是成功调用摘要，不是自动生成服务；需生成工具和Drive连接。
