# V3 · 1张复刻主画＋9张用途专用原画

本轮只做一个主题的一整套，不是10套不同主题。10次图像生成已用完。

本轮关键变化：电脑/平板/手表/朋友圈/QQ/聊天各自原生构图；两张情头直接生成1024×1024近景，不从全身图裁215像素小脸再放大。不同用途是同一参考下重新绘制，不是同一照片像素级重排，姿态/细节会有差异。

- masters：10张原生生成图，保留原始结果。
- images：33个独立成品，包括31张静态图、1段720p光点MP4、1个低清GIF预览。
- 31张静态图里包含10张完整原生无UI图、模拟UI、整幅适配导出及情侣版式组合。不是31次AI生成。
- 4K、1440p和平板标准尺寸版本为专用画布整幅等比放大导出，不是原生4K。
- 手表竖屏保留方图并加顶部时钟留白；情侣壁纸为完整近景头像缩小叠在聊天底图上，没有裁脸放大。
- UI为通用英文模拟，不是实机截图或安装包。聊天背景可供微信和QQ共用，未虚构两张独立AI聊天背景。
- 本轮无HTML/PDF/ZIP替代独立图片。新目录，不覆盖V1/V2。

制作思路、10次预算分配、用途安全区和清晰度边界详见skills/SKILL.md。
