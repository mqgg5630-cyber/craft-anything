# 懒羊羊和小猫｜十个场景（重新制作）

- 参考《带着小猫看晚霞的懒羊羊～》公开展示图（[笔记](https://xhslink.cn/o/6bdoxc66Ezp)，[Actions 下载](https://github.com/mqgg5630-cyber/craft-anything/actions/runs/45970439192)，原图 853×1844，并非经确认的无损母版）及百度百科中的经典动画角色参考。脸和画风取前者，身体依据经典形象补全；原图未显示完整身体。
- 本轮共 10 张独立 AI 再创作，以海边、苹果园、山间露营、湖畔、樱花公园、乡间车站、花园、河畔单车、风车山坡、小镇庭院为场景。角色脸、羊毛、两角、黄色口水巾、手脚及猫尽量统一；AI 绘制不能保证细节完全一致。
- `images/` 为无 UI 版本，`ui/` 为后期添加的静态锁屏模拟（不是手机截图）；各 10 张 PNG。生成底图均为 768×1376，等比裁切并重采样为用户设定的默认 852×1848，非原生增加画面细节。两个 ZIP 各 10 项且通过 CRC；两个总预览分别对应两组。
