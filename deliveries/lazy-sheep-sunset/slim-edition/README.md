# 懒羊羊和小猫｜十场景（纤细版）

- 参考《带着小猫看晚霞的懒羊羊～》的公开展示图（[笔记](https://xhslink.cn/o/6bdoxc66Ezp)，[GitHub Actions 下载](https://github.com/mqgg5630-cyber/craft-anything/actions/runs/45970439192)，原图 853×1844），未确认是作者无损母版。参考图身体被遮挡；用户同意按经典形象补全，并要求上一版偏胖的问题改为更纤细。
- 10 张分别是海边、苹果园、山间露营、湖畔、樱花公园、乡间车站、花园、河畔单车、风车山坡、小镇庭院；人物造型尽量一致，因 AI 重绘表情、姿势和细节仍会有变化。
- `images/` 保存 10 张无 UI 壁纸，`ui/` 保存 10 张静态模拟锁屏，并非真实手机截图；两组都以文件夹独立存放。底图经等比裁切、重采样到默认 852×1848，并非原生新增细节。
- Drive [总目录](https://drive.google.com/drive/folders/1eI_fmnJmBx2jE74_9M0Wa6uhzEdSzKDh)，[公开参考](https://drive.google.com/drive/folders/1P4Rr8xgp7cByEGx0KMlD5-ZHLRSO58hE)，[无 UI 十张](https://drive.google.com/drive/folders/1umU-mgeBlGUy3hwsObEpF8P_-1ZJKWn4)，[模拟 UI 十张](https://drive.google.com/drive/folders/1hfyKXcLwHy16bMcSNCpSwESSysfdecs7)。每组云端各有 10 单图和总预览；均已重列并逐项核对 MD5 和文件尺寸。
