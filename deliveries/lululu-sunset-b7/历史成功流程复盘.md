## 查阅范围与结论

本次列出仓库当前全部 **16 个远端分支头**，逐分支读取 GitHub tree，定位壁纸下载脚本、工作流和交付记录；重点读取同一笔记的三个成功分支及两个失败分支的脚本，并通过 Actions runs/jobs API 核对 8 个代表性成功运行的步骤状态。未切换、修改或推送其他分支。

机器可读证据：`branch-download-audit.json`。这是一份当前分支头与代表性运行的审计，不声称穷尽已删除分支或全部历史提交。

## 本轮可复现链路

1. **定位同一笔记，不按相似标题猜图。** 分享链接一致；笔记 ID `6ad212fc000000001802d6be`；历史清单标题「和你一起奔夕阳 噜噜噜妹壁纸」、作者「等噜噜」；轮播顺序为 5 张。
2. **来源种子入库。** `source-seed.json` 保存来源分支、不可变提交、原清单路径、成功运行链接、逐图 URL、尺寸、字节数及 MD5/SHA-256。只复制元数据，没有在当前环境从 CDN 下载图片。
3. **当前分支触发 Actions。** `.github/workflows/sunset-b7-download.yml` 只绑定 `arena/b7bfcf81-craft-anything`；`contents: write`；Python 3.12 + Pillow 11.3.0；先跑离线回归测试，再运行下载。下载脚本在非 Actions 环境主动拒绝执行。
4. **runner 下载与硬校验。** 精确请求历史已成功的公开图片 URL。复用 12 MiB 单响应上限、最小 300px 的 `fetch()`；再完整解码；本轮还要求格式、宽高、字节数、MD5 和 SHA-256 全部与历史清单相等，合计上限 60 MiB。任一失败不写回部分原片。
5. **全部通过后同分支回写。** 暂存全部 5 张，确认不会覆盖不同内容，再写出来源清单；机器人仅提交选定交付路径，`git push origin HEAD:$JOB_BRANCH`；本次成功机器人提交 `a2421d7`。
6. **回取与人工核验。** 当前分支 `git pull --ff-only` 取回的是仓库机器人提交，不是在当前环境请求小红书。再次解码/比对哈希，逐张看过 5 张原片后才生成。
7. **10 张独立参考生成。** 每张直接附对应已下载原片，不能用上一张生成图替代参考，也不从拼版裁出 10 张。保留毛绒角色、服饰、材质、夕阳暖色与留白；变化互动与场景。
8. **有 UI 是额外对应版本。** 保留 10 张无 UI PNG 原始输出，使用 `render_ui.py` 生成同名 10 张通用模拟锁屏；不是可安装主题或真机截图。渲染前后核对无 UI 文件 MD5 不变。
9. **总览不代替单张。** 原片、无 UI、有 UI 各自总览，另附包含三组的总预览；独立 PNG 仍分别交付。
10. **谷歌硬盘分目录验收。** 原片与结果分开，结果内再分有/无 UI；上传后重新列出各目录，比对数量、名称、字节数、MD5，并检查没有未读取的下一页。不能只凭上传返回成功就声称云端验收完成。

## 安全与停止边界

不使用 Cookie、账号、代理、验证码或登录会话；不尝试突破付费、私有内容或页面权限；不猜测资源标识、不伪造签名。历史公开地址若失效或哈希不一致，立即停止并记录，不冒充下载成功。没有历史已核验来源时，不能因为本次成功就把任意登录受限笔记视为可下载。
