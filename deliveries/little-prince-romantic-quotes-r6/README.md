# 小王子 · 浪漫短句10张

沿用无字第五辑的10张原画，每张排入一句不同的四字浪漫短句；并非重新生成10张AI原画。保留原画尺寸768×1376和全部构图，不覆盖无字版。短句使用仓库Noto CJK字体精确排版，不交给生图模型生成汉字。

01 星河予你
02 月色为你
03 此心向你
04 与你朝夕
05 余生是你
06 黄昏有你
07 心动不息
08 温柔予你
09 岁岁相依
10 此生与你

文字为暖金小字、舒展字距及轻微暗影，逐张选位避开主要人物；已检查总览后调整03、07文字位置。原始英文不恢复。实际壁纸只有一句短句，没有总览中的编号与标签。

images/内十张独立PNG；00-浪漫短句十张总览.jpg仅为浏览。manifest.json含逐张来源、短句、字位、字号、尺寸、字节和MD5。render.py可在仓库根目录用.venv/bin/python执行，需要Pillow、仓库字体和上轮原画。

本地数量、完整解码、尺寸、MD5互异检查通过。云端进度以cloud-verification.json为准（如存在）。
