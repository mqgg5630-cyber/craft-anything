## 4. 有UI与无UI

`package_delivery.py`离线在同编号成片上叠加透明UI层，源无UI PNG文件不变。金褐色衬线9:41时钟、Sun 22 Nov日期、锁图标、底部手电／相机和手势横条；第05时钟右移到留白区。系统DejaVuSerif字体不可用时回退仓库DM Sans，中文预览用仓库Noto CJK。

这是模拟锁屏效果，不是真机截图、动态主题、可安装系统皮肤。UI版不适合直接设为系统锁屏后再叠加手机自身时钟；实际设置壁纸应优先使用无UI版。
