## 做了什么

原帖公开 **6 张**（页面显示 1/6），六张原片全部留存。
按你的要求，**只以第 1、3、5 张为风格锚点复刻 10 张**干净壁纸；
第 2 / 4 / 6 张那种厚涂油画本轮不模仿，只作为「同一套角色、同一年四季」的背景参考。

## 尺寸与做法

模型原生输出 **768×1376**（十张完全一致，所以景别能对齐）→
按 1080:1920 裁切（只切顶部那片空天空，人物与地面一个像素都不裁）→
Lanczos 重采样到 **1080×1920**，不做非等比拉伸。
原生比例 0.5581 与目标 0.5625 相差 11 px，实际裁切量不到 1%。

## 有 UI / 无 UI

**`02-复刻无手机UI/` 是母版，永远不被覆盖。**
`03`、`04` 是从母版另存生成的独立文件，UI 只画在副本上；
`package_spongebob.py` 在渲染前后各算一次母版哈希，若被改动就直接失败退出。
`验收记录.json` 记录了 10 张母版与 6 张原片的 SHA-256，可逐张校验。

## 原片是怎么拿到的（沙箱限制）

本沙箱只放行 github / npm / pypi，小红书 CDN 直连会在 TLS 握手期被切断，
因此沿用仓库既有通道：`tools/wallpaper-job/download_spongebob.py` +
GitHub Actions 作业 `SpongeBob four-seasons source download`（run `44652225661`，
46 s 成功）在 Runner 上抓取公开 CDN 原字节，并回提到本分支。
只请求笔记页面本来就会加载的公开地址，不使用 cookie、凭据或私有接口。
