本套与上一套“和你一起奔夕阳”完全分开。原片、生成结果、UI 和校验记录不混用，也不改变上一套的上传进度。

## 交付内容

- `01-下载原片/`：实际下载的 **5 张**公开笔记轮播图，JPEG，**941×1672**；保留响应字节、原文字和来源标识，不重编码。不保证为作者母版。
- `02-复刻无UI/`：**10 张**独立图像条件 AI 重绘，PNG，原生 **768×1376**。01—05 对应五张参考，06—10 为同风格新场景；不是重复裁切、滤镜变色或放大。图片内中文短句为字体排版，不是手机 UI。
- `03-复刻模拟UI/`：与上述十张逐一配对的 **10 张**模拟锁屏 PNG，原生尺寸不变。日期 2026 年 11 月 22 日、时间 09:41；非真实设备截图。
- `00-总预览.jpg`：每组左无 UI、右模拟 UI，下方为五张实际原片。
- `04-无UI总览.jpg`、`05-模拟UI总览.jpg`、`原片总预览.jpg`：分类预览。
- `source-manifest.json`：Actions 原片校验清单，保留写回时记录。
- `output-manifest.json`：25 张单图与 4 张预览的尺寸、字节数、SHA-256、MD5、场景、短句和参考映射。
- `full-process.json`：完整制作过程的结构化记录及后续存储状态。

### 3. 下载与原片校验

- 实际笔记 ID：`6a6195240000000001030e32`。
- 标题：“今天是谁家的可爱噜啊”。
- 实际轮播 5 张，不虚称下载到 10 张原片。

### 7. 用字体精确排版中文

使用仓库 Noto Sans CJK 中文字体，按每张留白位置单独排短句并加浅色描边。检查总览后放大短句字号，尤其加强 04、05 的标题感；不依赖生图模型拼汉字。十句内容与字位均记录在清单和脚本中。

临时无字生成底图保存在本地暂存区，不作为原片。最终无 UI 成品已独立保存，之后重建 UI 不需要这些临时文件，也不会重生成 AI 图像。

### 8. 另存模拟 UI 版本

用 Pillow 透明图层添加日期、时钟、电量、信号、相机/手电与底部横条。按各张浅色背景选择深色文字，避免白字看不清；时钟与中文标题分区，人物区域不加大型遮罩。操作不改动无 UI 图。

### 9. 总览与验收

生成有/无 UI 对照总览、两套分类总览；逐张校验数量、完整解码、原生尺寸、哈希互异、原片不变及 UI 非破坏性。结构化记录见 `full-process.json`。完整包另做 ZIP CRC 校验。

## 离线复核 / 重建 UI 和预览

在仓库根目录、已有本套图片的情况下运行：

```sh
.venv/bin/python -m unittest discover -s tools/wallpaper-job -p 'test_download*py' -v
.venv/bin/python -m unittest discover -s tools/wallpaper-job -p test_cute_lulu_package.py -v
.venv/bin/python tools/wallpaper-job/package_cute_lulu.py
```

需要 Pillow 11.3.0、仓库内中文/数字字体。默认打包命令只读取现有十张无 UI 成品重建 UI、预览和本地清单；不会访问网络、上传文件或重新生成 AI 图像。首次 `--typeset` 需要临时底图，并拒绝覆盖已经保存的成品。
